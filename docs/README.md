# NAND 使用指南

NAND 将看板、评论、编程智能体、浏览器、档案、图标和自动化组合在同一个 Obsidian 库中。界面默认简体中文，也可选择英文。

| 要完成的事 | 指南 |
|---|---|
| 安装、选择语言、开启功能 | [首页与设置](settings.md) |
| 组织卡片、待办和快捷操作 | [看板](dashboard.md) |
| 运行手动操作、设置时间和查看结果 | [自动化与通知](automation.md) |
| 使用 CLI、原生历史和上下文 | [Agent 工作台](agent-workbench.md) |
| 浏览网页、采集材料和站点授权 | [内置浏览器](browser.md) |
| 管理人物、企业及相关资料 | [档案](contacts.md) |
| 对笔记添加评论 | [编辑器与评论](comments.md) |
| 设置文件图标和批量规则 | [图标](icons.md) |
| 打卡、记账、阅读和番茄钟 | [业务记录](records.md) |
| 查找数据、备份和处理保存失败 | [数据与恢复](data.md) |

开发者从 [领域与架构入口](../speculo/.speculo/specdev/.config/domain-layout.md) 阅读当前规范。第三方来源与许可证见 [Orca 适配说明](third-party/orca-terminal-workbench.md) 和根目录 README。
