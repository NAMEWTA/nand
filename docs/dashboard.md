# 看板

在设置里开启看板后，从工作台导航进入“首页”。功能区只有一个“打开工作台”图标；命令面板中的打开看板也进入这个首页。多份看板的选择留在首页页头，不另做导航产品。每份看板保存自己的栏目、卡片、待办及快捷入口。习惯和记账仍是首页上的小组件，不是独立的工作台页面。

## 内容与布局

从界面添加栏目、卡片和待办，设置布局、背景及需要的小组件。外观设置使用当前看板主题；记录类小组件的业务资料独立保存，关闭看板不会删除资料。

看板文件由 YAML 属性和 Markdown 正文组成。NAND 更新自己管理的字段和内容区域，保留未知 YAML、注释以及自由正文。不要删除身份标记或复制已有 ID 来创建另一条记录。

同一笔记在编辑器存在未保存修改时，先完成编辑再从看板保存；遇到冲突先保留草稿，再检查磁盘内容。不要把覆盖整份笔记当作冲突恢复方式。

## 快捷操作

可添加文件、Obsidian 命令、网页，或引用自动化中心的已保存操作。独立操作先在 [自动化中心](automation.md) 创建，无时间选择“手动”，然后“添加到看板”并选择目标看板。

同一操作可以固定到多个看板。快捷入口引用定义 ID，修改定义后入口读取新名称和内容；移除入口保留定义，删除定义后原入口显示不可用。运行中可查看状态、打开执行界面或停止支持取消的任务。

快捷按钮支持 Tab、Enter、Space；支持排序的快捷项可用 Alt + 方向键调整顺序。窄屏可展开侧栏或打开对应小组件面板。

网页卡片可选内部弹窗或原生标签页，详见 [浏览器](browser.md)。打卡、记账等资料的保存位置见 [业务记录](records.md)。

## 默认内容与最近编辑

新看板按创建时的 NAND 语言生成示例分区、阅读卡片和 Banner；切换语言不翻译已保存的用户内容。新配置的待办归档路径为 `Archive/Done.md`，划线导入目录为 `Weread/Highlights`；已有中文或自定义路径保持原值，界面换语言不移动文件。

“最近编辑”先排除 NAND 的习惯、记录和自动化管理集合、注册看板文件，以及配置档案目录中的主文件和格式说明，再排序并取设置数量。普通同名笔记、`NAND/` 下非管理目录中的笔记及档案关联材料不因此隐藏。
