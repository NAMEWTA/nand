# 看板

看板是工作台的首页，一块像手机桌面一样自由组合的小组件画布：想要哪些小组件、放在哪里、多大，都由你决定。一份看板是一篇 Apex v3.8.4 格式的 Markdown，受管笔记在 `.nand/content/`，工作台列表保存于 `home.workspaces: { files, names, active }`。

## 小组件画布

看板只有一种布局：12 列、10px 细行、10px 间距的网格。横幅、时钟、日历、番茄钟、常用操作、备忘、待办、项目、数据库、文件夹等全部是小组件，每种可以添加多个，自由摆放。看板文件里的 `widgets:`（有哪些小组件）和 `immersive:`（位置与大小）是唯一的布局来源；卡片与分区内容仍是 Markdown 正文，不受影响。

### 编辑模式

右上角「编辑看板」进入编辑模式，「完成」退出。非编辑模式下小组件照常交互，不会误拖。编辑模式中：

- 每个小组件顶部出现标题栏：抓手、图标与名称、尺寸档 S/M/L/XL、适应内容、设置和删除；整块小组件都可以拖动，右下角可缩放。小组件很窄时标题栏自动收起：先把尺寸档、适应内容和设置收进「更多操作」菜单，最窄时只剩抓手和菜单（删除也在菜单里），所有操作始终可达；触摸设备上按钮放大到 44px，栏随之变高，并更早收进菜单。
- 「添加小组件」打开面板：按分类（概览、时间、效率、记录、智能体、笔记与内容、媒体、工具，各带图标）筛选，可搜索，每个小组件带尺寸预览，先选尺寸档再添加。倒计时、纪念日、相册等有实例的小组件列出已有实例，并可「新建」。单例小组件已在看板上时显示「已添加」。
- 键盘：聚焦抓手后 Enter/空格拾起，方向键移动，Shift+方向键缩放，Enter 放下，Esc 取消。
- 每次放下、切换尺寸档、添加或删除只写一次文件；取消不写入。切换看板是一个整体：页面先变成只读并显示“正在切换看板”，目标看板（旧看板还要转换）在内存里加载并写好之后，路径和内容才一起换成新的；切换一开始，这张看板上打开的所有对话框、确认框、预览和浮层都会被关闭（不是隐藏），进行中的新建/配置立即结束，切换前拿到的任何回调（包括迟到的异步结果）此后都会被拒绝，不会落到另一张看板；源看板有未解决的冲突或未保存内容而不能离开时，切换被拒绝，源看板的本地内容和冲突状态原样保留；切换失败时回到原来的看板（路径、内容、写入目标都不变）并提示原因，连回退也失败时页面保持只读并说明原因，重新选择看板即可恢复；其他模块提供的小组件若其实例被移除，视图随即释放，位置保留为占位，实例回来后自动恢复。删除分区会连同其中的卡片，先确认。

### 尺寸档

每个小组件在自己的定义里声明支持的尺寸档（类似手机小组件），这是它唯一的尺寸表，档位映射到网格的宽（列）和高（行）。例如日历：S 4×28、M 4×50、L 6×52、XL 8×60。小组件的内容随所在框的实际大小排版，不只看档位：日历在不足以放下月历的高度（S 档）自动从周视图开始，用量只显示最忙的提供方（仍保留刷新按钮），快捷命令在很窄时只剩图标。选档会把高度固定为该档；仍可拖右下角在网格内自由微调，但不小于小组件声明的最小尺寸。内容分区（备忘、待办、项目等）默认按内容收缩，不超过保存的高度上限。

### 窄屏

页面宽度 960px 以下临时投影为 6 列，600px 以下为单列，按原阅读顺序排列。投影不写文件，窄屏下不能移动、缩放或切换尺寸档，宽屏打开后位置照旧。

## 多工作台

页面左上角用数字药丸切换工作台；「＋」输入名称并创建笔记，新看板使用默认布局。取消不会写入。设置 → 看板 → 常规中可重命名、调整顺序、改路径和移除工作台。移除只影响列表，保留笔记；至少保留一份。每个页面分别记住自己的看板，切换前先完成已有写入。

### 默认看板与旧看板

新看板从横幅开始：横幅、日历、备忘、待办、常用操作、番茄钟、项目和数据库。

旧版的左右、上下布局以及侧栏小组件开关已不存在。看板文件用 `canvas: 1` 标记画布格式；没有这个标记的旧看板（左右、上下布局，以及横幅还在网格外的旧沉浸布局）打开时转换一次：卡片、分区和横幅数据原样保留，原来侧栏里开启的小组件变成画布上的小组件，横幅成为顶部小组件，位置自动排好后写入文件并写上标记，之后不再转换，所以你删掉的横幅不会再回来。旧沉浸看板已有的位置原样保留，横幅补在空位上。

## 横幅

横幅是一个小组件，可以放在任意位置、选任意尺寸档，也可以添加多个：原来的横幅是第一个实例，「新建」得到一个从默认海报开始的独立横幅，各自的图片、名言和统计页互不影响（保存在看板文件的 `banners:`）。它支持多张图片每 30 分钟轮播、多条名言每 30 秒切换。设置（编辑模式标题栏的齿轮，或悬停时右下角按钮）打开海报设置，名言与图片可拖动排序，字体提供中文与英文各八款跨平台字体栈；每张图片可拖动预览调整焦点，也可输入位置或回到中心。没有图片时文字使用当前配色的前景色。

## 配色与外观

看板没有自己的主题：所有颜色都由 NAND 全局配色（设置 → 外观里的“NAND 配色”：跟随 Obsidian 或 Orca 中性色）和亮暗模式决定，背景、卡片、文字、边框、强调色与其他页面一致。看板内部使用的 `--db-*` 变量全部从全局令牌派生（`--db-bg` 取背景、`--db-accent` 取主色、卡片取卡片色），固定的图表色与状态色取图表和状态令牌。

外观工作室（命令「外观工作室」）只保留与全局一致的项：背景图（暗化、模糊、填充方式）、毛玻璃、表面不透明度、圆角、字号。可以另存为外观预设，预设同时保存全局主题和这些装饰；预设不含颜色。设置里可选择沿用 NAND 字体或使用 Obsidian 字体。

## 分区与卡片

分区也是小组件：在「添加小组件」面板中选备忘、待办、便利贴、笔记、数据库、文件夹、数据视图、日历、图片、视频、网页、工作流、项目管理、技能库、RSS、微信读书或滴答清单，就会新建一个该类型的分区，并放在你选的尺寸档上。可以添加多个。双击分区或卡片标题可重命名，Enter/失焦保存，Esc 取消。

- 便利贴：备忘、待办与网页快捷卡混排。备忘点击正文编辑，可设强调色、保存为笔记或置顶。待办支持勾选、子任务、进度、模板、归档及保存到日记。铃铛经自动化模块公开接口打开来源任务的提醒编辑器。
- 笔记：项目卡带可选封面、可调焦点和关联文档树。可搜索添加文档、拖动文档到其他项目卡、选择模板创建新笔记。
- 网页快捷卡：可选择弹窗、NAND 浏览器标签或系统浏览器。
- 拖拽：分区的位置和大小在编辑模式中调整；卡片、任务与文档仍可在分区内拖动排序。放下时只提交一次，取消不写入。

备忘编辑期间若同一正文收到外部修改，保存会提示冲突并保留草稿；先复制草稿，再取消并打开最新内容。无关字段的外部更新可以合并。暂时写入失败时可继续编辑，并在恢复写入后失焦保存最新草稿；本地失败提交不会被当作外部修改。归档待办需确认，先写入配置的固定文件或当天日记，再从看板移除；归档写入失败时保留任务。

## 数据库与文件夹

按文件夹、标签与属性筛选笔记，支持网格、画廊、列表、表格和看板五种视图。工具栏可搜索、排序、切换 S/M/L、选择日期区间、分组或全部折叠。表格可调整列顺序和显隐。分组与看板先显示 50 条，每次追加 50 条，总展示上限 500 条；普通列表使用分页。

点击笔记会打开就地预览，可切换为编辑并保存；也可在设置中选择直接在标签页打开。预览期间外部修改过的内容不会被草稿覆盖。

文件卡或列表中的删除入口会打开确认框，默认聚焦取消。确认使用 Obsidian 回收站操作。新建笔记支持选择文件夹及多个模板；数据库可预填等值筛选属性，文件名与模板支持标题、日期替换，并避开重名。

## 常用操作

常用操作条按今日、快捷命令、置顶笔记、模板新建和技能按钮排列。每行最多五项，超过时自动增高换行。齿轮可编辑四类列表、图标与排序。图标来自 Obsidian 完整目录，常用置顶、模糊搜索、最多显示 400 项。捕捉框可切换闪念或文件搜索；宽度不足时收起为铅笔按钮。闪念追加到目标笔记开头或末尾，未设目标时按文件夹和模板创建；Shift+Enter 换行。未提交闪念在窄屏投影切换后保留。窄屏（手机）关闭看板及弹层的背景模糊。文件搜索支持方向键、Enter 与 Esc。

## 快捷操作

快捷按钮可打开文件、执行命令或运行已保存的自动化操作。它通过自动化公开接口读取操作，不复制操作定义。

小组件通过「添加小组件」面板放到看板上，也可以随时删除再加回；没有单独的开关：

| 小组件 | 行为 |
|---|---|
| 快捷按钮 | 文件、命令、已保存自动化操作；右键移除，Alt+方向键排序 |
| 智能体用量 | 各智能体提供方的额度进度条与重置倒计时，可刷新；S 档只显示用量最高的提供方，M 档列出全部提供方，L 档再列出每个额度窗口（如 5 小时、每周），超过 80% 变黄、95% 变红。数据来自智能体模块的用量服务，与底部状态栏同源；该模块关闭时显示说明。 |
| 快捷命令 | 一组可自行配置的按钮：打开笔记、运行 Obsidian 命令、运行已保存的自动化、运行智能体模块里已保存的终端快捷命令（编辑器里直接选择，经智能体模块的公开接口）、启动智能体（向所选智能体的新会话发送一段提示词）。按钮是你自己配置的，点击即执行，不再确认；执行时会提示“正在运行/启动…”，目标已不存在（笔记被删、命令/自动化/终端快捷命令被移除、智能体未安装或已关闭、相关模块已关闭）或执行失败时，用提示说明是哪个按钮和原因，并提醒编辑该快捷命令重新选择。命令按钮在宽尺寸下显示已绑定的快捷键。小组件右上角的齿轮打开编辑器，保存前不写入；按钮列表保存在看板设置的 `shortcutButtons`，各看板共用 |
| 笔记导航器：最近笔记 / 快捷方式 | 显示笔记导航器的最近笔记或快捷方式（笔记、文件夹、标签、属性、保存的搜索），点击由导航器打开或定位；列表归导航器所有，这里只读。导航器模块关闭时显示说明 |
| 天气 | 城市搜索与经纬度、当前天气与五日预报；开启后使用 Open-Meteo |
| 番茄钟 | 专注/短休/长休、每日目标、暂停/跳过、正计时提醒与迷你面板 |
| 倒计时 | 多条目标日期、天/小时/分钟、提醒提前天数与背景图片 |
| 习惯 | 打卡/撤销、连续天数、添加习惯和补昨天的卡 |
| 记账 | 支出/收入、类别、备注、补录日期、今日收支与净额；设置货币符号 |

计时与记录服务由模块统一持有，多份看板不会创建重复计时器。页面隐藏时停止页面刷新定时器，关闭时释放订阅、观察器和拖拽资源。统计通过小组件上的按钮打开对话框。记录不再是工作台页面。其他分区见后文。所有看板弹窗统一在所属窗口居中，包括统计、配置、项目详情和外观工作室；不会以卡片位置作为弹窗中心。

## 统计与账本

| 领域 | 小组件里的输入 | 统计弹窗 |
|---|---|---|
| 习惯 | 添加习惯并勾选今天已完成；“补打卡”只能为前一天补打未完成的习惯 | 连续天数、近 30 天完成率、累计打卡次数、近 12 周热力图；可重命名和删除习惯 |
| 记账 | 记一笔支出或收入，包含金额、类目、备注和日期；不接受未来日期 | 按周、月、年或历史查看合计、净额、日均支出、类目占比、趋势、收支对比和类目排名；另有收支明细 |
| 番茄钟 | 为某个活动开始专注和休息 | 今日番茄数、效率分、打断次数、休息遵守率、近 7 日均值、本月和今年专注时间、每日目标仪表、时段分布、今日时间轴、热力图；可按活动筛选趋势 |
| 阅读 | 搜索书名或 ISBN 选书，或手动输入书名，然后开始计时 | 总计、今日、书籍数、连续天数、最近阅读和书籍列表；结束一次阅读时记录日期、时长和进度（页码或百分比），并可标记为已读完 |

这些小组件的设置（时长、每日目标、提示音、货币符号等）在 **设置 → 看板** 中。每日番茄目标为 1 到 16。货币符号显示在金额前。

### 收支明细

明细列出全部记录，支持搜索、筛选和排序，也支持编辑、批量删除、导入 CSV 和导出 CSV。导入要求列为 `date,type,category,amount,note`，并报告导入和跳过的行数。导出把当前筛选结果写入当前库的 `.nand/content/exports/expense-export-<日期>.csv`。

类目分两级。内置类目不可删除。可以添加最多 30 个自定义类目（名称 1 到 12 个字）和最多 10 个一级分类。删除自定义类目时，使用过它的记录保留数据和名称。

## 资料保存在哪里

| 领域 | 资料 | 默认位置 |
|---|---|---|
| 习惯 | 习惯定义和打卡记录 | `.nand/content/NAND/习惯/` |
| 记账 | 类目、收入和支出记录 | `.nand/content/NAND/记账/` |
| 阅读 | 书籍和阅读记录 | `.nand/content/NAND/阅读/` |
| 番茄钟 | 活动和专注记录 | `.nand/content/NAND/番茄钟/` |

无论界面语言是什么，文件夹名称都是中文。四个领域分别保存 Apex v3.8.4 格式的 `habits.json`、`expense.json`、`reading.json` 和 `pomodoro.json`。旧 NAND Markdown 数据保留原位，本次不迁移，也不会把不可读的文件当成空数据覆盖。

## 保存

界面区分 **保存中…**、**已保存**、**未保存** 和 **存在冲突**。出现“未保存”时，打开错误详情，检查文件权限和同步状态，然后重试。只有保存成功后，才能依赖重启来恢复你的输入。

读取失败或已损坏的文件不会被当成空数据覆盖。多处修改同时到达时，NAND 比较打开时的基线、当前编辑和磁盘上的最新内容：互不相关的修改会合并，对同一条记录的冲突则保留双方内容。删除不会因为简单的并集而恢复。

故障草稿保存在 `.nand/recovery/drafts/`。请备份整个领域目录，见[数据与恢复](data.md)。

## 联网

在阅读小组件中搜索书籍时，输入的文字会发送到 `book.douban.com`。这些记录的其他部分不联网。见[隐私与数据边界](privacy.md#联网)。

## 日期小组件

农历卡显示农历日期、节气、节日与宜忌，可打开六类抽签；签文逐字显示，解签后可重新选择。年度进度显示百分比与剩余天数。日历可切换月份、周起始日，查看当天笔记与任务，展开为全屏月历或任务列表；Shift+滚轮切月。纪念日支持阳历或农历、年月日/天/小时精度与每年提醒。

独立的闪念速记、文件搜索和技能按钮也是小组件，在添加面板中放到看板上。闪念沿用常用操作条配置的目标与模板；文件搜索按回车或圆形搜索键显示结果，左侧加号列出最近文档。技能键每行最多五个，齿轮位于末行，按钮列表独立于常用操作条；发送走 NAND 智能体接口，可先预览修改提示词或为单个按钮开启直接发送。

## 网页快捷入口

便利贴新增网页快捷卡后，可在编辑对话框填写名称、网址及打开方式：弹窗、NAND 浏览器标签或系统浏览器。

## 更多分区

- 数据视图：使用内置 DQL 的 TABLE、LIST、TASK、CALENDAR、HEATMAP；配置提供语法反馈与示例，结果可搜索、排序和分页，手机手动刷新后运行。
- 日历分区：月视图与周时间轴、任务筛选、今天和日期任务入口；任务落点可选日记、固定文件、每天一篇或每任务一篇，并可使用模板。
- 图片与视频：网格/列表、缩略图尺寸、文件夹/标签分组、日期与文件夹范围筛选、标签编辑、灯箱与移入回收站。灯箱支持左右方向键和 Esc，视频关闭后释放解码资源。
- 网页：配置网址与 50%–125% 显示比例。允许嵌入时使用 iframe，受限网页在桌面端使用隔离 webview，手机显示兜底入口；也可在 NAND 浏览器打开。
- 工作流：按状态分列，拖动或菜单移动到其他阶段，可配置阶段目录、截止与提醒、模板和卡片技能。写入失败保留实际完成的步骤，重试继续未完成部分。
- 项目管理：读取 `type: project` 笔记，里程碑与待办分开显示。项目看板内勾选、添加、删除任务和修改资料即时保存；支持新建、置顶、归档、工作笔记和分组看板。
- 技能库：通过智能体公开技能目录聚合同名条目，并读取 `.nand/content/NAND/技能/`；可搜索、置顶、分组、切换看板和导入包含 `SKILL.md` 的本地文件夹。卡片显示描述、来源徽章和更新时间；点击或按 Enter/空格查看完整技能说明、来源位置与逐实例移入回收站入口。调用先预览提示词，经 NAND 智能体接口发送；看板卡片可拖到其他分组，菜单也可调整分组。删除分组后成员归入未分组。导入副本及其附件保存在受管技能目录；已有同名文件不会被覆盖。

## 订阅与服务分区

- RSS：添加 HTTP(S) 订阅源、分组或导入 OPML，按来源、分组和未读筛选；阅读器可查看正文、标记已读并保存为受管 Markdown。默认文章与 OPML 位置为 `.nand/content/` 下的 `NAND/RSS/`，缓存和已读状态在 `.nand/cache/` 下的 `rss/rss.json`。正文优先使用完整 feed，其次缓存、页面提取和摘要。
- 微信读书：在设置中填写 API 密钥，可查看书架、筛选阅读状态与内容、配置统计、导入划线；密钥只保存在本设备设置。
- 滴答清单：选择中国或国际地区，通过桌面登录窗口或手动 Cookie/CSRF 配置连接；显示任务、已完成与习惯，支持完成/恢复、标题、日期、优先级和排序。仅有会话 Cookie 时不可写入。请求失败或超时会显示错误，写入超时后读取核实，不自动重复提交。

音乐小组件支持网易云搜索、歌单、播放顺序、音量、进度、歌词及账号；相册支持多实例、递归图片、自然排序、悬停暂停、手动切换、比例与轮播间隔。音乐需要桌面端；登录与外部服务可用性由服务方决定，见[隐私](privacy.md#联网)。

## 横幅统计页

横幅编辑有「海报」与「数据统计」两页。统计页可配置三栏指标、进度项、强调色、模糊、暗化、日记与排除文件夹、笔记或习惯热力图。命令「切换横幅视图」可切换两种模式。

## 设置与备份

看板设置分为常规、小组件、关于三个标签。常规页包含多工作台、路径、待办归档位置、RSS 已读保留时间与备份，以及外观工作室入口。小组件页只保留各小组件的专用选项与背景（音乐账户、相册多实例编辑、倒计时显示模式、纪念日删除确认、货币符号等），不再有开关。快捷按钮、番茄钟、习惯与年度进度的图片、不透明度、暗化、模糊和文字颜色保存在设置里。常规页保留微信读书 API 密钥、获取链接和导入路径；关于页显示当前插件版本和上游署名。

启用备份后可按小时、日、周或月保存当前工作台 Markdown 与习惯、记账、番茄钟、阅读 JSON，按时间戳分组并保留指定数量。也可立即备份或确认恢复最近备份。备份位于 `.nand/recovery/dashboard/backups/`，带来源路径和完整性清单；恢复只匹配同一工作台，覆盖前保留 `before-restore` 副本。恢复最近备份只恢复看板，记录快照作为独立备份保留，需另外恢复。
