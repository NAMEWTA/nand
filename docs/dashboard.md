# 看板

看板是工作台的首页。一份看板是一篇 Apex v3.8.4 格式的 Markdown，包含海报横幅和分区。受管笔记在 `.nand/content/`，工作台列表保存于 `home.workspaces: { files, names, active }`。本轮重构不迁移旧 NAND 的专用看板格式。

## 多工作台与布局

横幅左上角用数字药丸切换工作台；「＋」输入名称并选择左右或上下布局，再创建笔记。取消不会写入。设置 → 看板 → 通用中可重命名、调整顺序、改路径和移除工作台。移除只影响列表，保留笔记；至少保留一份。每个页面分别记住自己的看板，切换前先完成已有写入。

左右布局中，侧栏默认收起为 15px 细条。鼠标悬停或点击展开，点外部收起，横幅左下钉子可固定。拖右缘可设宽度 180–420px。上下布局将小组件放到顶部卡片墙，每列宽 240px、间距 6px，底缘可调整单元高度 240–560px；常用操作条固定在上方。页面宽度不超过 600px 时切换为手机排布，用图标打开小组件抽屉。

## 横幅与主题

横幅高 120px，支持多张图片每 30 分钟轮播、多条名言每 30 秒切换。编辑按钮打开海报设置，名言与图片可拖动排序，字体提供中文与英文各八款跨平台字体栈；每张图片可拖动预览调整焦点，也可输入位置或回到中心。书签按钮收起横幅。横幅收起与侧栏固定状态保存于当前库。

## 看板外观

设置中可选择 13 个 Apex 主题：大地、北欧、宝莉、花漾、胶囊、岛屿、苔原、抹茶、朱砂、霓虹、伏特、岩浆和曜黑。按钮、输入与弹窗跟随看板主题；默认沿用 NAND 字体，也可使用主题字体。

## 分区与卡片

末尾「添加分区」打开 15 类类型网格。本阶段开放便利贴、笔记、数据库和文件夹；其余类型留待后续阶段。双击分区或卡片标题可重命名，Enter/失焦保存，Esc 取消。折叠、拖动排序、底边高度调整和相邻分区半宽并排均会保存；半宽分隔条可设 20%–80%。

- 便利贴：备忘、待办与网页快捷卡混排。备忘点击正文编辑，可设强调色、保存为笔记或置顶。待办支持勾选、子任务、进度、模板、归档及保存到日记。铃铛经自动化模块公开接口打开来源任务的提醒编辑器。
- 笔记：项目卡带可选封面、可调焦点和关联文档树。可搜索添加文档、拖动文档到其他项目卡、选择模板创建新笔记。
- 网页快捷卡：可选择弹窗、NAND 浏览器标签或系统浏览器。
- 拖拽：使用标题或抓手调整分区、卡片、任务、文档与小组件顺序。放下时只提交一次，取消不写入。

备忘编辑期间若同一正文收到外部修改，保存会提示冲突并保留草稿；先复制草稿，再取消并打开最新内容。无关字段的外部更新可以合并。暂时写入失败时可继续编辑，并在恢复写入后失焦保存最新草稿；本地失败提交不会被当作外部修改。归档待办需确认，先写入配置的固定文件或当天日记，再从看板移除；归档写入失败时保留任务。

## 数据库与文件夹

按文件夹、标签与属性筛选笔记，支持网格、画廊、列表、表格和看板五种视图。工具栏可搜索、排序、切换 S/M/L、选择日期区间、分组或全部折叠。表格可调整列顺序和显隐。分组与看板先显示 50 条，每次追加 50 条，总展示上限 500 条；普通列表使用分页。

点击笔记会打开就地预览，可切换为编辑并保存；也可在设置中选择直接在标签页打开。预览期间外部修改过的内容不会被草稿覆盖。

网格和画廊文件卡上的删除按钮会打开确认框，默认聚焦取消。确认使用 Obsidian 回收站操作。新建笔记支持选择文件夹及多个模板；数据库可预填等值筛选属性，文件名与模板支持标题、日期替换，并避开重名。

## 常用操作

常用操作条按今日、快捷命令、置顶笔记、模板新建和技能按钮排列。每行最多五项，超过时自动增高换行。齿轮可编辑四类列表、图标与排序。图标来自 Obsidian 完整目录，常用置顶、模糊搜索、最多显示 400 项。捕捉框可切换闪念或文件搜索；宽度不足时收起为铅笔按钮。闪念追加到目标笔记开头或末尾，未设目标时按文件夹和模板创建；Shift+Enter 换行。未提交闪念在左右、上下及手机排布切换后保留。手机排布关闭看板及弹层的背景模糊。文件搜索支持方向键、Enter 与 Esc。

## 快捷操作

快捷按钮可打开文件、执行命令或运行已保存的自动化操作。它通过自动化公开接口读取操作，不复制操作定义。

六个 P0 小组件可在设置中分别开关：

| 小组件 | 行为 |
|---|---|
| 快捷按钮 | 文件、命令、已保存自动化操作；右键移除，Alt+方向键排序 |
| 天气 | 城市搜索与经纬度、当前天气与五日预报；开启后使用 Open-Meteo |
| 番茄钟 | 专注/短休/长休、每日目标、暂停/跳过、正计时提醒与迷你面板 |
| 倒计时 | 多条目标日期、天/小时/分钟、提醒提前天数与背景图片 |
| 习惯 | 打卡/撤销、连续天数、添加习惯和补昨天的卡 |
| 记账 | 支出/收入、类别、备注、补录日期、今日收支与净额；设置货币符号 |

计时与记录服务由模块统一持有，多份看板不会创建重复计时器。页面隐藏时停止页面刷新定时器，关闭时释放订阅、观察器和拖拽资源。统计记录页面暂时保留，见[业务记录](records.md)；统计弹窗、P1 分区和沉浸布局属于后续阶段。

## 网页快捷入口

便利贴新增网页快捷卡后，可在编辑对话框填写名称、网址及打开方式：弹窗、NAND 浏览器标签或系统浏览器。
