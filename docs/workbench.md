# 工作台

功能区只有一个 NAND 图标“打开工作台”，同名命令的 ID 是 `open-workbench`。看板、智能体、档案等功能从工作台进入，批注独立位于 Obsidian 侧栏。Obsidian 自带的 **设置 → NAND** 只保留一个简短入口，完整设置在工作台中（见[设置](settings.md)）。

## 三栏布局

| 栏 | 内容 |
|---|---|
| ① 图标栏 | 每个功能一个图标，通知和设置在底部。点击当前功能的图标收起或展开第 ② 栏；点击其他图标回到那个功能上次所在的位置 |
| ② 侧栏 | 由当前功能显式提供对象与分区：智能体会话与历史、档案分组、图标设置分区、设置分类。没有侧栏的功能使用完整页面宽度。条目较多的侧栏带搜索框 |
| ③ 页面 | 标准页头显示位置和“页面操作”菜单；首页、智能体和自动化使用各自的顶部布局。智能体工作区内管理终端和浏览器标签 |

图标栏从上到下依次是：首页、AI Agent、档案、自动化、Git 同步（开启时）、图标、内容；底部是通知（带未读数）和设置。首页和设置始终列出，其他图标在对应功能关闭或当前设备不支持时隐藏。功能启动失败时，它的图标上出现警告点。

键盘：方向键、Home 和 End 在图标栏图标之间移动，F6 与 Shift+F6 在图标栏、侧栏、页面和状态栏之间移动焦点，跳过未显示的区域。

侧栏宽度为 220 到 500 像素（默认 280）。拖动右边缘调整宽度，松开时保存，双击边缘复位；边缘获得焦点后，左右方向键每次调整 8 像素，Home 和 End 跳到上下限。

### 窄窗口

| 容器宽度 | 布局 |
|---|---|
| 960 像素及以上 | 图标栏和侧栏并排显示在页面旁 |
| 600 到 959 像素 | 图标栏保留，侧栏覆盖在页面上 |
| 不足 600 像素，以及手机 | 图标栏与侧栏合成一个抽屉，从页头左侧打开；按 Esc 关闭 |

## 专注模式

“页面操作”菜单中的“在原生标签页中打开”和“在分屏中打开”会新开一个只显示该页面的工作台叶子，没有图标栏和侧栏。它的页头有“在工作台中打开”，可把页面放回完整的工作台。智能体页内的标签和分屏由工作区管理；网页从智能体页的「+」或链接入口打开，见[浏览器](browser.md)。

图标栏的右键菜单也提供这两个入口。从抽屉打开新标签或分屏时，抽屉和菜单先关闭。切换标签使工作台隐藏时，它的抽屉、菜单和用量弹层会关闭；切回后保留页面内容，不重新打开这些弹层。

浏览器标签与终端可在智能体工作区中并排；跨窗口移动网页会重新加载，保留地址、导航历史、个人资料和缩放，不保留页面内临时状态。

## 底部状态

桌面工作台底部有 24 像素状态栏。左侧显示智能体用量，支持详细或精简、已用或剩余；空间不足时先精简，再将提供方折叠到 `+N`。点击用量向上打开面板，可刷新或进入用量详情与账号设置。右侧按顺序显示需要处理的事项，点击后打开相关页面：

- 正在运行的自动化，以及自动化数据加载失败
- 仍未读的、运行失败或被中断的通知
- 工作中或等待输入的智能体会话
- Git 同步：正在执行的操作、冲突、上次同步失败、因连续失败而暂停的自动同步、尚未推送的提交
- 无法保存的看板

右键状态栏可以隐藏各段、选择用量显示方式或隐藏整条状态栏。**设置 → 常规 → 状态栏** 可重新开启；这些偏好保存在库内并在重启后恢复。移动端隐藏底部栏，由页头显示最多三个状态标签。

Obsidian 自带状态栏默认不增加 NAND 项目。常规设置中的“在 Obsidian 状态栏显示精简用量”可独立开启镜像，关闭后立即移除。

## 页面不可用时

页面可能显示一条消息，而不是内容：

- 功能已关闭，数据仍然保留。“在设置中开启”会打开设置。
- 当前设备不支持此功能。
- 功能尚未就绪或启动失败，可点“重试”再试。
- 所选资源已不存在，例如已删除的看板或档案。

## 重启 Obsidian

工作台保存页面、侧栏宽度和每个功能上次的位置。智能体的标签组、分屏比例和标签信息另存于本设备的 `workspace.json`；网页按地址、标题、缩放和个人资料恢复。导航历史仅在当前进程中用于窗口迁移和重试，不跨重启保存。

终端进程不会跨重启存活，也不会自动重放命令。普通终端可点击“重新启动”；具有有效原生会话标识的智能体可点击“恢复会话”，经账号和目录校验后续接。旧版叶子状态与新布局不保证兼容，不提供迁移。失效资源显示明确提示。

## 命令

下面的命令始终可用：

| 命令 | 结果 |
|---|---|
| 打开工作台 | 在当前窗口打开工作台 |
| 切换到下一个主题 | 切换全局样式，见[外观](appearance.md) |
| 复制相对引用、复制绝对引用 | 见[设置](settings.md#复制引用命令) |

各功能的命令在功能开启时可用，列在各自的指南里。
