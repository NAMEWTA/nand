# 首页与设置

日常从功能区唯一的 NAND 图标“打开工作台”进入。工作台里的“首页”是看板。本页的 **设置 → NAND → 首页** 是插件设置（产品 ID `home`），不是工作台首页。

打开 **设置 → NAND → 首页**。首页始终可用，依次显示“通用设置”和“功能模块”。

## 语言

“语言”可选择 **简体中文** 或 **English**。首次使用默认中文，选择保存后立即生效，重启后保留；不跟随 Obsidian 或操作系统语言。保存失败时保留原选择并提示重试。

语言设置影响 NAND 的标题、菜单、按钮、提示和无障碍名称。用户笔记、脚本、提示词、网页、CLI 输出、图标资源名称和中文签文等原文内容不被翻译。切换语言不会重新执行操作或重启运行中的终端。看板关闭后，仍能在首页修改语言。

## 功能模块

首页分别控制浏览器、看板、编辑器、智能体、图标、档案和自动化。模块开关决定服务是否运行，不等同于关闭一个标签页。

关闭看板停止所属服务；关闭智能体会停止其终端进程；关闭浏览器释放页面和本地连接；关闭自动化停止它拥有的运行。停用保留已保存资料。同步目前是预留能力，没有可开启的同步服务。

已开启模块显示各自设置页。首页、自动化与同步入口始终可见；自动化停用时可以查看已有记录。看板布局、主题和小组件属于看板设置；浏览器搜索、档案目录、终端行为和图标规则在各自领域设置中管理。

## 安装与平台

将匹配版本的 main.js、manifest.json、styles.css 放入库的 .obsidian/plugins/nand/ 并启用。最低声明版本为 Obsidian 1.12.0；1.13 起使用声明式设置，旧版使用回退界面，两者共用配置与语言入口。

CLI Agent、Rust PTY 和内置浏览器依赖桌面宿主。手机保留可用的看板、档案等界面，桌面专属入口显示相应状态；网页快捷入口使用系统浏览器。最低版本和各移动平台的实机验证范围见当前开发基线。

配置保存在库内 `.nand/config/settings.json`；备份方法见 [数据与恢复](data.md)。
