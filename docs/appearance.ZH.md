# 外观

外观在工作台 **设置 → 外观** 中调整，同时作用于 Obsidian 界面、笔记（实时预览、源码与阅读模式）和 NAND 自己的页面，主窗口与弹出窗口都生效。修改即时生效，保存在 `.nand/config/settings.json`。Obsidian 的 **设置 → NAND** 里也有“样式”一项。

## 样式

| 样式 | 效果 |
|---|---|
| 跟随系统（默认） | 不做任何修改，完全使用当前的 Obsidian 主题或社区主题 |
| Claude Code | 浅色为象牙白底、深色为炭灰底，陶土橙强调色，衬线标题。标题与加粗使用强调样式 |
| 护眼绿 | 浅色为豆沙绿底、深色为墨绿灰底，对比峰值较低，行高更高（1.75）。标题使用强调样式，加粗使用荧光笔样式 |

Claude Code 和护眼绿各有浅色与深色两套颜色，跟随 Obsidian 的明暗模式切换。正文与背景的对比度不低于 7:1，次要文字和强调色文字不低于 4.5:1。

命令 `NAND: 切换到下一个主题` 按顺序切换这三种样式。

## Markdown 外观

| 设置 | 选项 |
|---|---|
| 标题 | 使用样式默认；强调（一级标题下方有分隔线、二级标题左侧有强调色竖条、三级标题使用强调色，四到六级逐级减小）；朴素（使用主题自己的标题） |
| 加粗文字 | 使用样式默认；强调色；荧光笔；朴素（只加粗） |
| 阅读行高 | 0 表示使用样式默认值，最高 2.2 |

这些设置只改变笔记的显示方式，不会修改笔记内容。

## 强调色

“浅色模式强调色”和“深色模式强调色”替换按钮、链接和选中项的强调色，取值为 `#rrggbb`。未设置时显示当前样式的强调色；点“使用样式强调色”恢复默认。

## 复制、粘贴与重置

- **复制设置**：把当前外观设置以 JSON 复制到剪贴板，可粘贴到另一个库。
- **粘贴设置**：应用从 NAND 复制的外观设置。剪贴板内容不是 NAND 外观设置时不做修改并提示。
- **重置外观**：恢复为“跟随系统”和默认的 Markdown 外观。

## 与社区主题共用

使用社区主题时建议保持“跟随系统”。其他样式会覆盖主题的背景、文字、强调色与标题变量，两者叠加时可能出现不协调的颜色。关闭 NAND 或卸载插件后，它做过的所有外观修改都会撤除。

看板没有单独的配色方案：卡片、小组件和横幅都使用全局颜色。看板的背景图、玻璃模糊、圆角、卡片透明度和字号在 **设置 → 看板 → 看板外观** 中单独调整（见[看板](dashboard.ZH.md#看板外观)）。
