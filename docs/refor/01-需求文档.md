# 01 需求文档（PRD）

## 1 背景

NAND 是一个 Obsidian 插件，把看板、编程智能体终端、内置浏览器、自动化、批注等放进一个三栏工作台。当前版本（0.0.2-alpha.1）功能齐全，但用户反馈了七个问题：

1. 首页看板的交互、布局、盘板没有照搬 apex-dashboard，组件也很丑。
2. 终端的新建逻辑、用量识别、智能体管理、统计、底部状态栏都不像 Orca。
3. 浏览器应该属于终端/智能体，和 Orca 一样在「+」里新建；需要默认搜索引擎、会话与 Cookie 导入；不要本地外接。
4. 自动化也要照搬 Orca；浏览器、自动化、终端的页面版式要和 Orca 一致；不要 SSH 等。
5. 新闻要彻底删除。
6. 批注要在右侧栏有图标，点开能看；悬停批注能弹出查看和编辑。
7. 要用成熟的 UI 组件库，统一风格、组件、字体。

## 2 目标与非目标

### 2.1 目标

| 编号 | 目标 | 衡量方式 |
|---|---|---|
| G1 | 首页看板在布局、交互、主题上与 apex-dashboard v3.8.4 一致 | 对照 apex 截图和功能清单逐项验收（第 6.3 节） |
| G2 | 智能体工作区的版式、新建流程、状态、用量、状态栏与 Orca 一致 | 对照 Orca 截图与功能清单验收（第 6.4～6.6 节） |
| G3 | 浏览器成为工作区标签，支持搜索引擎、Profile、Cookie 导入 | 第 6.7 节 |
| G4 | 自动化页与 Orca 一致 | 第 6.8 节 |
| G5 | 批注可从右侧栏图标进入、悬停查看编辑 | 第 6.9 节 |
| G6 | 新闻模块与浏览器扩展功能被完整删除，无残留引用 | 第 6.10 节的检索命令返回空 |
| G7 | 全部 NAND 界面使用同一套组件、令牌和字体 | 第 6.1 节；随机抽查 10 个界面无旧原语 |

### 2.2 非目标

- 不兼容旧数据格式，不写迁移代码（旧文件保留在磁盘）。
- 不实现 Orca 的 worktree、SSH、远程主机、移动伴侣、GitHub/Linear/Jira、代码编辑器、diff 审阅、CLI、Computer Use、语音、插件市场、Artifacts、浮动终端。
- 不让终端会话活过 Obsidian 重启（只恢复布局和“可恢复”入口）。
- 不改插件 id、不改仓库为网页应用。

## 3 用户与场景

**主要用户：** 一位在 Obsidian 里管理个人知识库，同时用 Claude Code、Codex 等 CLI 智能体处理库内文件的人。中文界面为主，偶尔切英文。桌面端为主，手机只看看板。

| 场景 | 现在的痛点 | 重构后 |
|---|---|---|
| 每天打开首页 | 布局与 apex 不同，控件丑，入口分散在侧栏和按钮上 | 和 apex 一样：横幅 → 左侧小组件 → 常用操作条 → 分区 |
| 开一个 Claude Code 干活 | 要在侧栏点“新建会话”菜单 | 在标签条右侧点「+」，输入 `claude` 回车，或点列表里的 Claude Code |
| 查额度够不够 | 要进“用量”页面 | 底部状态栏常驻 `Claude ▬ 78% 5h · 94% 周`，点击看全部智能体 |
| 让智能体看一个网页 | 浏览器在另一个图标里 | 「+」里粘贴网址回车，网页作为标签和终端并排，可以抓取元素附加给智能体 |
| 登录网站 | 每个 Profile 都要重新登录 | 从本机 Chrome/Edge 导入 Cookie |
| 夜里定时跑一个智能体任务 | 自动化页面是自研样式 | Orca 式表格，新建对话框里写提示词、选智能体和时间 |
| 给笔记某一行写批注 | 只能选中文字再评论，面板要用命令打开 | 鼠标靠近行首点批注图标；右侧栏一点就看；悬停高亮直接编辑 |

## 5 功能需求总览

需求编号规则：`FR-<区域>-<序号>`。区域缩写：UI 设计系统、SH 外壳、ST 状态栏、AG 智能体工作区、US 用量、AM 智能体管理、BR 浏览器、AU 自动化、CM 批注、HM 首页看板、RM 删除、SE 设置、NF 非功能。

每条需求都有验收标准（AC）。验收方法分三类：**[自测]** 实现者在开发库里手动确认；**[单测]** 有自动化测试；**[实机]** 在真实 Obsidian 桌面端（Windows 或 Linux 至少一个）确认。

## 6 功能需求详述

### 6.1 设计系统（UI）

**FR-UI-01 统一组件库。** 所有 NAND 自绘界面使用 `src/ui/components/` 中的 shadcn 风格组件（Button、Input、Textarea、Select、Switch、Checkbox、Tabs、Tooltip、Popover、HoverCard、DropdownMenu、ContextMenu、Dialog、AlertDialog、Sheet、Command、ScrollArea、Separator、Badge、Card、Progress、Slider、ToggleGroup、Collapsible、Skeleton、Table、Sonner）。

- AC1 [自测] 在项目里搜索 `ui/primitives/`，除被删除的旧文件外无引用。
- AC2 [自测] 任一页面的按钮、输入框、下拉、弹窗、菜单、提示在外观上一致（同高、同圆角、同字体）。

**FR-UI-02 主题跟随。** 组件颜色来自令牌，令牌由 Obsidian 变量派生。

- AC1 [实机] 切换 Obsidian 亮/暗色，NAND 所有界面立即跟随，无需刷新。
- AC2 [实机] 安装一个社区主题（如 Minimal），主色、背景、边框跟随主题。

**FR-UI-03 样式隔离。** NAND 样式不影响 Obsidian 其他界面；Obsidian/社区主题的表单样式不影响 NAND 组件。

- AC1 [实机] 打开 NAND 前后，Obsidian 设置页、文件列表、编辑器外观无变化。
- AC2 [单测] 样式验证脚本（《测试与验收》§3）检查 Button/Input/Textarea 在亮/暗主题下的常态、悬停、聚焦计算样式符合预期。

**FR-UI-04 统一字体。** 界面字体为 Geist + 中文系统字体；等宽为 Geist Mono；设置中可切换为“跟随 Obsidian”。

- AC1 [实机] 开发者工具中任意 NAND 文字的 `font-family` 首项为 Geist（或用户选择的 Obsidian 字体）。

**FR-UI-05 弹出窗口。** NAND 页面移到 Obsidian 弹出窗口后，菜单、弹窗、提示出现在同一个窗口里。

- AC1 [实机] 把工作台拖到新窗口，打开「+」菜单、右键菜单、对话框，均显示在新窗口。

**FR-UI-06 可访问性。** 所有可点击元素可用键盘到达，有可见焦点环和可读名称；遵守“减少动效”。

- AC1 [自测] 只用 Tab/方向键/Enter/Esc 可以完成：新建终端、关闭标签、打开设置。
- AC2 [自测] 系统开启减少动效后，弹窗不做缩放动画。

### 6.2 工作台外壳（SH）

**FR-SH-01 图标轨。** 顺序：首页、智能体、档案、自动化、Git 同步、图标；底部：通知（未读数）、设置。模块关闭时隐藏对应图标；启动失败显示警告点。

- AC1 [自测] 图标轨中不出现浏览器、新闻、批注、记录。
- AC2 [自测] 关闭「档案」模块后其图标消失，重新开启后出现。

**FR-SH-02 页面外框。** 页面可声明 `chrome: 'none'`，此时不显示 44px 页头，由页面自己绘制顶部栏；首页、智能体工作区、自动化使用 `'none'`。

- AC1 [自测] 首页最顶部直接是横幅；智能体页最顶部直接是标签条；自动化页最顶部是“自动化”标题栏。

**FR-SH-03 侧栏可选。** 功能未提供侧栏时不显示第 2 栏；提供时可折叠、拖动调宽（220～500px）。

- AC1 [自测] 首页、自动化没有第 2 栏；智能体有。

**FR-SH-04 窄窗口。** 宽 ≥960px 三栏并排；600～960px 侧栏浮层；<600px 或手机，图标轨与侧栏合并为抽屉。

- AC1 [自测] 把工作台拖窄，布局按上述三档切换；Esc 关闭浮层/抽屉。

**FR-SH-05 专注模式。** 页面菜单「在新标签页打开 / 在分屏中打开」仍可用，打开的叶子没有图标轨和侧栏。

**FR-SH-06 恢复。** 重启 Obsidian 后，工作台恢复上次所在功能、侧栏宽度、各功能的上次位置。

### 6.3 底部状态栏（ST）

**FR-ST-01 位置与外观。** 工作台底部一条 24px 横条，上边框，`text-xs`。左侧为用量区，右侧为状态段。照抄 Orca `StatusBarSurface`。

- AC1 [自测] 所有 NAND 页面底部都有状态栏（可在设置中整体隐藏）。

**FR-ST-02 用量区。** 每个已启用且支持额度的智能体一个片段：图标、迷你进度条（详细模式）、各窗口百分比（如 `78% 5h · 94% 周`）；超过 80% 显示警告色，超过 95% 显示危险色；宽度不够时右侧片段折叠为 `+N` 芯片；旁边有刷新按钮。

- AC1 [自测] Claude 登录后显示 5 小时和每周百分比；未登录显示“未登录”。
- AC2 [自测] 拖窄窗口，片段依次折叠为 `+1`、`+2`。

**FR-ST-03 用量面板。** 点击用量区弹出 360px 宽的面板：标题“用量”、“全部智能体”、刷新；“详细 / 精简”分段切换；按最紧张程度排序的提供方行；底部“用量详情与历史 ›”“管理账号… ›”。Claude、Codex 行可展开子菜单切换账号。

- AC1 [自测] 面板中点击“用量详情与历史”打开用量统计页。

**FR-ST-04 状态段。** 右侧依次：运行中的智能体数（转圈）、等待输入数（橙色 ?）、运行中的自动化数、Git 同步状态（有冲突/未推送/失败时）、通知未读数。点击跳转到对应页面。

**FR-ST-05 右键显隐。** 在状态栏右键弹出菜单，可勾选显示/隐藏：用量、各状态段；选择用量显示“已用 % / 剩余 %”。

**FR-ST-06 Obsidian 状态栏镜像（可选）。** 设置开启后，在 Obsidian 自己的状态栏显示精简用量（默认关闭）。

### 6.4 智能体工作区（AG）

**FR-AG-01 版式。** 侧栏（Orca 左栏）+ 页面（标签条 + 内容区，可分屏）+ 可开关的右侧面板（会话历史）。详见《设计-智能体工作区》。

**FR-AG-02 侧栏导航。** 顶部：搜索（打开跳转面板）、智能体看板、自动化、用量统计；下面「会话」区，按「需要处理 / 运行中 / 已完成 / 浏览器」分组，组可折叠；标题右侧有「+」（同标签条「+」）和筛选菜单。

- AC1 [自测] 智能体进入等待输入状态时，它的卡片移到“需要处理”组并显示橙色问号。

**FR-AG-03 会话卡片。** 状态图标、标题（会话名或 CLI 名）、第二行：智能体图标 · 工作目录短路径 · 相对时间；悬停显示「⋯」，右键菜单：重命名、复制会话 ID、在分屏打开、结束会话、关闭。

**FR-AG-04 标签条。** 每个标签组顶部一条标签条，高约 36px；标签宽 180px（宽屏 220px）、最窄 72px；显示前导图标（智能体图标/终端图标/网站图标）、状态图标、标题、关闭按钮；当前标签底部 2px 指示线；可拖动排序，可拖到其他组，拖到内容区边缘创建分屏；中键关闭；溢出时出现左右滚动箭头。

- AC1 [自测] 拖动标签到内容区右边缘，出现左右分屏。
- AC2 [自测] 中键点击标签关闭它；运行中的会话关闭前确认。

**FR-AG-05 「+」新建菜单。** 标签条右端「+」打开 288px 宽的菜单：

1. 顶部输入框，占位“搜索已打开的标签、网址、智能体…”；输入时实时匹配：已打开标签、新建动作（终端/浏览器）、智能体、网址/本地地址、搜索词（用默认搜索引擎）、浏览历史；`?` 前缀强制搜索；↑↓ 选择，Enter 执行；输入为空直接 Enter 打开默认终端。
2. 分隔线后：新建终端（Ctrl/Cmd+T）、新建浏览器标签；Windows 上新建终端展开为 PowerShell / CMD / Git Bash / WSL 等多项。
3. 分隔线后：已检测并启用的智能体列表（默认智能体排第一，带快捷键提示），没有时显示“未检测到智能体”；最后“智能体设置…”。

- AC1 [自测] 输入 `claude` 回车，在当前组新开 Claude Code 标签并聚焦终端。
- AC2 [自测] 输入 `example.com` 回车，新开浏览器标签访问 `https://example.com/`。
- AC3 [自测] 输入 `obsidian 插件 开发` 回车，用默认搜索引擎搜索。
- AC4 [自测] 输入 `localhost:3000` 回车，访问 `http://localhost:3000/`。

**FR-AG-06 终端标签。** 内容为 xterm 终端，沿用现有终端能力（键盘协议、括号粘贴、链接、Shell 集成、查找、右键菜单）。标签内可再左右/上下分屏（最多 4 个窗格），窗格之间可拖动分隔线。

**FR-AG-07 智能体状态。** 状态来自 CLI 生命周期 Hook：工作中（转圈）、等待输入（橙色 ?）、已完成（绿色 ✓，侧栏为绿点）、失败/中断（红点）、空闲（灰点）、普通 Shell（无图标）、状态未知（虚线圈）。已完成但未查看的标签显示琥珀色铃铛，查看后消失。

**FR-AG-08 退出与重启芯片。** 智能体进程退出后，标签内显示“已退出”遮罩和「重新启动」按钮（相同智能体、相同目录、相同账号）。

**FR-AG-09 会话历史面板。** 右侧面板，照抄 Orca Agent Session History：顶部“N 条显示 · M 条最近”、搜索框、范围（本库 / 全部）、视图菜单（按智能体筛选、排序、分组、隐藏空会话）；行点击展开详情（目录、模型、消息数、首条提示词、最近几轮）；操作：恢复、复制恢复命令、复制会话 ID、打开日志、导出为笔记、收藏、归档。

**FR-AG-10 智能体看板。** 侧栏「智能体看板」打开看板页：需要处理 / 运行中 / 已完成 / 空闲（默认隐藏，在看板设置里开）；卡片：智能体图标、会话名、状态、最近一条消息预览、目录、时长；点击卡片切到对应标签；搜索与智能体筛选。

**FR-AG-11 快捷命令。** 标签条右侧「▶ 快捷命令 ⌄」分体按钮：点主按钮运行上次用过的命令（新开终端标签执行），点箭头列出全部快捷命令（全局 / 本库），末尾“添加命令…”；终端右键菜单也可“插入快捷命令”。快捷命令可以是终端命令，也可以是“带提示词启动智能体”。

**FR-AG-12 重启后恢复。** 见决策 D14。重启后标签布局恢复；智能体标签显示“会话已结束”与「恢复会话」按钮；浏览器标签按需加载。

**FR-AG-13 键盘。** Ctrl/Cmd+T 新终端；Ctrl/Cmd+Shift+T 重新打开关闭的标签；Ctrl/Cmd+W 关闭标签；Ctrl+Tab 最近标签；Ctrl/Cmd+Shift+] / [ 下/上一个标签；Ctrl/Cmd+\ 向右分屏；Ctrl/Cmd+Shift+\ 向下分屏；Ctrl/Cmd+J 跳转面板。快捷键只在焦点位于智能体工作区时生效，并可在 Obsidian 快捷键设置中通过命令重新绑定。

### 6.5 用量与统计（US）

**FR-US-01 读取方式。** 沿用现有读取器：Claude（OAuth 用量接口）、Codex、Gemini、Grok、OpenCode；按账号隔离；最少 60 秒刷新一次，手动刷新立即读取；失败时保留上次结果并标记过期。

### 6.7 浏览器（BR）

**FR-BR-01 浏览器标签。** 浏览器页面是工作区标签；标签显示网站图标、标题、加载中转圈、关闭；`target=_blank` 链接和普通弹窗在新标签打开（同 Profile）；登录类具名弹窗仍为独立窗口。

**FR-BR-02 工具栏。** 一行：后退、前进、刷新（加载中变停止；右键：刷新 / 强制刷新）、地址栏（占满剩余宽度）、Cookie 导入提示按钮（Profile 无 Cookie 时）、抓取元素、标注元素、截图标注、开发者工具、在系统浏览器打开、「⋯」。窄时工具按顺序折叠进「⋯」。

**FR-BR-03 地址栏。** 显示当前地址；聚焦时全选；输入时下拉建议（浏览历史模糊匹配、搜索建议行）；输入规则：

| 输入 | 结果 |
|---|---|
| 空 | 打开空白页 |
| `localhost`、`127.x.x.x`、`0.0.0.0`、`[IPv6]`（可带端口路径） | `http://` |
| 绝对文件路径 | `file://`（仅本机预览） |
| `域名:端口` | `https://` |
| 带协议的 http/https/file 地址 | 原样 |
| 单个词含点且后缀像域名（`a.com/x`） | `https://` |
| 含空格，或不含点和冒号 | 默认搜索引擎搜索 |
| `javascript:`、`data:` 等其他协议，带用户名密码的地址 | 拒绝 |

**FR-BR-04 默认搜索引擎。** 设置 → 浏览器：Google（默认）、Bing、百度、DuckDuckGo、自定义（模板含 `%s`）。

**FR-BR-05 主页与缩放。** 默认主页（新浏览器标签打开的地址，空则空白页）；默认缩放（新标签生效，每个标签可单独 Ctrl+滚轮调整）。

**FR-BR-06 Profile。** 默认 Profile + 用户新建的 Profile；每个 Profile 独立 Cookie、存储、缓存（目录在 `.nand/browser/<device>/profiles/<id>/session/`）；工具栏「⋯」中切换当前标签的 Profile（切换后重载）；设置页可新建、重命名、删除（删除前列出受影响标签）、设为默认、清除 Cookie。

**FR-BR-07 Cookie 导入。** 「⋯ → 导入 Cookie ▸」列出检测到的浏览器（Chrome、Edge、Brave、Arc、Chromium、Firefox），有多个用户资料时再展开二级菜单；另有“从文件…”（Netscape `cookies.txt` 或 JSON 导出）。只替换导入域名下的旧 Cookie；`google.com` 系列 Cookie 不导入并提示“请直接在 NAND 中登录 Google”；结果提示“已从 Chrome（个人资料 1）导入 312 个 Cookie 到 默认”。

- AC1 [实机] 在 Chrome 登录某网站后导入，NAND 浏览器打开该网站已是登录状态。

**FR-BR-08 下载。** 工具栏下方下载栏，显示进行中和最近完成的下载：进度、取消、打开文件、在文件夹中显示、移除；文件保存到 Profile 的 `downloads/`。

**FR-BR-09 查找与缩放。** Ctrl/Cmd+F 打开页内查找（上一个、下一个、匹配数、Esc 关闭）；Ctrl/Cmd+加/减/0 缩放，缩放比例在工具栏短暂显示。

**FR-BR-10 视口模拟（P2）。** 「⋯ → 视口大小 ▸」默认 / 预设机型。

**FR-BR-11 元素抓取与标注。** 抓取：悬停高亮、点击采集文字/选择器/HTML 摘要/样式/截图，弹出预览，可复制或“附加到智能体 ▸”（列出运行中的智能体会话），附加内容以粘贴形式进入输入框、不自动发送。标注：在元素上写一句说明再附加。截图标注：画笔、高亮、箭头、矩形、椭圆、文字、撤销重做。

**FR-BR-12 链接路由。** 设置：终端和笔记里的 http(s) 链接在「NAND 浏览器 / 系统浏览器」打开；按住 Shift+Ctrl/Cmd 点击反向。终端链接单击弹出小菜单：在 NAND 浏览器打开、在系统浏览器打开、复制链接（可关闭此弹出菜单）。

**FR-BR-13 站点权限。** 敏感权限默认拒绝；地址栏左侧盾牌按钮按站点授权摄像头、麦克风、位置、通知、剪贴板读取、全屏。

**FR-BR-14 加载失败。** 失败时内容区显示错误遮罩：错误说明、重试、在系统浏览器打开。

**FR-CM-07 阅读模式。** 阅读视图中有批注的文字同样高亮，点击打开浮窗（P2）。

**FR-CM-08 锚点。** 编辑、移动、重命名笔记后批注跟随；找不到时标为“已脱离”。

**FR-CM-09 命令。** 为选区添加批注、打开批注面板、下一条批注、上一条批注、解决本笔记全部批注（需确认）。

## 7 非功能需求（NF）

| 编号 | 需求 | 验收 |
|---|---|---|
| NF-01 启动性能 | 插件启动时静态加载的代码不超过预算（`eagerBytes`，React 运行时不进入启动集合，首次打开工作台时才加载） | `pnpm run check:bundle` 通过 |
| NF-02 页面切换 | 已打开过的页面切换不重建；首次打开智能体工作区 < 500ms（不含进程启动） | 开发者工具 Performance 记录 |
| NF-03 终端性能 | 隐藏的终端保留最多 2 个 WebGL 上下文（沿用现有 LRU）；不可见标签不渲染 | 打开 10 个终端无明显卡顿 |
| NF-04 内存 | 关闭标签释放 xterm、webview 与 React 子树 | 开关 20 次标签后内存回落 |
| NF-05 国际化 | 所有新文案 `t()` 且有 en/zh | `pnpm test:i18n` 通过 |
| NF-06 无障碍 | 见 FR-UI-06 | 自测 |
| NF-07 弹出窗口 | 见 FR-UI-05 | 实机 |
| NF-08 移动端 | 看板、批注面板在手机可用；智能体工作区、浏览器、自动化中的终端/浏览器动作仅桌面 | 手机或移动模拟 |
| NF-09 数据位置 | 所有新数据在 `.nand/` 下，不写插件目录、不写全局目录 | 代码审查 + `pnpm test:architecture` |
| NF-10 隐私 | Cookie 导入只在用户操作后读取其他浏览器数据；不上传任何数据；凭据不写日志 | 代码审查 |
| NF-11 可靠性 | 写文件走现有原子写与写队列；失败有提示且不丢用户输入 | 单测 + 自测 |
| NF-12 代码规范 | `pnpm run lint` 零警告；`pnpm run build` 通过；架构检查通过 | CI |

| Obsidian/社区主题 CSS 污染组件 | 组件外观错乱 | D03 方案 + 中和层；遇到新冲突在中和层补规则（《常见问题与排错》Q1） |
