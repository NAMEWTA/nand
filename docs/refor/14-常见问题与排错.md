# 14 常见问题与排错

按“现象 → 原因 → 解决”组织。先用 `Ctrl+Shift+I` 打开开发者工具，看 Console 报错和元素的 Computed 样式。

## 样式

### Q1 组件样式不对，像是 Obsidian 的按钮/输入框样式

- **检查 1：** 元素或它的某个祖先有没有 `nand-ui` 类？没有的话，所有 Tailwind 工具类都不会生效。`ReactSurface` 会自动加；自己 `createRoot` 的地方要手动加。
- **检查 2：** 弹层（菜单、对话框）是不是渲染到了 `document.body`？应该用 `usePortalContainer()` 渲染到 `.nand-portal-root`。
- **检查 3：** 构建产物里有没有这个类？在 `styles.css` 里搜（比如 `.h-9:is(`）。没有 → 见 Q2。
- **检查 4：** Computed 面板里胜出的规则是谁？
  - 是 `neutralize.css` 本该生效却没生效（按钮还是 Obsidian 的白底和阴影）：先看选择器是不是被拆成了多行。`:is(...)` 与 `:not(...)` 之间的空格或换行会变成后代选择器，整条规则失效（《架构文档》§5.4）。
  - Obsidian 或社区主题的规则胜出，而且它带 ID 选择器（特异性 ≥ (1,0,1)，与中和层相同或更高）：在 `neutralize.css` 补一条更具体的规则（保持 ≤ (1,1,x)，达到 (1,2,0) 就会压过工具类）。
  - 是 `!important`：只能在组件上加一个带 `!important` 的局部类，并在代码里写明原因。
- 跑 `pnpm test:ui-styles` 复现。

### Q2 新写的 Tailwind 类不生效

- `pnpm dev` 有没有在跑？它同时监听 esbuild 和 Tailwind。只跑了 `node esbuild.config.mjs` 时 CSS 不会更新 → 运行 `pnpm run build:css`。
- 类名是不是拼接出来的？Tailwind 只能识别**源码里完整出现的字符串**。`'text-' + color` 不会被生成；要写成映射表：`{ red: 'text-red-500', … }[color]`。
- 文件在不在 `@source` 扫描的目录里（`src/shell`、`src/ui`、`src/modules`、`src/app`）？
- 构建时看到 `DeprecationWarning: module.register() is deprecated`（DEP0205）：这是 Tailwind CLI 在 Node 26 上的提示，不影响产物，可以忽略，和类不生效无关。

### Q3 字号类被吃掉了（`text-2xs` 加上颜色类后消失）

`cn()` 里的 tailwind-merge 不认识自定义字号。确认 `src/ui/lib/utils.ts` 用了 `extendTailwindMerge({ extend: { theme: { text: ['2xs', '3xs'] } } })`（《设计系统》§13）。

### Q4 暗色主题下某处白底白字

- 用了 `bg-white`、`text-black` 这类字面颜色 → 换成令牌类（`bg-background`、`text-foreground`）。
- 看板里的弹窗：弹窗在 Portal 根里，不在看板根下，拿不到 `--db-*` 变量 → 给 `DialogContent` 加 `nand-dashboard-root` 类和 `data-theme`（《设计系统》§9）。

### Q5 手机上看板卡顿或闪退（尤其 iOS）

移动端关闭所有 `backdrop-filter`（毛玻璃）：apex 1.6.3 因此在 iOS 上崩溃过。在看板主题 CSS 里加 `.is-mobile .nand-dashboard-root { --db-backdrop-blur: none; }`，并且不要在移动端使用 `backdrop-blur-*` 工具类。

## React 与生命周期

### Q6 报错 “Invalid hook call” 或 “Cannot read properties of undefined (reading '__H')”

React 与 Preact 混用了：

- 文件开头有 `/** @jsxImportSource preact */` 却 `import { useState } from 'react'`，或者反过来。一个文件只能用一种。
- 确认 `scripts/esbuild-options.mjs` 里**没有** `react → preact/compat` 的别名（阶段 2 已删除）。
- 新文件默认是 React，不要加 Preact 注释。

### Q7 页面切走再切回，状态丢了 / 重新请求数据

页面隐藏时外壳调用 `setVisible(false)`，**不会卸载**。如果你在 `setVisible` 里卸载了 React 根，或者组件根据 `visible` 返回了 `null`，内部状态就没了。隐藏时只暂停动画和轮询。

### Q8 关闭模块后控制台还在打印 / 监听器没释放

- `ReactSurface.onClose` 必须 `root.unmount()`。
- 订阅（`store.subscribe`、`onLanguageChanged`、Obsidian 事件）放在 `useEffect` 里并返回取消函数；服务层的订阅登记到 `context.lifetime`。
- 编辑器扩展、命令必须通过 `context.editor`、`context.commands` 注册（模块停用时自动移除）。

### Q9 菜单/对话框出现在主窗口而不是弹出窗口

Portal 容器取错了 `document`。`NandProviders` 以页面根元素的 `ownerDocument` 创建 Portal 根；组件里不要直接用全局 `document`，用 `useOwnerDocument()`。

## 终端与浏览器

### Q10 终端切换标签后空白、尺寸错乱或闪烁

- 不要因为标签不活动就卸载 `TerminalHost`；用 `hidden` + `inert` 隐藏。
- 变为可见后要触发一次尺寸适配（现有 `stable-terminal-fit.ts`），因为隐藏期间测量到的尺寸是 0。
- 同时可见的 WebGL 终端很多时，现有的 `HiddenRendererRetention` 只保留 2 个隐藏的 WebGL 上下文，其余回退 DOM 渲染——这是预期行为。

### Q11 网页每次切换标签/分屏都重新加载

`<webview>` 被移动到了别的父节点。Electron 的 webview 一旦从 DOM 摘下再插入就会重载。必须用“保留层 + 占位元素同步位置”的做法（《架构文档》§10.1）。只有移动到另一个 Obsidian 窗口时重载是不可避免的。

### Q12 网页盖住了菜单或对话框

保留层宿主的 `z-index` 太高。网页宿主应在普通内容层级（不设或很低的 z-index），NAND 弹层用 `--layer-menu`/`--layer-modal`，自然在它之上。

### Q13 快捷键（Ctrl+T 等）没反应，或者被终端吃掉

- Obsidian 自己也用 Ctrl+T（新标签页）。NAND 的处理只在焦点位于智能体工作区内时 `preventDefault`。
- 焦点在终端里时，xterm 先拿到按键：在 `terminal-view.ts` 的 `attachCustomKeyEventHandler` 里对这些组合返回 `false`（让事件冒泡到工作区）。
- 所有快捷键也注册成 Obsidian 命令，用户可在“设置 → 快捷键”自定义。

### Q14 中文输入法打字时回车把内容提交了

输入框没加 IME 保护。所有 `Input`/`Textarea` 都要在 `compositionstart`～`compositionend` 期间忽略 Enter（`e.nativeEvent.isComposing` 为真时直接返回）。用组件库里的 `Input`/`Textarea`，不要直接用原生 `<input>`。

## 智能体

### Q15 「+」菜单里显示“未检测到智能体”，但我装了 Claude Code

- Obsidian 从桌面图标启动时，进程的 PATH 往往不包含 `~/.local/bin`、nvm、Homebrew 等目录。检测会先读取登录 Shell 的 PATH；到 设置 → 智能体 点“刷新”。
- 仍然检测不到：在该智能体行展开，填“命令覆盖”为可执行文件的绝对路径（`which claude` 的输出）。
- Windows：确认 `claude.cmd`/`claude.exe` 所在目录在用户 PATH 中，修改 PATH 后需要重启 Obsidian。

### Q16 智能体状态一直是“状态未知”

- 设置 → 智能体 → 状态 Hook 是否开启。
- Codex 会要求用户在 CLI 里用 `/hooks` 审查新增的 Hook，审查前不生效（NAND 不会跳过这一步）。
- 没有原生生命周期事件的 CLI 只能显示“状态未知”——这是设计（输出停顿从不被当作完成）。

### Q17 状态栏用量显示“未登录”或“已过期”

NAND 的智能体账号是**库内隔离**的（`.nand/agents/<device-id>/accounts/…`），不会读取全局的 `~/.claude`。在 NAND 里新建该智能体的终端标签完成登录后再刷新用量。

## 浏览器 Cookie 导入

### Q18 导入时 macOS 弹出钥匙串对话框

正常现象：Chrome 的 Cookie 加密密钥存放在钥匙串的“Chrome Safe Storage”里，需要你点“允许”。点“拒绝”会导致导入失败，NAND 会提示原因。

### Q19 Windows 上从 Chrome 导入，提示大量 Cookie 无法解密

Chrome 127 起在 Windows 上对 Cookie 使用“应用绑定加密”（值以 `v20` 开头），只有 Chrome 自己能解密，DPAPI 解不开。NAND 会提示“有 N 个 Cookie 使用了 Chrome 应用绑定加密”。解决：在 Chrome 里用 Cookie 导出扩展导出 `cookies.txt`，然后用“从文件…”导入；或者改从 Edge/Brave/Firefox 导入（视其版本而定）。

### Q20 Linux 上导入失败或只导入了一部分

Chrome 在有系统钥匙环时用 v11 加密，密钥要通过 `secret-tool` 读取。没有安装 `libsecret-tools`（提供 `secret-tool`）或钥匙环未解锁时，v11 的 Cookie 无法解密。安装 `libsecret-tools` 并解锁钥匙环后重试。

### Q21 Google 账号导入后仍要求登录

设计如此：Google 会把会话绑定到来源浏览器，转移过来的 Cookie 会被强制登出，所以 NAND 不导入 `google.com` 系列 Cookie。请直接在 NAND 浏览器里登录 Google（浏览器标识用“精简”模式）。

## 批注

### Q22 悬停高亮文字没有弹窗

- 批注模块开着吗？编辑器扩展只在模块激活时注册。
- 高亮元素的类名必须是 `nand-comment-hl`（悬停委托按类名识别）。
- 每个窗口要有一个 `CommentsOverlay` 根；弹出窗口里的编辑器找不到 Overlay 时不会弹出。
- 悬停延迟是 350ms，移动太快不会触发（设计如此）。

### Q23 改了笔记后批注“已脱离”

锚定的文字被大幅修改或删除（编辑距离超过容差）。在面板里点“重新挂上”，在编辑器选中新位置确认。容差可在设置里调大（最多 0.5）。

## 构建与检查

### Q24 `pnpm run check:bundle` 超预算

- 大库（chart.js、xterm、Radix 的大组件）要放在 `import()` 之后懒加载。
- `pnpm run check:bundle --files` 列出启动集合里每个文件的大小，找出被静态导入的大文件。
- 确实需要上调时，在 `scripts/bundle-budget.json` 对应的 `*Reason` 字段写明：日期、原因、实测值。

### Q25 `pnpm test:architecture` 报“跨区导入”

看《架构文档》导入矩阵：`core/` 不能导入 React；`ui/` 不能导入别的模块内部（只能导入对方 `api.ts`）；`desktop/` 之外不能用 Node 内置模块。常见修法：把类型移到 `api.ts`，把 Node 代码移到 `platform/desktop/`。

### Q26 测试里 Radix 组件报 `ResizeObserver is not defined` / 指针事件错误

`happy-dom` 缺少部分 API。在 `dom` 测试项目的 setup 文件里补：

```ts
globalThis.ResizeObserver ??= class { observe() {} unobserve() {} disconnect() {} };
Element.prototype.hasPointerCapture ??= () => false;
Element.prototype.scrollIntoView ??= () => {};
```

### Q27 `pnpm test:ui-styles` 显示“跳过”

找不到 Chrome 或 Obsidian 安装目录。用参数指定：`node scripts/verify-ui-styles.mjs --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --obsidian "%LOCALAPPDATA%\Programs\Obsidian"`。

## 数据

### Q28 换了一台电脑，浏览器登录和智能体登录都没了

`.nand/` 是点目录，Obsidian Sync 不同步；即使用 Git/Syncthing 同步了，浏览器会话和 CLI 凭据跨设备也可能失效（NAND 按设备隔离）。在新设备上重新登录即可。

### Q29 旧版本的看板、批注、设置不见了

本次重构不兼容旧格式（《决策记录》D01）。旧文件仍在磁盘上（`.nand/` 下），新版本不读取。需要的内容请手动迁移。
