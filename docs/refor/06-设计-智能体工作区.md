# 06 设计：智能体工作区（照搬 Orca）

图标轨「智能体」打开的页面（内部功能 id `terminal`）。它把 Orca 主窗口搬进 Obsidian：左栏是会话，中间是可分屏的标签组（终端、智能体、浏览器），右侧是会话历史，底部是外壳的状态栏（用量）。本文覆盖终端、新建逻辑、智能体状态、会话历史、智能体看板、用量统计、快捷命令和智能体管理。浏览器标签的内部见《设计-浏览器》。

## 2 左栏（照抄 Orca Sidebar）

### 2.1 头部与导航

- 头部 `h-9 px-3`：标题“智能体”（`text-sm font-semibold`）+ 右侧收起按钮 `⇤`（`panel-left-close`）。
- 导航区 `flex flex-col gap-0.5 px-2 pt-2 pb-1`：
  1. **搜索按钮**：`rounded-md bg-foreground/5 px-2 py-1.5 text-[13px] font-medium text-foreground/60`，左图标 `Search`（`size-4 text-foreground/30 strokeWidth 1.75`），右侧悬停时显示快捷键芯片 `Ctrl J` / `⌘J`。点击打开跳转面板（§11）。
  2. **智能体看板**（`LayoutDashboard`）→ 页面切到看板视图（§8）。
  3. **自动化**（`Timer`）→ 跳到自动化功能（外壳导航）。
  4. **用量统计**（`ChartNoAxesColumn`）→ 页面切到统计视图（§9）。
  - 导航项样式：`flex w-full items-center gap-2 rounded-md px-2 py-1.5 text-[13px] font-medium`；未选中 `text-sidebar-foreground/60 hover:bg-sidebar-foreground/8`，图标 `text-sidebar-foreground/30 strokeWidth 1.75`；选中 `bg-sidebar-accent text-sidebar-accent-foreground`，图标 `strokeWidth 2.25`。
  - 右键导航项：「隐藏此入口」（设置里可恢复）。

### 2.2 会话区

- 区标题行：`会话`（`text-2xs font-semibold uppercase tracking-wide text-muted-foreground`）+ 右侧两个图标按钮：
  - `⚲` 筛选菜单（`ListFilter`）：勾选“显示终端”“显示浏览器标签”“显示已完成”“显示空闲（超过 30 分钟无动静）”；单选“分组：按状态 / 按智能体 / 不分组”；“清除筛选”。有生效的筛选时按钮右上角显示数字。
  - `＋`：与标签条「+」相同的新建菜单（§4），在当前活动组新建。
- 分组（按状态时，从上到下）：**需要处理**（等待输入/需要权限）、**运行中**（工作中）、**已完成**（完成未读或最近 30 分钟完成）、**空闲**（默认隐藏）、**终端**（普通 Shell）、**浏览器**。每组标题可折叠（`ChevronDown` 旋转），显示数量；空组不显示。

## 4 「+」新建菜单（核心交互）

照抄 Orca `tab-bar-surface.tsx` + `TabBarCreateEntry.tsx` + `QuickLaunchButton.tsx`。

### 4.1 结构

```
┌──────────────────────────────────────────┐  DropdownMenuContent align="start" sideOffset={6}
│ 搜索已打开的标签、网址、智能体…           │  w-72 rounded-[11px] p-1 shadow-[0_16px_36px_rgba(0,0,0,.24)]
│ ─────────────────────────────────────── │  ← 输入时这里出现结果行（见 4.2）
│ >_ 新建终端                     Ctrl T  │  静态项：gap-2 rounded-[7px] px-2 py-1.5 text-[12px] font-medium
│ 🌐 新建浏览器标签               Ctrl ⇧B │
│ ─────────────────────────────────────── │
│ ✱ Claude Code                  Ctrl ⌥N │  智能体：已检测且启用；默认智能体排第一并带快捷键
│ ⊛ Codex                                 │
│ ◆ Gemini CLI                            │
│ ⚙ 智能体设置…                           │  灰色
└──────────────────────────────────────────┘
```

- Windows：“新建终端”展开为多项：`新建终端：PowerShell`（第一个=默认，带 Ctrl T）、`新建终端：命令提示符`、`新建终端：Git Bash`（检测到时）、`新建终端：WSL`（检测到时）。macOS/Linux：一项，用默认 Shell；另有子菜单“其他 Shell ▸”（bash/zsh/fish/自定义）。
- 浏览器模块关闭时不显示“新建浏览器标签”。
- 没有检测到智能体：显示禁用行“未检测到智能体”；有检测到但全部停用：“没有已启用的智能体”。
- 菜单关闭后，焦点交给新建出来的终端（不回到「+」按钮）。

### 4.2 搜索框（omnibox）

- 打开菜单即聚焦输入框，`h-9 border-0 bg-transparent text-xs`，占位“搜索已打开的标签、网址、智能体…”。
- 输入后在输入框下方出现结果列表（`role="listbox"`，每行 `h-6 rounded-[7px] px-1 text-[11px]`，图标 + 名称 + `·` + 灰色详情），同时静态项被过滤为匹配项。
- 结果类型与排序（从上到下）：
  1. **已打开的标签**：标题/地址/会话名匹配；当前组优先，同等匹配最近用过的优先。选中 = 切换到该标签。
  2. **新建动作**：输入匹配“终端/terminal/shell”“浏览器/browser/web”时出现。
  3. **智能体**：别名精确匹配（`claude`、`codex`、`gemini`、`opencode`、`grok`、`pi`，以及显示名、命令覆盖名）得分最高；否则按词前缀匹配（单字符不做前缀匹配，避免一个字母误启动）。选中 = 新建该智能体标签。
  4. **网址/本地地址**：输入像地址（见《设计-浏览器》§3 规则）→ “打开 `https://example.com/`”。
  5. **搜索**：输入含空格或不像地址 → “用 百度 搜索「…」”。单个词时网址/智能体排在搜索之前；多词时搜索行提前。
  6. **浏览历史**：最近 500 条中模糊匹配的前 4 条，放在网址行下面。
  7. **快捷命令**：名称匹配的快捷命令（运行 = 新开终端执行）。
- `?` 开头强制搜索（跳过标签/智能体匹配）。
- 键盘：↑↓ 在结果间移动（到底循环）；没有结果时 ↓ 进入下面的静态菜单项；Enter 执行选中项；**输入为空直接 Enter = 新建默认终端**；有输入但没有选中项时 Enter 执行第一项；Esc 关闭菜单。
- 执行中（例如打开网址需要等待浏览器模块加载）：该行显示 `Loader2`，输入框只读，完成后关闭菜单；失败时在输入框下方显示红色状态行，不关闭菜单。

### 4.3 快捷键

| 动作 | 默认 |
|---|---|
| 新建终端（默认 Shell） | Ctrl/Cmd+T |
| 新建默认智能体 | Ctrl/Cmd+Alt+N（Orca 在 Linux/Windows 不绑定，NAND 统一提供，可在 Obsidian 快捷键中改） |
| 新建浏览器标签 | Ctrl/Cmd+Shift+B |
| 打开「+」菜单 | Ctrl/Cmd+Shift+N |

快捷键实现：注册为 Obsidian 命令（默认不绑定热键，遵守仓库规则），另在工作区根元素上监听 `keydown`，仅当焦点在智能体工作区内时生效；终端内部按键优先给终端（xterm 自定义按键处理器里放行这些组合）。

## 5 标签组与分屏

- 一个工作区最多 4 个标签组；每组有自己的标签条。
- **拖动标签到内容区**：内容区四周出现放置提示（右侧 30% 宽度高亮=向右分屏，下方 30%=向下分屏，中间=移到此组）。放下后新建组并把标签移入。
- **拖动标签到另一组的标签条**：移动到该组的指定位置（插入指示线 2px `bg-ring`）。
- 组之间的分隔条用 `react-resizable-panels` 的 `PanelResizeHandle`：1px 线，热区 8px，悬停/拖动时 `bg-ring`；双击平分。
- 组里最后一个标签关闭后该组消失，相邻组扩展。
- 活动组：组内容区外框 1px `ring-inset ring-ring/40`（仅在 ≥2 个组时显示），点击组内任何位置成为活动组。
- **标签内分屏（终端）**：终端标签右键 / `⋯` →「向右拆分终端」「向下拆分终端」，一个终端标签最多 4 个窗格（沿用 `core/terminal/layout.ts`）。多窗格时每个窗格顶部有 22px 细标题栏（窗格名 + 状态 + 关闭），活动窗格标题栏高亮。

## 6 智能体状态

| 状态 | 图标（AgentStateDot） | 颜色 | 何时 |
|---|---|---|---|
| 工作中 working | 转圈（`AgentWorkingSpinner`） | 前景色 | Hook 报告开始一轮 |
| 等待输入 waiting / 需要权限 permission | 问号圆（`AgentQuestionIcon`） | `--agent-question`（橙） | Hook 报告请求输入或权限 |
| 已完成 done | 对勾圆（`CircleCheck`），侧栏用绿点 | `--status-success` | Hook 报告一轮结束 |
| 失败/中断 failed/interrupted | 实心圆点 | `--status-error` | 进程异常退出 / Hook 报告错误 |
| 空闲 idle | 实心圆点 | `text-muted-foreground/50` | 完成后超过 30 分钟无动静 |
| 状态未知 unknown | 虚线圆（`CircleDashed`） | 琥珀 | 没有可靠事件来源（未装 Hook 的 CLI） |
| 普通 Shell | 无 | — | |

- 状态图标尺寸：标签里 10px（`h-2.5 w-2.5`），侧栏和看板里 12px。悬停显示文字（StateIndicatorTooltip）。
- **来源**：只信任 CLI 原生生命周期 Hook（现有 `platform/desktop/hooks/*`：Claude settings.json、Codex hooks.json、Gemini、Grok、Pi 扩展、OpenCode 插件）。输出停顿**从不**当作完成。
- **未读**：会话进入 done 时如果其标签不可见 → 标签显示琥珀色铃铛、侧栏卡片标题加粗；切到该标签后清除。
- **通知**（沿用通知模块）：完成或需要输入时，若 Obsidian 窗口不在前台，发系统通知（设置可关）。

### 7.2 列表行

```
✱ 重构看板解析器                         ⋯
  notes/dashboard · sonnet-4.6 · 2 小时前
```

- 点击行展开详情（同一面板内，不跳页）：工作目录、模型、消息数、**首条提示词**（展开时读取完整原文，带“复制”）、最近几轮对话（你 / 智能体 / 工具，各一行截断）。
- 详情底部按钮：「在新标签中恢复」（主按钮）、「复制恢复命令」、「更多 ⋯」。
- `⋯` 菜单：在新标签中恢复、复制恢复命令、复制会话 ID、复制日志路径、打开日志（用系统应用）、在文件管理器中显示日志、打开工作目录、导出为笔记、收藏/取消收藏、归档/取消归档。
- 行可拖到标签条或内容区：等同“在该位置恢复”。
- 恢复规则沿用现有实现：再次检查工作目录与原生记录，用 CLI 原生参数恢复（`claude --resume <id>`、`codex resume <id>`、`pi --session <file>` …）；记录不存在时报错，不偷偷新建会话。
