# 09 设计：批注

## 0 目标与参考

用户需求：对某个 Markdown 文档的某一行做了批注后——

1. **右侧栏有一个批注图标**，点开就能看到这篇笔记的批注；
2. **鼠标放到批注上会弹出来**，可以查看、编辑。

主要参考 **Margin Comments**（jonaas-dev/obsidian-margin-comments，MIT，v1.0.1）：行级批注靠编辑器左侧（gutter）的标记添加，选区批注靠命令或浮层，线程在贴着文字的浮窗里显示和编辑（不是模态框），右侧栏面板列出全部线程，锚点按“文字 + 上下文”跟随编辑，找不到时标为脱离。同时参考 Marginalia、Hover Annotations 的悬停弹出做法（在编辑器 DOM 上委托 `mouseover`）。

NAND 现状：已有选区批注、高亮、点击高亮聚焦面板、右侧面板 `nand-comments-view`（要用命令打开）、工作台“批注”页面、`.nand/editor/comments/` 旁路存储。**缺**：行级批注与 gutter 标记、悬停弹窗、右侧栏常驻图标、模糊重锚。本次改造补齐这些，并删除工作台里的“批注”页面。

**原则：批注从不改写笔记正文。**

## 1 右侧栏「批注」视图

### 1.1 常驻图标

- 视图类型仍为 `nand-comments-view`，显示名“批注”，图标 `message-square-text`。
- 插件 `onLayoutReady` 后，如果设置 `comments.panelAutoPlaced` 为假，调用：

  ```ts
  await app.workspace.ensureSideLeaf(COMMENTS_VIEW_TYPE, 'right', { active: false, reveal: false });
  settings.update({ panelAutoPlaced: true });
  ```

  这会在右侧栏里放一个“批注”标签（和“大纲”“反向链接”一样，图标常驻在右侧栏顶部的标签条里），但不抢焦点。只做一次：用户自己关掉后不再自动放回，可用命令“打开批注面板”重新打开（命令用 `ensureSideLeaf(..., { active: true, reveal: true })`）。
- 设置项“面板位置：右侧栏（默认）/ 左侧栏”。

### 1.2 面板版式

```
┌────────────────────────────────────┐
│ 批注                     ⟳  ⋯      │  h-9 px-3；⋯ = 排序、全部解决、设置
│ ( 本笔记 | 全库 )                   │  SegmentedControl size=sm
│ [全部 5] [未解决 3] [已解决 2]       │  ToggleGroup，带数量
├────────────────────────────────────┤
│ ┌────────────────────────────────┐ │
│ │ ▏第 12 行 · “## 方案对比”        │ │  引用块：左边 2px 强调色竖线，text-xs，最多 2 行
│ │ 我    3 分钟前                  │ │  作者 text-xs font-medium · 时间 text-2xs 灰
│ │ 这里要补充成本数据。             │ │  正文 Markdown 渲染 text-[13px]
│ │   └ 我 · 刚刚：已补，见附录      │ │  回复缩进 12px
│ │ [回复…]                ✓ ✎ 🗑 ↗ │ │  悬停显示操作：解决、编辑、删除、跳转
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │ ▏“检索延迟在 200ms 以内”  ⚠已脱离│ │  脱离线程：琥珀色徽标 + [重新挂上]
│ └────────────────────────────────┘ │
│ 已解决（2）                     ▸  │  已解决折叠在底部
└────────────────────────────────────┘
```

- **本笔记**：跟随当前活动的 Markdown 编辑器；没有打开笔记时显示空状态“打开一篇笔记查看它的批注”。
- **全库**：按笔记分组（笔记名 + 未解决/全部数量），组默认折叠，展开时才读取该笔记的线程（大库不卡）；点击线程打开对应笔记并定位。被删除笔记的批注（保留模式下）显示在“找不到的笔记”组。
- 排序：文中位置（默认）/ 创建时间 / 最近活动。
- 点击卡片空白处：在编辑器中滚动到锚点并短暂闪烁高亮（600ms）。
- 空状态（本笔记无批注）：图标 + “这篇笔记还没有批注” + 说明“把鼠标移到行首左侧点 💬，或选中文字后按 批注”。
- 面板宽度由 Obsidian 右侧栏控制；内容 `.nand-ui`，React 渲染。

## 2 编辑器中的批注

### 2.1 两种批注

| 类型 | 如何添加 | 锚定什么 | 显示 |
|---|---|---|---|
| **行级** `line` | 鼠标移到某行左侧边缘（gutter 区域 20px 内），出现「添加批注」图标 `message-square-plus`，点击 | 整行文字 | gutter 图标 `message-square`（多条显示数字），可选整行浅色底 |
| **选区** `range` | 选中文字 → 选区末端旁出现浮动按钮“批注”，或命令“为选区添加批注”（无选区时退化为当前行的行级批注） | 选中的文字 | 文字底色高亮 + 下划线；所在行 gutter 也显示图标 |

不能批注的位置：前置元数据（frontmatter）、代码块内部（沿用现有 `selectionIsCommentable` 规则）。

### 2.2 Gutter 标记（CodeMirror 6 `gutter()`）

- 自定义一列 gutter `nand-comment-gutter`，放在行号左侧，宽 18px。
- 标记规则（照抄 Margin Comments `gutter-state.ts`）：
  - 设置“显示 gutter 图标”关闭 → 不显示任何标记（仍可用命令和选区按钮添加）。
  - 该行有未解决批注 → 常驻 `message-square`（`size-3.5`，颜色 `--interactive-accent`），2 条以上在图标右上角显示数字，超过 9 显示 `9+`。
  - 该行只有已解决批注 → 灰色图标（设置“显示已解决”开启时）。
  - 鼠标在该行且靠近左边缘 20px 内（防抖 50ms）→ 显示 `message-square-plus`（灰色，悬停变前景色）。
  - 触屏设备：没有悬停，改为光标所在行显示添加图标。
- `title` 属性写“添加批注”/“本行 3 条批注”（CodeMirror 的 gutter 对读屏隐藏，读屏用户走面板和命令）。
- 点击：无批注 → 打开浮动编辑框（§4，行级）；有批注 → 打开悬停弹窗（§3）并固定（点击打开的弹窗不会因鼠标移开而关闭）。

### 2.3 高亮

- 选区批注：`Decoration.mark({ class: 'nand-comment-hl', attributes: { 'data-comment-ids': 'c-1 c-2' } })`。颜色：`background: color-mix(in srgb, var(--nd-comment-color) 22%, transparent)`，下边框 1px 同色 60%；`--nd-comment-color` 默认取 `--interactive-accent`（设置“跟随主题强调色”），可在设置里改为自定义颜色。
- 已解决的批注默认不高亮（设置“高亮已解决批注”）。
- 行级批注：设置“高亮有批注的行”开启时，整行 `Decoration.line({ class: 'nand-comment-line' })` 浅底色（强调色 8%）。
- 编辑笔记时，高亮跟随文字移动（CodeMirror 映射位置，沿用现有 `store.applyChanges`）。

## 3 悬停弹窗（查看与编辑）

### 3.1 触发

| 目标 | 打开 | 关闭 |
|---|---|---|
| 鼠标停在高亮文字上 | 停留 **350ms** 后打开，显示覆盖该位置的全部线程 | 鼠标离开文字和弹窗 **300ms** 后关闭；移入弹窗则保持 |
| 鼠标停在 gutter 批注图标上 | 同上，显示该行全部线程 | 同上 |
| 点击高亮文字 / gutter 图标 | 立即打开并**固定** | 点外部、Esc、关闭按钮 |
| 命令“显示光标处批注” | 光标在批注文字内/批注行时打开并固定 | 同上 |
| 弹窗内有未保存的编辑/回复 | — | **不因鼠标移开关闭**，只能保存、取消或 Esc（Esc 先取消编辑，再按一次关闭） |

实现：一个 `ViewPlugin` 在 `view.dom` 上委托 `mouseover`/`mouseout`（目标是 `.nand-comment-hl` 或 gutter 标记元素），用计时器控制开合，把锚点矩形（`getBoundingClientRect()`，多行选区取第一段 client rect）和线程 id 发给本窗口的 `CommentsOverlay`。

### 3.2 弹窗版式

```
┌──────────────────────────────────────┐  Popover：w-[360px] max-h-[min(480px,70vh)] overflow-y-auto
│ 第 12 行的批注（2）           📌  ✕  │  头部 text-xs 灰；📌=已固定（悬停打开时显示“固定”按钮）
├──────────────────────────────────────┤
│ ▏“## 方案对比”                       │
│ 我 · 3 分钟前 · 已编辑               │
│ 这里要补充成本数据。                  │  ← 点“✎”或双击正文：原地变成文本框
│   └ 我 · 刚刚：已补，见附录           │
│ [写回复…                         ]   │  回复框：Enter 换行，Ctrl/Cmd+Enter 发送
│                         ✓解决 ✎ 🗑 ↗ │
├──────────────────────────────────────┤
│ （第二个线程…）                       │
└──────────────────────────────────────┘
```

- 定位：优先放在锚点右侧（`side="right" align="start" sideOffset={8}`），空间不够翻到下方/上方（Radix 碰撞检测）；用 `PopoverAnchor virtualRef` 指向锚点矩形，编辑器滚动时更新位置，锚点滚出可视区时自动关闭（非固定状态）。
- 渲染到编辑器所在窗口的 Portal 根（支持弹出窗口）。
- 线程卡片与面板共用同一个组件 `ThreadCard`（§5）。
- **原地编辑**：点 ✎ 或双击正文 → 正文变 `Textarea`（自动高度），下方“取消 / 保存”；Ctrl/Cmd+Enter 保存，Esc 取消；保存后显示“已编辑”。只能编辑自己写的（`author` 等于当前设置的作者名，或作者为空）。
- 解决：线程淡化并折叠成一行“已解决 · 重新打开”，弹窗不关闭。
- 删除：线程根删除时弹 `AlertDialog`（“删除这条批注及其 2 条回复？”）；回复删除直接执行并提供 toast“已删除 · 撤销”（5 秒）。
- ↗ 跳转：关闭弹窗，编辑器选中锚点文字。
- 手机：轻点高亮或 gutter 图标，以底部抽屉（`Sheet side="bottom"`）显示同样内容。

## 4 浮动编辑框（新建批注）

```
        ┌────────────────────────────────┐
文字……  │ [写下批注…                     ]│  贴在锚点右侧（空间不够时下方），不是模态框
        │ 作者：我（设置中修改）            │  text-2xs 灰；未设置作者时显示“设置作者名”链接
        │                  [取消] [批注]   │  Ctrl/Cmd+Enter 提交，Esc 取消
        └────────────────────────────────┘
```

- 打开时记住原焦点，关闭后把光标放回原处（不跳到文档开头）。
- 提交失败（写盘失败）：编辑框不关闭、文字保留，显示红色错误行和“重试”。
- 选区按钮：选中可批注的文字后，在选区末端上方 8px 出现小按钮 `[💬 批注]`（`Button size="xs" variant="secondary"`）；设置“显示选区批注按钮”可关闭。

## 5 线程卡片组件 `ThreadCard`

| 部分 | 说明 |
|---|---|
| 引用 | 行级：“第 N 行 · 行内容摘要”；选区：“引用的原文”（最多 2 行，超出省略）。左侧 2px 竖线，颜色 = 批注色 |
| 消息 | 作者（空则“我”）、相对时间（悬停显示完整时间）、“已编辑”标记；正文用 Obsidian `MarkdownRenderer` 渲染（外层 `nand-native`），支持 `[[双链]]` 点击打开；长正文“显示更多/收起” |
| 回复 | 扁平结构（回复都挂在线程根上），按时间顺序 |
| 回复框 | 折叠为一行“回复…”，点击展开为 Textarea + 发送 |
| 操作 | 解决/重新打开（`Check` / `RotateCcw`）、编辑（`Pencil`）、删除（`Trash2`）、跳转（`ArrowUpRight`）；`ghost size="icon-xs"`，悬停卡片时出现，键盘聚焦时也出现 |
| 状态 | 已解决：整体 60% 不透明、默认折叠；已脱离：琥珀色“已脱离”徽标 + 说明“原文已被修改或删除” + 按钮“重新挂上”（进入选择模式：在编辑器里选中新位置后确认） |

## 6 阅读模式

- Markdown 后处理器在阅读视图中把仍能定位的选区批注包上 `<mark class="nand-comment-hl" data-comment-ids>`；行级批注在段落左侧显示小图标。
- 点击打开同一个弹窗（固定）。阅读模式下不显示添加入口（只读）。

## 7 锚点与重定位

### 7.1 保存的锚点（v2）

```ts
interface TextAnchorV2 {
	kind: 'range' | 'line';
	text: string;            // 选中的原文；行级 = 整行文字
	textHash: string;        // text 的哈希（快速比对）
	before: string;          // 前 50 个字符
	after: string;           // 后 50 个字符
	lineHint: number;        // 创建时所在行（1 起），只作参考
	start: number; end: number;   // 文档偏移缓存，只作参考
}
```

### 7.2 定位算法（打开笔记、外部修改后）

1. **缓存命中：** `doc.slice(start, end) === text` → 直接用。
2. **精确匹配：** 在全文中查找 `text` 的所有出现；只有一处 → 用它；多处 → 用“前后文相似度”（前缀匹配长度/50 + 后缀匹配长度/50，满分 2）打分取最高，平分时取离 `lineHint` 最近的。
3. **上下文匹配：** 原文找不到时，查找 `before`+`after` 夹住的区域（允许中间文字变化），区域长度在原文长度的 0.5～2 倍之间。
4. **模糊匹配：** 在 `lineHint` 前后 200 行范围内滑动窗口，用有界编辑距离（`boundedLevenshtein`，上限 = ⌈原文长度 × 阈值⌉，阈值默认 0.3，可设 0.1～0.5），取距离最小者。
5. **失败：** 标记 `orphaned`（已脱离），不再自动重新挂上。

行级批注：第 2 步在“整行等于 text”的行中找；第 4 步对整行做模糊匹配。

### 7.3 实时编辑

编辑器内的修改通过 CodeMirror `ChangeSet.mapPos` 实时移动锚点（现有 `store.applyChanges` 逻辑），保存时刷新 `text/before/after/lineHint`；当某次修改删除了锚定文字的全部内容 → 立即标为脱离。

## 8 存储

位置不变：`.nand/editor/comments/`（`index.json`、`pending.json`、`files/<路径哈希>.json`）。文件格式升级为 `version: 2`：

```json
{
  "version": 2,
  "path": "notes/方案.md",
  "threads": [
    {
      "id": "c-7f3k2a",
      "kind": "line",
      "status": "open",
      "anchor": { "kind": "line", "text": "## 方案对比", "textHash": "9c1e…", "before": "…", "after": "…", "lineHint": 12, "start": 340, "end": 347 },
      "messages": [
        { "id": "m-1", "author": "我", "text": "这里要补充成本数据。", "createdAt": "2026-10-13T08:10:00Z" },
        { "id": "m-2", "author": "我", "text": "已补，见附录", "createdAt": "2026-10-13T08:20:00Z", "editedAt": "2026-10-13T08:21:00Z" }
      ],
      "createdAt": "2026-10-13T08:10:00Z",
      "updatedAt": "2026-10-13T08:21:00Z"
    }
  ]
}
```

- `index.json`：`{ version: 2, files: { "<path>": { hash, open, total, updatedAt } } }`，全库范围只读它，展开某篇笔记时才读对应文件。
- 读到 `version: 1` 的旧文件：不迁移（D01），面板顶部提示“发现旧版批注数据，新版本不读取”。
- 笔记重命名/移动：跟随更新（沿用现有处理）。笔记删除：设置“删除笔记时：一起删除批注（默认）/ 保留批注”。
- 损坏的文件：移到 `.nand/editor/comments/set-aside/` 并提示，不覆盖。

## 10 命令

为选区添加批注（无选区时为当前行）、打开批注面板、显示光标处批注、下一条批注、上一条批注（光标跳到下一条/上一条未解决批注的行）、解决本笔记全部批注（确认）。都不设默认快捷键。

## 11 多窗口与生命周期

- 每个窗口一个 `CommentsOverlay` React 根（挂在该窗口 Portal 根下），编辑器插件按 `view.dom.ownerDocument` 找到对应 Overlay。
- 模块停用：移除编辑器扩展、后处理器、Overlay、右侧栏视图内容（视图本身保留并显示“开启批注模块”空状态，沿用现有 `CommentsLeaf` 行为）。
