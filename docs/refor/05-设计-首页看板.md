# 05 设计：首页看板（复刻 apex-dashboard）

## 0 原则

- **唯一蓝本：** apex-dashboard 提交 `ac4d2c745d950b9c4d53d3fd33388204b0769841`（v3.8.4）。本地参考副本路径见《参考映射与许可》。凡本文没写清楚的细节，**以 apex 源码和 `styles.css` 为准，不要自己设计**。
- **只换组件，不换设计：** 版式、尺寸、交互、主题与 apex 一致；按钮、输入框、下拉、弹窗、菜单换成新组件库，颜色经“令牌桥”取自 apex 主题变量（《设计系统》§9）。
- **删除 NAND 自创交互：** 页面上的「看板布局」「看板组件」按钮、首页侧栏的看板列表、独立的「记录」页面、看板组件目录对话框。
- apex 的 README 截图是较早版本；当有冲突时以 v3.8.4 代码为准（例如资料库工具栏在 3.6.1 起改为“下拉单按钮”）。

## 1 页面与外壳

- 功能 `dashboard`，`chrome: 'none'`，**没有侧栏**（第 2 栏不显示）。页面顶端就是横幅。
- 页面根：`<div class="nand-ui nand-dashboard-root" data-theme="<主题>" data-layout="side|stacked|immersive">`，对应 apex 的 `.apex-dashboard-root`。
- 页面菜单（`⋯`）放在横幅右上角书签按钮左侧，悬停横幅时出现：「看板设置」「在新标签页打开」「在分屏中打开」。

## 2 三种布局

### 2.1 左右布局 `side`（默认）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ① 横幅 120px（左上：1 2 3 + 药丸；右上：书签；右下：编辑；左下：钉住侧栏）   │  margin: 0 16px 8px
├────────────┬─────────────────────────────────────────────────────────────────┤
│ ② 侧栏     │ ③ 看板（.dashboard-kanban，纵向滚动，隐藏滚动条）               │  .dashboard-main
│ 220px      │  常用操作条：[今日][命令][置顶][新建…][技能]  ✎ 觉察当下… ⚙   │  padding: 8px 16px 0
│ 周历条      │  ┌ ⋮⋮ 便利贴 ▼ ─────────────────────── 操作按钮（悬停出现） ┐  │  gap: 10px
│ 天气卡      │  │ [卡片][卡片][卡片][卡片] → 横向滚动                      │  │
│ 音乐卡      │  └──────────────────────────────────────────────────────────┘  │
│ 番茄钟卡    │  ┌ ⋮⋮ 视频字幕稿 ▼ ───────────────────────────────────────┐  │
│ 记账卡      │  │ 工具栏 + 网格                                           │  │
│ …           │  └──────────────────────────────────────────────────────────┘  │
│ 最近文档    │  ┌ ＋ 添加分区 ────────────────────────────────────────────┐  │
│            │                                                       [↑ 顶部]│
└────────────┴─────────────────────────────────────────────────────────────────┘
```

- 侧栏宽度：默认 220px，拖动右缘调整 180～420px（只在左右布局、桌面端）。侧栏内文字按 `clamp(0.92, 宽/220, 1.12)` 缩放（apex `.dashboard-sidebar-widgets[data-layout="side"]`）。
- 侧栏三态：**收起**（15px 细条 + 中间细指示条，鼠标按下展开）、**展开**（点外部收起）、**钉住**（常驻）。钉住状态由横幅左下角的钉子按钮切换，按库保存在本地存储。默认收起。
- 看板区与侧栏各自滚动；看板 `container-type: inline-size`，内部用容器查询适配宽度。

### 2.2 上下布局 `stacked`

```
┌──────────────────────────────────────────────────┐
│ 横幅                                              │
│ 常用操作条（固定，不随下面滚动）                    │
├──────────────────────────────────────────────────┤
│ ↓ 一个滚动区域                                    │
│ 小组件卡片墙（横向一排，单元高 300px，可拖 240–560）│
│ 看板分区 …                                         │
└──────────────────────────────────────────────────┘
```

- 小组件按高度比例（全高 / 三分之二 / 二分之一 / 三分之一）拼成卡片墙；习惯、阅读小组件的比例在设置里选。
- 小组件条底边可拖动调整单元高度（240～560px）。
- 侧栏的收起/展开/钉住在这里变成“小组件条折叠成细条 / 展开 / 钉住”。

### 2.3 沉浸布局 `immersive`

```
┌──────────────────────────────────────────────────────────────┐
│ ░░░░░░░░░░ 海报背景铺满（横幅图片 + 焦点 + 轮播 + 遮罩） ░░░░░ │
│ [1 2 +]                                           [✨编辑]    │
│                    12:34  周二 10月13日                        │
│        [今日][命令] ✎ 觉察当下，随心落笔  ⚙                     │
│ ┌──────────┬────────────────────┬──────────┐                  │
│ │ 天气     │ 便利贴（分区卡片）   │ 番茄钟   │  12 列自由网格     │
│ ├──────────┤                    ├──────────┤  每行 10px 细行    │
│ │ 习惯     ├────────────────────┤ 记账     │  卡片高度贴合内容   │
│ └──────────┘ 数据库（分区卡片）   └──────────┘                  │
│ [＋ 添加卡片]                                                   │
└──────────────────────────────────────────────────────────────┘
```

- 结构（apex `immersive.ts`）：`.dashboard-imm` 下有固定背景层、顶部（时钟 + 常用操作条，居中）、唯一的滚动层（12 列网格）、左上角工作台切换、右上角编辑按钮。
- 网格：12 列，行高 10px（`IMM_ROW_UNIT`），卡片间距 10px，最少 3 行；卡片宽度 = 用户拖动的列数（1～12），高度 = 测量内容高度后取整到细行，但不超过保存的上限 `h`；用户手动调过高度的卡片 `fixed: true`，内容在内部滚动。
- 摆放：按列表顺序用“天际线左下”算法（每张卡放在可放位置中最低的那一行，同行取最左）；有 `x/y` 显式坐标的卡片先放。算法已在 NAND `home/core/board/immersive-grid.ts` 实现，复用。
- 交互：拖标题移动（放下时一次写回）、拖右下角调整大小、右键菜单「从看板移除」、悬停右上角 ×；键盘：聚焦标题后 Enter/Space 拾起，方向键移动，Shift+方向键缩放，Esc 取消。
- 窄宽度下临时投影为 6 列或 3 列，不改保存的布局。
- 新建沉浸工作台：横幅药丸的「+」→ 选择布局“沉浸”。

### 2.4 手机

手机固定使用移动版左右布局：横幅 → 小组件标签条（农历、日历、番茄钟、习惯、记账、阅读图标按钮，点一下在下方展开该小组件面板，再点收起）→ 看板。所有背景模糊在移动端关闭（apex 1.6.3 的 iOS 崩溃修复）。

## 3 横幅

### 3.1 结构

```
┌─[1][2][3][+]────────────────────────────────────────────────[⋯][🔖]─┐
│                                                                        │
│            “The mind is everything. What you think you become.”        │  名言：1.2em 斜体，白色，带文字阴影
│                               Buddha                                    │  作者：.8em，白色 60%
│[📌]                                                              [✎]  │
└────────────────────────────────────────────────────────────────────────┘
```

- 高 120px，圆角 `--db-radius-lg`，背景图 `cover` + 焦点位置（百分比），无图时用主题 `--db-bg-banner` 渐变；四周 `margin: 0 16px 8px`。
- 左上：工作台切换药丸（每个工作台一个数字或名称，当前高亮；最后一个 `+` 新建）。药丸高 14～20px，半透明玻璃底。
- 右上：书签按钮（悬停才显示）折叠/展开横幅；折叠后横幅变成 4px 细条，药丸悬挂在下方；折叠状态按库保存。
- 右下：编辑按钮（悬停才显示，图标 `wand-sparkles`），打开「横幅编辑」对话框。
- 左下：钉住侧栏按钮（`pin` / `pin-off`），仅桌面端。
- 名言与图片轮播：配置了多条名言/多张图片时自动轮播，名言淡入淡出 0.4s，图片切换 0.6s。

### 3.2 两种模式

| 模式 | 内容 |
|---|---|
| 海报名言 `quote` | 背景图 + 名言 + 作者（上图） |
| 数据统计 `stats` | 背景图模糊 + 暗化，三栏：**规模**（笔记总数 + 小字条）、**活跃**（连续天数 + 贡献热力图，数据源可选“笔记活跃”或某个习惯）、**生产力**（任务完成率、每篇链接数、连通度等进度条）。窄屏只显示中间栏 |

命令「切换横幅视图（海报名言 / 数据统计）」。

### 3.3 横幅编辑对话框

Tabs：「海报」「数据统计」。

- 海报：名言列表（可增删排序）、作者、名言颜色、名言字体（下拉：中文 8 款 + 英文 8 款，内置跨平台字体栈）、图片列表（库内图片选择器或网址，可增删排序）、每张图的焦点（拖动预览 / 方向键 / 百分比输入 / “图片居中”）。
- 数据统计：三栏显隐与主指标、右栏进度项、模糊与暗度滑杆、强调色、日记文件夹、排除文件夹、热力图数据源。
- 底部：取消 / 保存。

## 4 侧栏

自上而下：

1. **周历条**：7 天（周一到周日），每格上面一个字的星期、下面日期数字；今天用强调色填充圆角块（强调色较亮时文字用深色）。
2. **小组件卡片**：按设置中的顺序排列，可拖动排序（拖卡片空白处；从按钮、输入框、滑杆上按下不触发拖动）。
3. **最近文档**：最近编辑的 N 篇（设置“最近文档数量”），文件名 + 相对时间，点击打开。
4. 右下角浮动「回到顶部」按钮（看板滚动后出现）。

小组件卡片通用外观：`bg-[--db-bg-card] border border-[--db-border-card] rounded-[--db-radius-md] p-3`，可设背景图（不透明度、黑色蒙版、模糊、前景色：浅/深/自定义），设背景图后卡片内浮起一层磨砂玻璃承载文字。卡片右上角按钮簇（统计、设置齿轮等）在悬停时出现（习惯打卡的按钮常显）。

## 6 常用操作条（Quick Notes 区）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ [☀ 今日] [⌘ 闪念] [▤ 油管] [🚀 今日简报] [✨ 技能]   [✎ 觉察当下，随心落笔 ⏎] ⚙ │
└─────────────────────────────────────────────────────────────────────────────┘
```

- 左侧芯片顺序固定：今日日记（开启时）→ 快捷命令 → 置顶笔记 → 模板新建预设 → 技能按钮。芯片过多时在条内横向滚动；超过一排自动换行（每行最多 5 个），多行时条体圆角变为卡片圆角。
- 右侧捕捉框，两种用途二选一：
  - **闪念**：多行输入，回车追加一行到目标笔记（文件开头或末尾），没有目标笔记时在指定文件夹按模板新建一篇。
  - **文件搜索**：输入即在下方浮窗列出文件（↑↓ 选择、回车打开、Esc 收起）；「+」显示最近打开的文件。
- 宽度不够时：按钮组保底，输入框缩成一个铅笔图标，点击后展开。
- 没有配置任何内容时显示空状态：“常用操作条还是空的” + 「配置」。
- 齿轮打开「常用操作配置」对话框：四个列表（模板新建预设、置顶笔记、快捷命令、技能按钮），每项可改名、换图标（全量 Lucide 图标选择器，常用置顶、模糊搜索、最多显示 400 个）、拖动排序；捕捉框用途、目标、文件夹、模板、插入位置；“今日”按钮开关。

## 7 分区

### 7.1 通用外框

```
┌ ⋮⋮ 标题 ▼                                         [操作按钮…（悬停出现）] ┐  header: margin-bottom 8px
│ 内容（随类型）                                                              │
└──────────────────────────────── 拖动底边调高度 ─────────────────────────────┘
```

- 外观：`background: --db-bg-section; border: 1px solid --db-border-section; border-radius: --db-radius-lg; padding: 12px 16px; max-height: 500px（可拖动改）`；主题可设置为透明分区（花漾、苔原等）。
- 抓手 `grip-vertical`（仅桌面）：拖动整个分区排序。
- 标题 `h3`（1em，700），**双击原地重命名**（Enter 保存，Esc 取消，失焦保存）。
- 折叠三角：标题右边；折叠后只剩标题行，三角旋转 -90°；折叠状态按库保存。
- 操作按钮：默认透明度 0，悬停标题行时出现；按类型不同（见 §7.3）。
- 高度：桌面端拖动分区底边调整（写入看板文件 `height`），手机端忽略。
- 半宽并排：分区设置“半宽”后与相邻的半宽分区并排，中间分隔条可左右拖动（20%～80%，写入 `pairWidth`）；拖动时嵌入网页暂停接收鼠标。

### 7.2 添加分区

看板末尾一个虚线框按钮「＋ 添加分区」（沉浸布局叫「＋ 添加卡片」）。点击打开「添加分区」对话框：

1. 3 行 × 5 列类型网格（图标 + 名称），顺序固定：
   - 便利贴、文件夹、数据库、笔记、数据视图
   - 项目管理、工作流、技能库、日历、RSS
   - 图片、视频、网页、微信读书、滴答清单
2. 选中后输入名称（默认类型名），确定后创建并滚动到新分区。

命令「添加新分区」走同一流程。

### 7.3 分区类型

| 类型（key） | 内容 | 头部操作 | 优先级 |
|---|---|---|---|

### 7.4 数据库/文件夹分区工具栏

```
[🔍 搜索文件…        ] [修改时间 ⌄] [↧] [▦ 视图 ⌄] [M ⌄] [⏳ 快捷筛选] [⊟ 分组 ⌄] [⇕ 全部展开]   1734 个文件 [20条/页 ⌄] [＋] [⚙]
```

- 视图、卡片大小（S/M/L）、分组是“下拉单按钮”：只显示当前项，点击弹菜单选择（apex 3.6.1）。
- 快捷筛选：日期按钮 + 日历面板框选起止区间，生效时按钮高亮。
- 分组：不分组 / 按文件夹 / 按属性；开启后出现“全部展开/折叠”。
- 每组/每列先显示 50 条，“再显示 50 条”追加；总显示上限 500 条，超过提示缩小筛选。
- 表格视图多一个眼睛按钮：列显隐与排序（各分区记忆）。
- 网格/画廊卡片悬停右上角出现删除按钮（移入回收站，确认框默认聚焦“取消”）。
- 「＋」新建笔记：文件夹分区在该文件夹创建（多个文件夹时弹菜单选）；数据库分区在设置的路径创建并预填筛选属性；多模板时先选模板。

## 8 卡片

### 8.1 通用

- 外观：`bg --db-bg-card; border 1px --db-border-card; radius --db-radius-md; padding 16px; box-shadow --db-shadow-card`；悬停 `translateY(-2px)`、`--db-shadow-card-hover`、`--db-bg-card-hover`。
- 头部：标题 `h4`（双击重命名）+ 操作按钮（悬停出现）：尺寸 S/M/L（小组件卡）、颜色（备忘）、新笔记（项目卡）、编辑、保存为笔记（备忘）、待办保存到日记、置顶、删除（危险色）。
- 底部可有截止日期 `due`（过期变红）。
- 拖动卡片标题：同分区内排序，或拖到其他分区（备忘/待办/便利贴之间互转时保留内容与勾选状态，笔记链接随行）。拖动中卡片 40% 透明、旋转 2°；目标分区边框变强调色、底色变 `--db-bg-drop-indicator`。

### 8.2 待办卡

- 任务行：圆形复选框（`--db-checkbox` 色）、文字（`[[双链]]` 可点）、提醒铃铛（打开自动化编辑器，以该任务为来源）、子任务折叠箭头；拖动行排序（含层级）。
- 底部“+ 添加任务…”输入行；进度条（`--db-progress-from` → `--db-progress-to` 渐变）+ 百分比。

### 8.3 备忘卡

- 正文用 Obsidian `MarkdownRenderer` 渲染（外层加 `nand-native`），点击进入编辑（textarea）；颜色强调条（8 色）。

### 8.4 项目卡（笔记分区）

- 封面图（库内图片或网址，焦点可调）、标题、关联文档列表（每行文件图标 + 名称，可拖动到其他项目卡）、进度；卡内搜索框添加文档。

### 8.5 网页快捷卡（便利贴内）

- 名称、网址、打开方式（弹窗 / NAND 浏览器标签 / 系统浏览器）。重构后“标签页”改为在智能体工作区新建浏览器标签。

`--db-font` 只在设置“使用主题字体”开启时生效（默认关，统一使用 Geist + 系统中文字体）。横幅名言字体独立（横幅编辑里选）。

### 9.4 外观工作室

对话框（大尺寸）：左侧分组表单，右侧实时预览（就是看板本身，因为对话框不遮挡全部看板）：

- 颜色：强调色、浅强调、页面底色、卡片、分区、文字、次要文字、卡片边框；每项“跟随主题 / 浅色 / 深色 / 自定义”+ 透明度滑杆。
- 背景：图片（库内或网址）、暗化 0～100、模糊 0～30px、铺满/适应。
- 高级：表面不透明度、毛玻璃模糊 0～20px、圆角基准 0～22px、字号（小/中/大）。
- “保存为我的主题”（命名），主题下拉里出现“我的主题”分组；可应用、改名、删除。
- 底部：重置为主题默认 / 关闭（所有改动即时生效）。
