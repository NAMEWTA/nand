# 07 设计：浏览器（照搬 Orca 浏览器）

## 0 定位

- 浏览器**不再是独立功能**。它是智能体工作区里的一种标签：「+」菜单里“新建浏览器标签”，或在「+」搜索框输入网址/搜索词。浏览器标签可以和终端标签并排分屏，方便智能体边改代码边看网页。
- `browser` 模块只做“浏览器引擎”（`BROWSER_HOST` 服务，见《架构文档》§10）：网页宿主、个人资料、Cookie、下载、查找、缩放、元素抓取、截图标注、站点权限。
- **删除**：AI 工作台、受限网页助手、浏览器流程、本地外接（限定授权页面、会话级 `NAND_BROWSER_*` CLI 桥）。清单见《删除清单》§2。
- 术语：Orca 的 *Profile* 在中文界面叫 **个人资料**（与 Chrome 中文版一致），避免与智能体“账号”混淆。

## 1 浏览器标签

```
[🌐favicon] 页面标题…                [×]     加载中：favicon 换成 Loader2 转圈
```

- 外观同终端标签（《设计-智能体工作区》§3.2）。前导图标为网站图标（16×16，`rounded-sm`，加载失败用 `Globe`）。
- 标题：页面 `<title>`，空时显示域名，再空显示“新标签页”。
- 右键菜单：重新加载、复制地址、复制标题和地址（Markdown 链接）、在系统浏览器打开、复制此标签（同地址同个人资料新开）、切换个人资料 ▸、向右分屏、向下分屏、关闭、关闭其他、关闭右侧。
- 关闭浏览器标签会取消该标签正在进行的下载（先确认：“有 1 个下载正在进行，关闭标签会取消它”）。
- `Ctrl/Cmd+Shift+T` 重新打开最近关闭的标签（终端与浏览器共用一个“最近关闭”栈，浏览器恢复地址与个人资料）。

## 3 地址栏

### 3.1 外观与状态

- `h-7 rounded-md bg-muted/60 px-2 text-xs`，聚焦时 `bg-background ring-[3px] ring-ring/50`。
- 左侧：站点信息按钮（`Shield`/`ShieldAlert`/`Lock`/`FileText`），点击打开站点权限弹出框（§12）。
- 文本：未聚焦时显示完整地址，`https://` 前缀与路径为灰色、域名为前景色；聚焦时全选，显示原文。
- 右侧：非 100% 缩放时显示缩放比例按钮（点击重置）；加载中显示细进度条在地址栏底边（2px，`bg-primary`）。

### 3.2 输入规则（照抄 Orca `normalizeBrowserNavigationUrl`）

| 输入 | 导航到 |
|---|---|
| 空、`about:blank` | 空白页 |
| `localhost`、`127.*`、`0.0.0.0`、`[IPv6]`（可带端口与路径） | `http://…` |
| Windows UNC 路径、绝对路径（`/…`、`C:\…`） | `file://…`（本机预览，guest 仍然沙箱化） |
| `主机名:端口`（如 `myserver:8080`） | `https://…` |
| 已带 `http:`、`https:`、`file:` 协议 | 原样 |
| 其他协议（`javascript:`、`data:`、`chrome:` …）、带用户名密码的地址 | 拒绝，地址栏下方提示“不支持此地址” |
| 单个词，含点且后缀像域名（`example.com`、`a.cn/x`） | `https://…` |
| 含空格，或不含 `.` 和 `:` | 默认搜索引擎搜索 |

### 3.3 建议下拉

聚焦并输入时，地址栏下方弹出 `Popover`（宽同地址栏）：

1. 第一行：按当前输入将执行的动作（“打开 `https://…`”或“用 百度 搜索「…」”）。
2. 浏览历史（最近 500 条，标题与地址模糊匹配，最多 6 条），每行 favicon + 标题 + 灰色地址。
3. 已打开的浏览器标签（匹配时，行尾“切换到标签”）。
- ↑↓ 选择，Enter 执行，Tab 补全到选中项，Esc 恢复原地址并失焦。

## 4 新标签页

新建浏览器标签打开“默认主页”（设置项）；未设置时打开空白页，**焦点在地址栏**（Orca 行为）。不设计额外的起始页。

## 5 默认搜索引擎

设置 → 浏览器 → 默认搜索引擎（`Select h-7 w-36 text-xs`）：

| 选项 | 地址模板 |
|---|---|
| Google（默认） | `https://www.google.com/search?q=%s` |
| Bing | `https://www.bing.com/search?q=%s` |
| 百度 | `https://www.baidu.com/s?wd=%s` |
| DuckDuckGo | `https://duckduckgo.com/?q=%s` |
| 自定义 | 用户填写，必须是 `https://` 且包含 `%s`；保存前校验，不合法时输入框标红并提示 |

说明文字：“在地址栏或新建菜单中输入非网址文字时使用的搜索引擎。”搜索词用 `encodeURIComponent` 编码后替换 `%s`。

## 6 个人资料与 Cookie 导入

### 6.1 个人资料

- “默认”个人资料始终存在、不能删除；用户可新建任意多个。
- 每个个人资料一个独立的 Electron 会话目录：`.nand/browser/<device-id>/profiles/<id>/session/`；下载目录 `…/<id>/downloads/`。不同个人资料之间 Cookie、localStorage、缓存完全隔离。
- 新建：⋯ →「新建个人资料…」或设置页「添加个人资料」→ 小对话框（`max-w-md`）：名称（必填，1～40 字）、“创建后从浏览器导入 Cookie”勾选（勾选后创建完立即打开导入子菜单）。成功提示“已创建个人资料「工作」”。
- 新标签使用“默认个人资料”设置里选的那个；`target=_blank` 打开的新标签继承来源标签的个人资料。
- 删除：设置页每行“删除”→ `AlertDialog`：“删除个人资料「工作」？将关闭使用它的 2 个标签，并清除它的 Cookie、网站数据和下载记录（已下载的文件保留）。”主按钮“删除”（危险色），默认焦点在“取消”。

### 6.2 导入 Cookie

**入口：** 工具栏“导入 Cookie”提示按钮、⋯ →「导入 Cookie ▸」、设置页个人资料行「导入 ▸」。

**子菜单内容：**

```
⚠ 只在这台电脑上读取浏览器数据（说明，见下）      ← BrowserCookieImportMachineNotice
从 Google Chrome            ▸  个人资料 1 / 工作 …（只有一个用户资料时不展开，直接执行）
从 Microsoft Edge
从 Brave
从 Arc（macOS）
从 Chromium
从 Firefox
──────────────
从文件…
ⓘ Google 登录不会被导入，请直接在 NAND 中登录 Google。   ← BrowserCookieImportDisclosure
```

- 打开子菜单时才检测本机浏览器（不在启动时扫描其他应用的数据目录）。
- 检测规则：在各平台的用户数据目录（macOS `~/Library/Application Support/<Browser>`、Windows `%LOCALAPPDATA%\<Vendor>\<Browser>\User Data`、Linux `~/.config/<browser>`）中查找含 `Cookies` 数据库的用户资料目录；Firefox 读 `profiles.ini`。

**执行过程与反馈（> 1 秒，按《设计系统》§10 显示阶段）：**

1. toast（加载态）：“正在从 Chrome 读取 Cookie…”
2. macOS 首次会弹出系统钥匙串授权框（“NAND/Obsidian 想要使用钥匙串中的 Chrome Safe Storage”），用户需点“允许”；文案提前在说明里告知。
3. 完成：成功 toast “已从 Chrome（个人资料 1）导入 312 个 Cookie 到「默认」”；若跳过了 Google Cookie，再追加一行警告“跳过了 18 个 Google Cookie，请直接在 NAND 中登录 Google”。
4. 部分失败：警告 toast “有 40 个 Cookie 无法解密（原因：Chrome 应用绑定加密 / Linux 钥匙环不可用）。可改用“从文件导入”。”
5. 完全失败：错误 toast，附“查看详情”（打开对话框显示原因和建议），不改动个人资料。
6. 成功后，当前个人资料下打开的标签提示“Cookie 已更新，刷新页面后生效”并提供“全部刷新”按钮。

**导入规则：**

- 只替换导入的那些域名下的旧 Cookie，其他网站的登录保持不变。
- 排除 `google.com` 及其子域（Google 会把会话绑定到来源浏览器，转移后会被强制登出）。
- 非法域名、超长值、无法写入的 Cookie 计入“跳过”。
- 读取前先把 Cookie 数据库复制到 `.nand/browser/<device-id>/tmp/`，读完立即删除副本。

**从文件导入：** 系统文件对话框，接受 Netscape `cookies.txt`（浏览器扩展导出的标准格式）和 JSON 数组（Cookie-Editor、EditThisCookie 导出格式：`domain`、`name`、`value`、`path`、`expirationDate`、`secure`、`httpOnly`、`sameSite`）。

## 7 下载栏

浏览器标签有下载时，工具栏下方出现下载栏（`border-b bg-muted/30 px-3 py-1.5`），列出进行中和最近 10 分钟内完成的下载：

```
⤓ report.pdf      ▬▬▬▬▬▬▬░░░ 68% · 2.1 MB/s     [取消]
✓ data.csv        已完成 · 1.2 MB          [打开] [在文件夹中显示] [×]
✕ big.zip         失败：网络中断                     [重试] [×]
```

- 文件保存在当前个人资料的 `downloads/`；完成后 toast“已下载 report.pdf”，带“打开”。
- 栏右侧“全部清除”。没有下载时整栏不显示。

## 8 查找与缩放

- **查找**（Ctrl/Cmd+F，焦点在浏览器标签内时）：工具栏下方右侧浮出查找条：输入框、匹配计数“3/12”、上一个（Shift+Enter）、下一个（Enter）、区分大小写开关、关闭（Esc，焦点回到网页）。
- **缩放**：Ctrl/Cmd+加号/减号/0；Ctrl/Cmd+滚轮。每个标签单独记忆；新标签用“默认缩放”。改变时地址栏右侧短暂显示比例（1.5 秒后淡出，非 100% 时常显为可点击的重置按钮）。范围 25%～300%。

## 9 链接路由

- 设置 → 浏览器 → 链接打开方式：**在 NAND 浏览器打开（默认）/ 在系统浏览器打开**。作用于终端里的链接和笔记里的外部链接（笔记链接只在开启“接管笔记中的外部链接”时生效，默认关闭，以免改变 Obsidian 原有行为）。
- “按住 Shift+Ctrl/Cmd 点击反向打开”开关（默认开）。
- 终端链接单击弹出小菜单（照抄 Orca Link actions，可在设置中关闭）：在 NAND 浏览器打开、在系统浏览器打开、复制链接。Ctrl/Cmd+单击直接按默认方式打开。
- 在 NAND 浏览器打开时：在当前活动组新建浏览器标签；若已有同地址标签则切换过去。

## 10 视口模拟（P2）

⋯ →「视口大小 ▸」单选：默认、iPhone 15（393×852）、Pixel 8（412×915）、iPad（820×1180）、笔记本（1280×800）、桌面（1920×1080）。通过 Chrome DevTools Protocol 的设备模拟实现（页面看到的 `innerWidth` 与媒体查询随之变化）；非默认时地址栏右侧显示 `▭ 393×852` 芯片，点击恢复默认。

## 11 元素抓取、标注与截图绘制（Design Mode）

照抄 Orca Design Mode，复用 NAND 现有 `grab-script.ts`、`snapshot-*`、`core/markup-model.ts`。

### 11.1 抓取页面元素（`Crosshair`，快捷键 Ctrl/Cmd+Shift+C）

1. 进入抓取模式：网页上方覆盖半透明层，鼠标悬停元素时画出高亮框和标签（`div.card 320×180`），Esc 退出。
2. 点击元素：弹出预览浮层（`Popover`，锚定到元素框）：元素截图、文字摘要、CSS 选择器、HTML 摘要（前 2 KB）、关键计算样式；页面提供源码映射时显示源码位置。
3. 浮层操作：复制（文字 / 选择器 / HTML / 截图）、**附加到智能体 ▸**（列出正在运行的智能体会话，按“当前组的会话优先”排序；选择后把材料作为一次括号粘贴放进该会话输入框，**不自动回车**，并切到该标签）、重新选择、关闭。

### 11.2 标注页面元素（`MessageSquarePlus`）

同抓取，但点击元素后弹出输入框“说明你想怎么改…”，保存为一条“待附加标注”（工具栏按钮右上角显示数量圆点）。可连续标注多个元素；点按钮旁的箭头打开“待附加标注”列表：编辑、删除、全部附加到智能体 ▸。附加时生成一段结构化文本（每条：选择器、元素摘要、你的说明）+ 截图文件路径。

### 11.3 在截图上绘制（`PenTool`）

截取可见区域后打开全屏绘制层：画笔、荧光笔、箭头、矩形、椭圆、文字、颜色、撤销/重做、清空；完成后“复制图片”或“附加到智能体 ▸”（图片保存到 `.nand/browser/<device-id>/artifacts/`，粘贴其路径和说明）。

## 13 加载失败

内容区居中错误卡片（`EmptyState` 变体）：图标 `CloudOff`、标题（“无法打开此页面”/“连接被拒绝”/“证书无效”）、地址与错误码（灰色等宽）、按钮「重试」「在系统浏览器打开」。证书错误不提供“继续访问”（安全起见）。

## 15 数据与隐私

| 数据 | 位置 | 说明 |
|---|---|---|
| 个人资料列表 | `.nand/browser/<device-id>/profiles.json` | id、名称、创建时间、导入来源 |
| 会话数据 | `.nand/browser/<device-id>/profiles/<id>/session/` | Cookie、缓存、存储（Electron 管理） |
| 下载 | `.nand/browser/<device-id>/profiles/<id>/downloads/` | |
| 浏览历史、站点权限 | `.nand/browser/<device-id>/state.json` | 最近 500 条 |
| 抓取/截图附件 | `.nand/browser/<device-id>/artifacts/` | 附加给智能体的文件 |
| 浏览器标签布局 | `.nand/terminal-agent/<device-id>/workspace.json` | 地址、标题、个人资料、缩放 |

- Cookie 导入只在用户点击后读取其他浏览器的数据，只写入本库的个人资料，不上传任何地方；读取用的临时副本立即删除；解密密钥只在内存中使用。
- `.nand/` 是点目录，Obsidian Sync 不同步；用 Git 同步时建议把 `.nand/browser/*/profiles/` 加入 `.gitignore`（用户指南里说明）。
