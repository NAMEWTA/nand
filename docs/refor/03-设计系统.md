# 03 设计系统

本文是 NAND 界面的唯一视觉规范：用什么组件、颜色、字体、间距，以及每种场景该选哪个组件。它改编自 Orca 的 `docs/STYLEGUIDE.md`，并针对“跑在 Obsidian 里”做了调整。

**一句话原则：** 安静、单色、跟随 Obsidian 主题；颜色只用来表达状态（选中、危险、运行中、需要处理），不做装饰；能用现成组件就不写新样式。看板是唯一的例外：它通过“令牌桥”使用 apex 的 13 款主题（§9）。

## 2 令牌

令牌是 CSS 变量，定义在 `.nand-ui` 上（`src/ui/styles/tokens.css`），通过 `@theme inline` 映射为 Tailwind 颜色（见《架构文档》§5.2）。组件里**只写 Tailwind 类**（如 `bg-card text-muted-foreground`），不直接写 `var(--…)`，更不写十六进制。

### 2.1 基础色（默认「跟随 Obsidian」）

| 令牌 | 取值 | 用途 | 不要用于 |
|---|---|---|---|
| `--background` / `--foreground` | `var(--background-primary)` / `var(--text-normal)` | 页面画布、默认文字 | 卡片、弹层 |
| `--card` / `--card-foreground` | `var(--background-primary-alt)` / `var(--text-normal)` | 从画布上“浮起”的面板 | 画布本身 |
| `--popover` / `--popover-foreground` | `var(--background-secondary)` / `var(--text-normal)` | 菜单、下拉、悬浮卡 | 内联界面 |
| `--primary` / `--primary-foreground` | `var(--interactive-accent)` / `var(--text-on-accent)` | 流程中**唯一**的确定动作（保存、创建、运行） | 装饰、悬停、次要动作 |
| `--secondary` / `--secondary-foreground` | `var(--interactive-normal)` / `var(--text-normal)` | 与主按钮并列的次要按钮 | 确定动作 |
| `--muted` / `--muted-foreground` | `var(--background-secondary)` / `var(--text-muted)` | 次要文字、说明、占位、禁用 | 正文 |
| `--accent` / `--accent-foreground` | `var(--background-modifier-hover)` / `var(--text-normal)` | 幽灵按钮和列表行的悬停/选中底色 | 实心填充按钮 |
| `--destructive` / `--destructive-foreground` | `var(--text-error)` / `var(--text-on-accent)` | 删除、结束进程、不可撤销 | 取消按钮 |
| `--border` | `var(--background-modifier-border)` | 所有细线：分隔、输入框、卡片边 | 强调（用 ring） |
| `--input` | `var(--background-modifier-border)` | 表单控件边框 | 表单外 |
| `--ring` | `var(--interactive-accent)` | 聚焦环、选中光晕 | 常驻装饰 |

### 2.4 圆角

`--radius: 0.625rem`（10px）。`rounded-sm` = 6px（小标签、轨道），`rounded-md` = 8px（按钮、输入、行），`rounded-lg` = 10px（卡片、弹层），`rounded-xl` = 14px（对话框、大卡片），`rounded-full`（徽标、药丸）。嵌套圆角 = 外层圆角 − 内边距。

### 2.5 阴影与层次（只有三级，照抄 Orca）

1. **细线**：`border border-border`，绝大多数元素在这一级。
2. **轻微浮起**：`shadow-xs` + 细线，描边按钮、内嵌卡片。
3. **悬浮**：`shadow-floating`（`0 10px 24px rgb(0 0 0 / .18)`），弹出菜单、浮窗、对话框。

不要发明第四级。需要更强调时用聚焦环，而不是更重的阴影。

| 用途 | 字体栈（`--nd-font-sans` / `--nd-font-mono`） |

## 4 间距与尺寸

- 基础单位 4px（Tailwind `1` = 0.25rem）。组与组之间的间距至少是组内间距的两倍。
- 卡片内边距 12～16px（`p-3`～`p-4`）。
- 阅读与表单页面内容最大宽度 760～960px；看板、终端、浏览器、自动化表格用全宽。

| 控件 | 高度 | 类 |

| 按钮 `default`、输入框 | 36px | `h-9` |
| 按钮 `lg` | 40px | `h-10` |
| 图标按钮 | 24 / 28 / 32 / 36 | `size-6` / `size-7` / `size-8` / `size-9` |

## 5 图标

- 只用 `lucide-react`。默认 `size-4`（16px），`Button` 内的图标自动是 16px。
- 元信息、密集行用 `size-3` / `size-3.5`；空状态大图标用 `size-7` 以上。
- 描边宽度用默认 2；侧栏导航未选中项用 `strokeWidth={1.75}`、选中项 `2.25`（照抄 Orca SidebarNav）。
- 颜色继承文字色：次要用 `text-muted-foreground`，危险用 `text-destructive`。
- 加载转圈统一 `<Loader2 className="size-4 animate-spin" />`；超过 3 秒的多步骤操作要显示阶段文字（§10）。
- 智能体图标（Claude、Codex、Gemini…）放在 `src/ui/components/nand/agent-icons/`（SVG），通过 `<AgentIcon agent="claude-code" size={14} />` 使用；Orca 的图标源文件在 `src/shared/agent-icons/` 和 `resources/`，许可见《参考映射与许可》。
- 用户在 Obsidian 里给文件设置的图标名，用 `<ObsidianIcon name="..." />`（内部 `setIcon`）。

## 6 选择正确的组件（照抄 Orca）

| 你想要… | 用 | 不要用 |
|---|---|---|
| 给纯图标按钮一个悬停说明 | `Tooltip` | `HoverCard`、`title` 属性 |
| 悬停预览较丰富的内容（会话摘要、批注线程只读预览） | `HoverCard` | `Tooltip` |
| 悬停后还能**编辑**的浮层（批注浮窗） | `Popover`（受控，悬停计时打开） | `HoverCard`（里面不应有可编辑表单） |
| 点击弹出的操作菜单 | `DropdownMenu` | `Popover` + 手写列表 |
| 右键操作 | `ContextMenu` | `DropdownMenu` |
| 点击弹出的表单/选择器 | `Popover` | `Dialog` |
| 必须先做决定才能继续 | `Dialog` / `AlertDialog` | `Popover` |
| 从边缘滑入的面板（手机抽屉） | `Sheet` | 居中 `Dialog` |
| 已知列表单选（≤7 项） | `Select`；2～4 项用 `SegmentedControl` | 自制列表框 |
| 需要搜索的单选 | `Command` 放进 `Popover` | `Select` |
| 短暂确认（已保存、已复制） | `toast()`（sonner） | `Dialog`、行内横幅 |
| 持续的行内状态（3 个错误） | 行内文字 + `Badge` | toast |

如果你发现自己在让一个组件“装成”另一个（用 Popover 当 Dialog），停下来换组件。

## 7 组件规则

### 7.1 Button

| 变体 | 用途 |
|---|---|
| `default` | 流程中唯一的确定动作 |
| `secondary` | 与 default 并列的次要动作 |
| `outline` | 工具栏、独立动作，实心太重时 |
| `ghost` | 图标按钮、列表行内触发器、需要“消失”的外框 |
| `link` | 段落内文字链接 |
| `destructive` | 删除、丢弃、不可撤销。**取消永远不是 destructive** |

尺寸按所在行高选：28px 的工具栏里不要放 36px 的按钮。图标按钮必须有 `aria-label`，并配 `Tooltip`。

### 7.2 Tooltip

- 只用来“命名”含义不明显的控件；不要在里面教学、警告或放可点击内容。
- 全局只有一个 `TooltipProvider delayDuration={400}`（在 `NandProviders` 里）。
- 触发器写 `<TooltipTrigger asChild>`，保证键盘聚焦也能显示。
- 默认 `side="top" sideOffset={4}`；状态栏里用 `side="top" sideOffset={6}`。
- 有快捷键时在说明后面加 `<ShortcutKeyCombo keys={…} />`，Mac 显示 `⌘ ⇧`，其他平台显示 `Ctrl+ Shift+`，且必须与真实绑定一致。

### 7.3 Dialog 尺寸

| 内容 | 尺寸 |
|---|---|
| 简短确认 | `max-w-sm` |
| 单个表单（重命名、新建 Profile） | `max-w-md` |
| 多字段表单（Cookie 导入结果、小组件配置） | `max-w-lg`～`max-w-2xl` |
| 编辑器级（自动化编辑、外观工作室、统计弹窗） | `w-[min(1080px,calc(100vw-2rem))] h-[min(880px,90vh)]`，内部分栏 |

打开时焦点落在最可能使用的输入框或主按钮上；Enter 触发主动作；Esc 关闭且不额外弹提示。

### 7.4 表单

- 结构（照抄 Orca `SettingsFormControls`）：外层 `space-y-3`；标签组 `space-y-1`，`<Label>` + `text-xs text-muted-foreground` 说明；控件用组件库；错误用 `aria-invalid`（组件已把它映射为危险色聚焦环）；脚注 `text-2xs text-muted-foreground` 放在控件下方。
- 设置行 `SettingsRow`：左侧 `min-w-0 flex-1` 标签+说明，右侧 `shrink-0` 控件；有说明时 `py-3`，否则 `py-2`。
- 中文输入法：所有文本框在 `compositionstart`～`compositionend` 期间不响应 Enter 提交（Orca 的 `ImeInput` 做的就是这件事，必须保留这个行为）。

### 7.5 列表行：悬停、键盘选中、当前

- 常态：透明背景。
- 悬停：`hover:bg-accent`（侧栏里 `hover:bg-sidebar-accent`）。
- 键盘高亮（cmdk 的 `data-selected`）：不要只用 `bg-accent`（亮色主题下几乎看不见）。用 `color-mix` 把前景色混入背景约 12% 再加内描边：`data-[selected=true]:bg-[color-mix(in_srgb,var(--foreground)_12%,var(--background))] data-[selected=true]:ring-1 data-[selected=true]:ring-inset data-[selected=true]:ring-border`。
- 当前项（正在查看的会话、当前设置分类）：`bg-accent` 加 `data-current="true"`。

### 7.6 滚动条

全局只定义三种滚动条类（在 `base.css`）：`.scrollbar-sleek`（细、中性，侧栏/列表/弹层默认）、`.scrollbar-sleek-parent`（父元素悬停才显示拇指）、`.scrollbar-none`（隐藏，看板横向卡片行用）。不要再写第四种。

### 7.7 空状态、加载、错误

- 空状态居中：图标（`size-7 text-muted-foreground`）+ 一句标题 + 一句说明 + 一个直接动作按钮（“新建终端”“导入 Cookie”），不说废话。
- 加载：骨架屏（`Skeleton`）优先于转圈；首屏 < 200ms 不显示任何加载态。
- 错误：需要用户阅读、重试、复制的错误放在行内（带“重试”按钮）；一次性的失败用 toast。

## 8 层级（z-index）

弹层渲染在每个窗口的 `div.nand-ui.nand-portal-root`（`display: contents`），各自用 Obsidian 的层级变量：

| 弹层 | z-index | Obsidian 对应 |
|---|---|---|
| 工作台内的粘性元素（标签条、表头） | `z-10` | — |
| 拖拽中的元素 | `z-[var(--layer-dragged-item)]`（80） | 拖拽项 |
| 菜单、下拉、弹出框、悬浮卡 | `z-[var(--layer-menu)]`（65） | 菜单 |
| 对话框、抽屉、遮罩 | `z-[var(--layer-modal)]`（50） | 模态框 |
| 提示（Tooltip） | `z-[var(--layer-tooltip)]`（70） | 提示 |
| 轻提示（sonner） | `z-[var(--layer-notice)]`（60） | 通知 |

对话框里打开的菜单也是 65，高于对话框的 50，所以不会被挡住。不要写裸数字 z-index。

## 9 看板主题桥

看板根元素 `.nand-dashboard-root[data-theme="<主题 key>"]`（例如默认的 `mono`）上先定义 apex 的 `--db-*` 变量（13 款主题 × 亮/暗，原样移植 apex `styles.css` 中的主题块，见《设计-首页看板》§9），再把组件令牌指向它们：

```css
.nand-dashboard-root {
  --background: var(--db-bg);
  --foreground: var(--db-text);
  --card: var(--db-bg-card);
  --card-foreground: var(--db-text);
  --popover: var(--db-bg-modal, var(--db-bg-card));
  --popover-foreground: var(--db-text);
  --primary: var(--db-accent);
  --primary-foreground: var(--db-text-on-accent, #fff);
  --secondary: var(--db-bg-btn);
```

## 10 动效与反馈

| 操作耗时 | 反馈 |
|---|---|
| 0～100ms | 无。任何可见变化都像闪烁 |
| 100ms～1s | 只显示禁用态 |
| 1～3s | 禁用 + 转圈或文字替换 |
| 3s 以上或多步骤 | 阶段文字（“正在读取 Cookie… 正在写入…”）、进度 |

- 预留空间：按钮可能变长时固定宽度（`w-…` 而不是 `min-w-…`），避免执行中控件跳动。
- 动画只用 `transform` 和 `opacity`；时长用 Obsidian 的 `--anim-duration-fast`（140ms）和 `--anim-duration-moderate`（300ms）。
- `prefers-reduced-motion: reduce` 时：移除位移、缩放、旋转（`motion-reduce:` 变体）；转圈保留一个静止的“工作中”图形；淡入淡出可保留。
- 脚本触发的滚动用 `behavior: matchMedia('(prefers-reduced-motion: reduce)').matches ? 'auto' : 'smooth'`。

## 11 无障碍

- 每个可交互元素是真正的 `button`/`input`（或 Radix 提供的等价物），有可访问名称，键盘可达，`:focus-visible` 时显示 `ring-[3px] ring-ring/50`。
- 目标尺寸 ≥32px（桌面）、≥44px（触屏）。纯图标按钮视觉上可以是 24～28px，但点击区域要扩到 32px（用 `relative` + 伪元素或外边距）。
- 列表用 `role="listbox"`/`option` 或 `menu`/`menuitem`，方向键移动；分组用标题关联。
- 只靠颜色表达的状态要同时有图标或文字（智能体状态：转圈/问号/对勾/圆点 + 悬停说明）。

## 12 文案规则

- **不夸大：** 只有代码拿到真实结果时，才用“已完成”“已保存”“已跳过”“已验证”这类结果动词；进行中用中性过程语言（“正在导入”）。
- 简洁具体，动词开头：“导入 Cookie”“新建终端”，不要“请点击这里以便您可以…”。
- 用“你”，不用“您”；中文与英文/数字之间加空格；全角标点。
- 状态文案统一：工作中 / 等待输入 / 已完成 / 已中断 / 失败 / 空闲 / 状态未知。
- 所有文案经 `t()`，en/zh 同时提供。

## 13 实现细节

```ts
// src/ui/lib/utils.ts
import { clsx, type ClassValue } from 'clsx';
import { extendTailwindMerge } from 'tailwind-merge';

// 不登记的话，tailwind-merge 会把自定义字号 text-2xs / text-3xs 当成颜色类，
// 与 text-muted-foreground 合并时把字号删掉（Orca 的 lib/utils.ts 同样这么做）。
const twMerge = extendTailwindMerge({ extend: { theme: { text: ['2xs', '3xs'] } } });

export function cn(...inputs: ClassValue[]) { return twMerge(clsx(inputs)); }
```

- 组件根元素保留 `data-slot="<名字>"`（shadcn 约定），便于 CSS 定位和测试。
- 合并类名时调用方的 `className` 放最后，让调用方可覆盖。
- 多个变体用 `cva`。
- 复制 Orca 组件时：删除 Orca 专有引用（`@/lib/ime-overlay-escape`、`translate()`、`useAppStore`），改成 NAND 的 `t()` 和服务；保留 Tailwind 类名原样。
- 不要在组件里读 `window`/`document`，用 `useOwnerDocument()`。
