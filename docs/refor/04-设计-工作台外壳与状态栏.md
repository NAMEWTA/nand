# 04 设计：工作台外壳与状态栏

外壳 = 图标轨 + 侧栏 + 页面框 + 状态栏。它负责“在哪里”，各模块负责“里面是什么”。本文给出每一部分的版式、尺寸、交互和状态。

## 1 总体版式

### 1.1 宽布局（工作台宽度 ≥ 960px）

```
┌────┬─────────────────────────┬──────────────────────────────────────────────────────────────┐
│ ⌂  │ 侧栏（可选，220–500px） │ 页面                                                          │
│ 🤖 │                         │  chrome='standard'：44px 页头 + 内容                         │
│ 👤 │                         │  chrome='none'    ：页面自己画顶部（标签条/横幅/标题栏）      │
│ ⏱  │                         │                                                              │
│ ⑂  │                         │                                                              │
│ ★  │                         │                                                              │
│    │                         │                                                              │
│ 🔔3│                         │                                                              │
│ ⚙  │                         │                                                              │
├────┴─────────────────────────┴──────────────────────────────────────────────────────────────┤
│ 状态栏 24px：用量 ……………………………………………………………………………………… 状态段                         │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 中等宽度（600～960px）

图标轨保留；侧栏变成浮层盖在页面上（半透明遮罩，Esc 或点遮罩关闭，焦点进入浮层，关闭后回到触发处）。

### 1.3 窄布局（< 600px 或手机）

图标轨和侧栏合并成一个从左侧滑出的抽屉（`Sheet side="left"`），由页面左上角的菜单按钮打开。状态栏在手机上隐藏（Obsidian 移动端没有空间），用量与状态改在页头芯片里显示。

布局档位按**工作台叶子自身宽度**判断（`ResizeObserver`），不是窗口宽度。沿用 `src/shell/layout.ts` 的 `layoutFor()`。

## 2 图标轨（Rail）

### 2.1 条目与顺序

| 位置 | 功能 id | 名称 | 图标（lucide） | 备注 |
|---|---|---|---|---|
| 上 | `dashboard` | 首页 | `house` | 始终显示 |
| 上 | `terminal` | 智能体 | `bot` | 桌面端；模块关闭时隐藏 |
| 上 | `contacts` | 档案 | `contact-round` | |
| 上 | `automations` | 自动化 | `timer` | |
| 上 | `sync` | Git 同步 | `git-branch` | 桌面端，默认关闭 |
| 上 | `icons` | 图标 | `images` | |
| 上 | `content` | 内容 | `files` | 受管内容浏览 |
| 下 | `notifications` | 通知 | `bell` | 未读数徽标 |
| 下 | `settings` | 设置 | `settings` | 始终显示 |

删除的条目：浏览器、新闻、批注、记录。

### 2.2 外观

- 宽 52px，背景 `bg-sidebar`，右侧 `border-r border-sidebar-border`。
- 按钮 36×36（`size-9`），`rounded-md`，图标 `size-[18px]`，`strokeWidth={1.75}`。
- 当前功能：`bg-sidebar-accent text-sidebar-accent-foreground`，图标 `strokeWidth={2.25}`，左侧 2px 竖条 `bg-foreground`（与 Orca 标签底部指示线同源的“当前”语言）。
- 悬停：`hover:bg-sidebar-accent/70`。
- 未读徽标：右上角 `min-w-4 h-4 rounded-full bg-destructive text-3xs text-destructive-foreground`，超过 99 显示 `99+`。
- 启动失败：右上角 6px 琥珀色圆点 + Tooltip “启动失败，点击查看”。
- Tooltip 在右侧（`side="right"`），文字为功能名。

### 2.3 交互

- 点击当前功能图标：切换侧栏开/合（无侧栏的功能则无反应）。
- 点击其他图标：回到该功能在这个叶子里上次的位置（`lastTargets`），侧栏开合状态保持。
- 键盘：↑↓ 在图标间移动，Home/End 到两端，Enter/Space 激活；F6 / Shift+F6 在图标轨、侧栏、页面、状态栏之间循环。
- 右键图标：菜单「在新标签页打开」「在分屏中打开」（专注模式）。

## 3 侧栏（SidePanel）

### 3.1 何时显示

| 功能 | 侧栏 |
|---|---|
| 首页 | 无（apex 没有侧栏；工作台切换在横幅药丸上） |
| 智能体 | 有：页面通过 `navigationEl` 自己渲染 Orca 左栏（见《设计-智能体工作区》§2） |
| 档案 | 有：分组与筛选（沿用现有） |
| 自动化 | 无（Orca 自动化页全宽） |
| Git 同步 | 有：变更 / 历史 |
| 图标 | 有：分区 |
| 内容 | 有：受管文件列表（可搜索） |
| 通知 | 有：未读 / 全部 |
| 设置 | 有：设置分类 + 搜索 |

### 3.2 外观（通用 PanelModel 渲染）

```
┌─────────────────────────────┐
│ 标题                     ✕  │  h-11 px-3，标题 text-sm font-semibold（窄布局才有 ✕）
│ [＋ 主操作               ]  │  可选，Button variant="outline" size="sm" w-full
│ [🔍 搜索…                ]  │  可选，Input h-8
│ 分组标题（11px 大写灰字）   │  text-2xs font-semibold uppercase tracking-wide text-muted-foreground px-3 pt-3 pb-1
│  ▸ 行（图标 · 标签 · 元信息 │  行高 28–32px，rounded-md mx-2 px-2，text-[13px]
│    · 徽标 · ⋯）             │  悬停显示 ⋯（DropdownMenu）；右键 ContextMenu 同内容
│  ▸ 行                       │
│ （空状态文字）              │  text-xs text-muted-foreground px-3 py-2
└─────────────────────────────┘
```

- 背景 `bg-sidebar`，滚动区 `.scrollbar-sleek`。
- 宽度拖动：右边缘 12px 宽的热区跨在分隔线上，悬停显示 1px `bg-ring/50`，拖动时 `bg-ring`；双击恢复默认 280px；键盘：聚焦后 ←→ 每次 8px，Home/End 到 220/500。
- 当前行 `bg-sidebar-accent` + `data-current="true"`。

## 4 页面框（PageFrame）

### 4.1 chrome = 'standard'

```
┌──────────────────────────────────────────────────────────────────────┐
│ [≡] 标题 · 状态芯片×≤3                         [在工作台中打开] [⋯] │  h-11 border-b px-3
├──────────────────────────────────────────────────────────────────────┤
│ 内容                                                                 │
```

- `[≡]`：侧栏收起、浮层或抽屉布局时显示的侧栏开关（`panel-left` / 窄布局 `menu`）。
- 标题 `text-sm font-semibold truncate`；页面忙时标题右侧出现 `Loader2 size-3.5`。
- 状态芯片：手机端（无状态栏）才显示，最多 3 个。
- `[⋯]`：页面菜单，包含页面提供的项 + 「在新标签页打开」「在分屏中打开」 + 资源页的「关闭当前页面」。
- 专注模式叶子：没有图标轨和侧栏，页头多一个「在工作台中打开」。

### 4.2 chrome = 'none'

外壳不画页头。页面必须自己提供：

1. 一个可见的标题或身份（横幅、标签条、“自动化”标题栏）；
2. 页面菜单入口（`[⋯]`），调用外壳提供的 `context.openPageMenu(event)`，以保留「在新标签页打开 / 分屏」；
3. 侧栏收起时的侧栏开关（调用 `context.togglePanel()`）。

### 4.3 页面不可用时

照旧显示居中的空状态（`EmptyState`）：功能已关闭（按钮“在设置中开启”）、设备不支持、启动失败（“重试”）、资源不存在。

## 5 状态栏（照抄 Orca StatusBarSurface）

### 5.1 版式

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│ [已用] (C)▬▬ 78% 5h · 94% 周   (X)▬▬ 100% 5h · 80% 周   +1  ⟳          ⟳2  ?1  ⏱1  ⑂↑3  🔔3 │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
  └──────────── 用量区（左，可折叠）───────────────────────┘          └── 状态段（右，不裁剪）──┘
```

- 容器：`flex items-center h-6 min-h-[24px] px-3 gap-4 border-t border-border bg-sidebar text-xs select-none shrink-0 whitespace-nowrap overflow-clip`。
- 左右两簇：左簇 `min-w-0 flex-1 overflow-clip`（空间不足时先压缩它），右簇 `shrink-0`（不足时可横向滚动，不消失）。

### 5.2 用量区

整个用量区是一个按钮（`DropdownMenuTrigger`），点击打开用量面板（§5.3）。

**单位标签**（可选）：最左侧灰色小字 `已用` 或 `剩余`，取决于设置“用量显示：已用 % / 剩余 %”；空间不够时第一个隐藏。

**提供方片段**（每个启用且支持额度的智能体一个）：

```
(图标14px) [迷你条 48×6，仅详细模式] 78% 5h · 94% 周   [⚠ 过期时]
```

| 状态 | 显示 |
|---|---|
| 首次加载 / 读取中且无旧数据 | 图标 + `···`（`animate-pulse`） |
| 未安装 | 图标 + `--`（50% 透明） |
| 出错且无旧数据 | 图标 + `⚠` + 简短原因（“未登录”“读取失败”），紧凑模式只有图标和 ⚠ |
| 有数据 | 图标 + 迷你条（最紧张窗口）+ 各窗口 `百分比 标签` 用 `·` 分隔 |
| 有数据但最近一次失败 | 同上 + 末尾 `⚠`（灰） |

- 窗口标签：`5h`、`周`、`月`、模型桶名（如 Gemini 的 `Pro`/`Flash`）；“剩余”模式下显示剩余比例。
- 颜色：最紧张窗口用量 <80% 正常色；80%～95% `text-status-warning`；≥95% `text-destructive`；迷你条填充 `bg-muted-foreground/40`。
- 精简模式（用户在面板里选）：每个提供方只显示最紧张的一个窗口：`(C) 94% 周`。
- **自动折叠：** 用 `ResizeObserver` 测量。宽度不够时：① 先切换到精简模式；② 再从右往左把提供方片段收进 `+N` 芯片（`h-4 rounded-full border px-1.5 text-2xs`，颜色取被收起者中最紧张的语气，`title` 列出它们的名称和百分比）；③ 最后连单位标签也隐藏。被收起的片段保留在 DOM 中（`invisible absolute`）以便测量恢复。
- 用量区右侧：刷新按钮（`RefreshCw size={11}`，读取中旋转），Tooltip “刷新用量数据”。

**空状态：** 没有任何支持额度的智能体启用时，用量区显示一个 `ghost` 小按钮“设置用量跟踪”，点击打开设置 → 智能体。

### 5.3 用量面板（UsageRosterPanel，360px 宽，向上弹出）

```
┌──────────────────────────────────────────┐
│ 用量                       全部智能体  ⟳ │  px-3.5 pt-3 pb-2；标题 13px semibold
│ [   详细   |   精简   ]                  │  SegmentedControl size=sm equalWidth
├──────────────────────────────────────────┤
│ [C] Claude · Max            重置 2h 14m ›│  行：图标盒 20px（rounded-md border bg-secondary）
│     5h ▬▬ 78%   周 ▬▬ 94%   Fable ▬ 40% │       名称 13px medium · 计划灰字；第二行各窗口
│ [X] Codex · Plus                       › │       指标：标签 10px · 条 28×5 · 百分比 11px
│     5h ▬▬ 100%  周 ▬▬ 80%               │
│ [G] Gemini           未登录      [登录]  │  无数据：状态文字 + 可选“登录”
├──────────────────────────────────────────┤
│ 用量详情与历史                         › │  打开智能体 → 用量统计页
│ 管理账号…                              › │  打开设置 → 智能体 → 账号
└──────────────────────────────────────────┘
```

- 行按“最紧张窗口的已用百分比”从高到低排序。
- 精简模式：每行只在右侧显示最紧张窗口。
- 重置倒计时：取各窗口最早的 `resetsAt`，格式“2h 14m”“3d 5h”；一个面板共用一个计时器，只在需要时（分钟边界）刷新。
- Claude 和 Codex 行右侧 `›` 打开**子菜单**：账号列表（单选，当前账号打勾）、“添加账号…”、“在设置中管理”；其他提供方行点击打开该提供方的统计页。
- 面板用 `DropdownMenuContent side="top" align="start" sideOffset={8} collisionPadding={{ top: 8, bottom: 32, left: 8, right: 8 }} className="w-[360px] p-0"`。

### 5.4 状态段（右簇）

由各功能贡献的 `statusSegments()` 汇总，按 `order` 排序。每段是一个 `ghost` 小按钮（`h-5 px-1 gap-1 rounded`），图标 `size-3.5` + 数字 `tabular-nums`，Tooltip 写完整说明，点击跳转。

| 顺序 | 段 | 显示条件 | 外观 | 点击 |
|---|---|---|---|---|
| 10 | 等待输入的智能体 | ≥1 | 橙色 `?` 图标 + 数字，`text-agent-question` | 跳到第一个等待的会话 |
| 20 | 运行中的智能体 | ≥1 | 转圈图标 + 数字 | 智能体工作区 |
| 30 | 运行中的自动化 | ≥1 | `timer` + 数字 | 自动化 → 运行记录 |
| 40 | 自动化加载失败 | 出错 | 红色 `triangle-alert` | 自动化页 |
| 50 | Git 同步 | 冲突/失败/暂停/有未推送提交/同步中 | `git-branch` + 简述（“冲突 2”“↑3”“同步中”） | Git 同步页 |
| 60 | 看板未保存 | 保存失败 | 红色 `save-off` | 首页 |
| 90 | 通知 | 未读 ≥1 | `bell` + 数字 | 通知页 |

### 5.5 右键菜单（StatusBarVisibilityMenu）

在状态栏任意空白处右键，于指针位置弹出菜单：

- 勾选项：用量、等待输入、运行中、自动化、Git 同步、通知（取消勾选即隐藏该段）。
- 单选组“用量数值”：已用 % / 剩余 %。
- 单选组“用量详细程度”：详细 / 精简。
- 分隔线后：“隐藏状态栏”（之后可在 设置 → 常规 → 状态栏 重新打开）。

### 5.6 与 Obsidian 状态栏的关系

- 默认只显示工作台状态栏。
- 设置 → 常规 → “在 Obsidian 状态栏显示精简用量”（默认关）：开启后在 Obsidian 底部状态栏加一项，内容同精简模式用量区，点击打开工作台智能体页。
- 现有的“Obsidian 状态栏显示待处理事项”功能删除（由工作台状态栏取代）。
