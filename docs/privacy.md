# 隐私与数据边界

本页只写当前代码里的边界。它不是“绝不上传”或“全部加密”的承诺。你之后在 CLI、浏览器或系统里做的事，由那些程序和你自己的操作决定。NAND 没有遥测，也没有统计分析。

## 记录什么

全部 NAND 管理的数据在当前库 `.nand/`。档案正文及其他受管 Markdown/附件在 `.nand/content/`，每个人或企业一份 `基本信息.md`；普通笔记、宿主自身数据与 Git 元数据保留原位置。请把 `.nand/recovery/` 当作敏感资料对待：里面是你正在编辑内容的恢复副本。浏览历史和站点权限在 `.nand/browser/`，终端智能体的历史标注在 `.nand/terminal-agent/`。各个目录的分工见[数据与恢复](data.md)。

笔记导航器的日历、模板、合并笔记和标签操作只读写库里的笔记和 NAND 设置，不联网。合并和标签修改会改写或新建你的普通笔记；撤销用的修改前内容只放在内存里，不写入磁盘。用模板新建笔记时，若启用了 Templater 并选用它，模板由 Templater 处理，它的行为由那个插件决定。

设置是明文 JSON。微信读书 API 密钥、滴答会话 Cookie（`t`）和 CSRF 令牌保存在 `.nand/config/devices/<device-id>.json`，不放入整库设置 `.nand/config/settings.json` 或看板 Markdown。设备分区只是数据归属，不是加密或自动排除同步；同步、备份或 Git 推送该设备文件仍会带上凭据。

看板技能模板是笔记中可见的 YAML。派发历史在 `.nand/automation/<device-id>/runtime.json` 中以明文保留最终提示词、选中文件引用、来源和交付回执。新会话把这些材料交给所选 CLI 及其配置的服务商；粘贴到既有会话时由你自行提交。这些快照不是诊断日志，不经过日志脱敏。

技能选择器读取本地 `SKILL.md` 以提取名称，不执行文件，也不把内容发送给服务商。只有打开或刷新时才扫描文档列出的三个库内目录。额外目录由用户在设备设置中明确配置，仅桌面端读取；留空时不扫描额外目录。记住的名称和目录路径保存在设备设置中，可在智能体设置里清除；发现过程不修改技能文件。

在桌面 POSIX 环境 上，私有 `.nand/` 目录使用 `0700`，文件使用 `0600`；启动时会收紧既有托管文件的权限，Git 克隆后也会重新应用。NAND 拒绝私有路径中的软链接，不修改普通笔记权限。这是本机访问控制，不是加密，也不限制 Git 上传。账号/helper在 Windows 通过 DACL 限定为当前用户与 SYSTEM，权限失败阻止启动；移动端权限行为不能冒称已实测。修复行为见[数据与恢复](data.md#私有文件权限)。

诊断日志在打印前会做脱敏：库路径和用户主目录会被替换，URL 里的账号信息，以及常见的令牌、口令和密钥查询参数会被遮住，Bearer 令牌和 `token=…` 形式的赋值也会被遮住，过长的文字会被截断。终端画面、你的 Markdown 和你自己复制的内容不经过这个脱敏，调试开关也不能绕过它。

## 联网

档案搜索和列表/卡片切换只读已经建好的内存索引，不发网络请求。下面的功能只在开启并被使用时才联网。终端组件使用标准输入输出与 NAND 通信。

| 功能 | 何时 | 发送什么，发给谁 |
|---|---|---|
| 浏览器 | 你打开网页、搜索、下载 | 你访问的网站收到的内容。不是地址的文字会发给你选择的搜索引擎（Google、Bing、百度、DuckDuckGo 或自定义 HTTPS 模板） |
| 看板的网页分区 | 分区显示时 | 配置的地址会被请求一次以读取其框架策略头，随后网页在看板中加载。网页快捷卡片在你打开之前什么也不加载 |
| 终端组件 | 第一次打开终端时 | 从插件版本对应的 GitHub Release 下载 `nand-pty-<平台>-<架构>` 及其校验值，不发送库内数据。离线模式从不联网 |
| 智能体额度 | 用量页打开，或额度显示在状态栏 | 对每个已启用的智能体，NAND 读取 CLI 保存在本机的登录信息，并调用提供方的额度接口（Anthropic、OpenAI/ChatGPT、Google、xAI/Grok、OpenCode 等） |
| 天气小组件（默认关闭） | 小组件开启 | 你选的城市的坐标发给 Met.no、wttr.in 和 Open-Meteo；城市搜索发给 Open-Meteo |
| 农历万年历小组件（默认开启） | 小组件显示时 | 年份，用来向 `timor.tech` 获取公共假日数据；结果缓存一天 |
| 阅读小组件 | 你搜索书籍时 | 你输入的文字发给 `book.douban.com`；并会获取书籍封面地址 |
| RSS 分区 | 配置源后分区显示、手动刷新或在配置中刷新；阅读文章时按需抓取正文 | 请求所配 HTTP(S) 订阅源；源内容不足且没有正文缓存时请求文章链接所在站点。请求含 RSS User-Agent 与 Accept 头，不发送滴答或微信读书凭据；源 URL 自带的查询参数会发送给该站点。阅读器渲染文章中的图片等外部资源时，资源站点也会收到请求 |
| 微信读书分区 | 配置密钥后加载书架、统计、笔记或手动刷新、导入划线 | 通过 `i.weread.qq.com/api/agent/gateway` POST 请求读取账号的书架、阅读统计和笔记；Authorization 头携带 Bearer 密钥 |
| 滴答清单 | 登录校验、已配置分区显示或刷新、操作任务 | 只向所选地区的 `api.dida365.com`（中国）或 `api.ticktick.com`（国际）发送会话 Cookie 与客户端设备标识，读取清单、任务、习惯和打卡。完成/恢复、改名、日期、优先级、排序会发送对应任务 ID/字段并附加 CSRF Cookie 和请求头；仅有会话 Cookie 时不可写入 |
| 音乐播放器（默认关闭；手机不可用） | 你搜索或播放时 | 向 `music.163.com` 发请求；可选的登录使用该网站的窗口 |
| Git 同步（默认关闭） | 获取、拉取和推送，手动或定时 | Git 连接你配置的远端。提交在你推送之前只留在本机 |
| 智能体和脚本 | 你运行它们时 | CLI 或你的脚本做的事，NAND 无法控制 |

RSS 的文章列表、已读/已保存标记和提取的正文缓存保存在 `.nand/cache/rss/` 下的 `rss.json`。默认成功缓存 30 分钟、失败重试间隔 5 分钟；网页正文缓存保留 30 天，列表最多 100 个源、每源 50 篇，已读标记按设置清理。保存文章与导出 OPML 默认在 `.nand/content/` 下的 `NAND/RSS/`，可选择其他受管内容子目录；保存 Markdown 保留文章里的图片链接，之后打开也可能加载远端图片。缓存、订阅地址和导出的 OPML 可能暴露阅读偏好。

滴答的请求结果只作当前客户端内存缓存（60 秒），任务不会自动导出成本地笔记。网络请求使用 Obsidian `requestUrl`；滴答在 15 秒后结束逻辑等待，隐藏页面、关闭登录或换账号会丢弃旧请求结果，但不能撤回已发到服务器的请求。写入超时会重新读取核实，不自动重复写入。桌面登录会打开所选地区的 `dida365.com` 或 `ticktick.com` 登录网页，由该服务处理账号输入；登录成功后读取会话和 CSRF Cookie。登录浏览器会话在库内 `.nand/browser/` 的设备/profile 会话目录，包含站点 Cookie/缓存；关闭登录窗口不会自动删除既有站点会话。手动保存和弹窗登录都先验证凭据；取消、隐藏或换账号使尚未提交的校验失效。

看板备份位于 `.nand/recovery/dashboard/backups/`，包含工作台 Markdown 与记录 JSON，并记录来源路径和完整性清单。恢复只匹配同一工作台；覆盖前另存 `before-restore` 副本，该副本不参与常规备份数量清理。备份和恢复副本也可能含私人笔记与记录。

## Cookie 导入

导入由用户打开个人资料的导入入口发起，届时才检测本机浏览器。数据库及存在的 WAL/SHM 复制到 `.nand/browser/<device-id>/tmp/<随机 ID>/`，终端辅助程序只读解析；完成、失败或取消后的读取结束时删除快照。来源文件不修改，删除临时文件不等于安全擦除。导入期间同步/备份工具仍可能复制它们。

解密使用本机的 Keychain、Linux 钥匙环或 Windows DPAPI；不可用、加密版本不支持及无效 Cookie 会有明确失败/跳过信息。NAND 到固定密钥桥的输入走 stdin；`security` / `secret-tool` 系统 CLI 不支持把查询条件放入 stdin，所以最终仅通过 argv 接收非机密 service/account/application 查询元数据。密码从 stdout 返回，Cookie 密文及密钥不放入 argv，不写诊断日志。Windows 解密数据经 stdin 传递。

可另选 Netscape `cookies.txt` 或 JSON 数组。导入先验证，再替换成功验证的精确域名；其他父域、子域和无关域保持原样，Google 及其子域不导入。完全无法写入时保留原 Cookie。Cookie 进入所选个人资料的库内 Session，网站会在后续访问时收到适用 Cookie；不同资料的 Cookie、localStorage 和缓存隔离。导入本身不把来源数据库上传到外部服务。

Cookie、账号凭据、浏览历史、下载和抓取附件都在 `.nand/browser/` 中，按敏感数据备份。跨设备不能保证登录继续有效，站点可能要求重新认证。不要将含登录状态的目录公开推送。

## 自动化预检

预检使用 `.nand/automation/<device-id>/precheck-home/` 中的 HOME、配置和临时目录，并检查受管目录链；这只限定 NAND 为命令配置的数据位置。**自动化预检不是安全沙箱**：命令拥有宿主用户权限，能主动访问其他路径或联网。超时/取消时尽力结束进程组和可识别后代，刻意脱离会话的后台进程不保证回收。

## Git 同步

Git 同步默认关闭。开启后，NAND 在库目录中启动本机的 `git` 进程。只有在拉取、推送或获取（手动或按设置定时）时，Git 才会连接你配置的远端；提交只发生在本机。NAND 不询问也不保存账号密码，认证由 Git 的凭据管理器或 SSH agent 完成；显示给你的 Git 错误输出会遮去地址中的账号和令牌。

提交的内容就是库里的文件。`.gitignore` 之外的笔记、附件和 `.nand/` 中的设置都会进入仓库，包括恢复草稿、浏览历史和可能含有 API 密钥的设置文件。推送前请确认谁能读取远端，并把不想公开的路径加入 `.gitignore`。自动同步的计时与暂停状态位于 `.nand/sync/` 的设备/仓库文件；同步后也不会自动领取另一设备的运行。详见 [Git 同步](sync.md)。

## 交给智能体的材料

网页正文和截图是不可信的材料。把它们附加到运行中的智能体会话时，NAND 用括号粘贴放进输入区，不在末尾追加 Enter。材料里的 ESC 和其他控制字符会被去掉，避免一段网页文字自己结束粘贴并变成按键。图片与说明保存在 `.nand/browser/<device-id>/artifacts/`，停用浏览器时仍保留这些附件。

原生 CLI 历史只读，NAND 不会修改 CLI 自己的日志文件。“本库”按工作目录的真实路径筛选，“全部”不限工作目录；这只是显示筛选，不是读取范围：无论当前选哪个账号，NAND 都会扫描系统账号（你本机 CLI 自己的会话目录，如 `~/.codex/sessions`）和已登记的托管账号（当前库 `.nand/agents/` 下的目录），并把标题、提示词文本、工作目录和用量写进库内的可重建索引 `.nand/terminal-agent/<device-id>/index.sqlite`，其中包括库外会话的内容；备份或同步 `.nand/` 时这个索引会一起带走。只有各 CLI 的会话日志会被读取（登录和设置文件不会），路径须通过校验，查询和读取缓存时会重新检查来源，拒绝软链接或已失效的来源。恢复会话仍要求工作目录位于当前库内。

## 库之外的文件

NAND 自身的新数据不写到全局 CLI HOME、Obsidian 应用数据或插件运行目录，唯一的例外是系统账号的状态 Hook。默认的系统账号让 CLI 使用你本机已有的登录，NAND 不复制、不上传这些凭据。状态 Hook 会在 `~/.nand/agent-hooks/` 放一份所有库共用的脚本（备份也在该目录，可能含你的原配置），并在你真实的 CLI 配置里为每个事件加一条固定、与库无关的命令；它在 NAND 终端之外不做任何事，不联网、不记录提示词。这些条目不会随关库或停用模块而移除，只有你在设置里点“移除系统状态 Hook”才会按完整命令串精确移除；NAND 不会写入符号链接、越出你主目录的路径或无法解析的 JSON（细节见[智能体工作台](agent-workbench.md#状态-hook)）。托管账号的登录、浏览器会话、下载均按库内设备/账号/profile划分；截图与说明作为受管附件保存。NAND 不会把系统登录复制进库内；托管账号的登录由你在该账号里自己完成，保存在库内，随 `.nand/` 一起被同步或提交时需自行留意。由用户自行维护的全局 CLI 配置、普通笔记、宿主数据与 Git 自有元数据不自动搬迁。

配置、账号凭据、Cookie、草稿、运行提示词和会话记录可能含敏感内容。`.nand/` 的访问控制不是全量加密；受保护 helper 回执也不加密全部资料。选择同步或 Git 推送时，请自行核对远端访问范围。登录状态跨设备可能无法使用，需要重新认证。
