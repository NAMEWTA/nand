# 隐私与数据边界

这里只写当前代码里的边界。它不是「绝不上传」或「全部加密」的承诺。用户之后在 CLI、浏览器或系统里做的事，由那些程序和用户自己的操作决定。

## 记录什么

档案正文在用户选定的资料目录里，每人一份 `基本信息.md`。NAND 自己的配置和运行数据在当前库的 `.nand/`，其中 `.nand/recovery/` 是恢复副本，按敏感资料对待。浏览历史和站点授权在 `.nand/browser/`。终端历史标注在 `.nand/terminal-agent/`。这些路径的分工见 [数据与恢复](data.md)。

诊断日志在打印前做脱敏：去掉 URL 里的账号信息，并遮住常见的令牌、口令和查询参数。终端画面、用户 Markdown 和用户主动复制的内容不经过这个脱敏函数。调试开关不能绕过它。

## 联网

档案搜索和列表／卡片切换只读已经建好的内存索引，本身不发网络请求。浏览网页、下载和查询订阅额度是单独的操作，只在对应功能开启并被使用时发生。关闭可选的联网模块后，档案搜索不会因此去联网。

## 交给 Agent 的材料

网页正文和截图是不可信材料。附加到已启用的 Agent 会话时，NAND 用括号粘贴放进输入区，不在末尾追加 Enter。材料里的 ESC 和控制字符会被去掉，避免一段网页文字自己结束粘贴并变成回车。普通 Shell 不会继承 Agent 专用的浏览器连接变量。浏览器连接令牌留在当次运行的内存里，写给 CLI 的 `connection.json` 只有端点，没有令牌。停用浏览器时清掉该次运行的已知临时文件，不递归删除 `.nand/recovery/`，也不收走已经交给 Agent 的附件。

原生 CLI 历史只读。归属按库目录的真实路径判断，不用一个相似的目录前缀把库外会话算进来。NAND 不改 CLI 自己的日志文件。
