# 习惯、记账、阅读与番茄记录

在看板设置启用所需小组件，从侧栏或窄屏面板打开。领域服务负责业务记录，面板负责输入和显示。

| 领域 | 资料 | 默认目录 |
|---|---|---|
| 习惯 | 习惯定义、打卡记录 | NAND/习惯/ |
| 记账 | 分类、收入和支出记录 | NAND/记账/ |
| 阅读 | 书籍、阅读记录 | NAND/阅读/ |
| 番茄钟 | 活动、专注记录 | NAND/番茄钟/ |

习惯与书籍各自使用带短 ID 的目录，定义为 Markdown；记录按年份和日期分文件，正文表格中的行有稳定 ID。记账分类与番茄活动分别保存在领域目录的“分类.md”和“活动.md”。

## 保存状态

界面区分保存中、已保存、未保存和冲突。出现未保存时打开错误详情、检查文件权限或同步状态，再重试；只有保存成功才可依赖重启恢复。

读取失败和文件损坏不会被当成空数据覆盖。并发更新比较打开时基线、当前编辑和最新磁盘内容：独立修改可以合并，同一记录冲突保留双方信息；删除不会通过简单集合并集恢复。

故障草稿保存在 `.nand/recovery/drafts/`。实体删除采用保留文件的删除标记，不自动清除旧文件。手工更改身份标识或受管表格会影响识别，请先备份。

业务记录不会因为界面分页或自动化运行历史限额而被清理。备份整个领域目录及需要的配置，参见 [数据与恢复](data.md)。
