# 图标使用指南

NAND 的图标模块可以为文件、文件夹、标签、属性、书签以及部分界面入口设置图标和颜色，也可以用规则批量应用。模块默认开启，要求 Obsidian 1.12.0 或更高版本。

## 开始使用

1. 打开 **设置 → NAND → 首页**，确认“图标”已开启。
2. 打开一篇笔记，在命令面板执行 **NAND：更改当前文件的图标**。
3. 在选择器中搜索图标，例如 `star` 或 `folder`；点击搜索结果即应用并关闭选择器。底部按钮可切换图标与 Emoji 搜索。
4. 需要调整颜色时，使用搜索框旁的颜色控件；只改颜色后可以点击“保存”。

也可以在受支持的项目右键菜单中更改图标。桌面端默认支持点击图标打开选择器；此行为可在 **设置 → NAND → 图标 → 可点击的图标** 中调整。

界面文案跟随 NAND 的语言设置。图标名称和搜索关键词保留上游英文资源，使用英文关键词搜索通常更直接。

## 用规则批量设置

在 **设置 → NAND → 图标 → 规则书 → 管理** 中打开规则书，或执行 **NAND：打开规则书**。文件规则与文件夹规则分别管理。

例如，为 Markdown 文件统一设置图标：

1. 在文件规则中新增规则，填写便于识别的名称。
2. 添加条件：扩展名等于 `md`。
3. 选择图标和颜色，启用规则并保存。

规则支持文件名、路径、标签、属性、日期等条件。多条件可以按“全部”“任意”或“均不满足”组合。多条已启用规则匹配同一项目时，按规则列表顺序采用第一条命中的规则；可调整规则顺序。

如果手动更改图标后显示与预期不同，先检查规则书中是否有命中的规则。选择器会提示影响当前项目的规则。文件内容与规则配置分别保存，配置图标不会把规则写入笔记正文。

| 侧边栏和标签页标题 | 显示所有文件夹图标 | 关闭 |
| 侧边栏和标签页标题 | 最小文件夹图标 | 开启 |
| 侧边栏和标签页标题 | 显示 Markdown 标签图标 | 开启 |
| 编辑器 | 显示标题图标 | 开启 |
| 编辑器 | 显示标签胶囊图标 | 关闭 |

| 菜单和对话框 | 显示建议图标 | 关闭 |

Obsidian 1.12 使用旧版设置界面，1.13 起使用声明式设置界面。两者配置项目相同；保留上游的搜索数量滑块范围差异：旧版为 50–500，声明式为 50–300，结果组件最多展示 300 项。

## 数据、备份与关闭模块

图标数据保存在库内 `.nand/icons/iconic.json`，备份保存在同一目录。

| 文件 | 内容 |
|---|---|
| `.nand/config/settings.json` | NAND 的主设置；图标领域只在其中保存模块开关 |
| `iconic.json` | 图标与颜色、文件和文件夹规则、图标偏好、选择器状态 |
| `iconic.json.backup1`、`.backup2` 等 | 图标数据的自动备份；编号越小越新 |

保存会合并约 300ms 内的连续修改。自动备份默认保留 2 份，可设为 0–9 份；保存时若距上次备份已满 3 小时，则轮换备份。这不是每次修改都产生一个历史版本。

主文件缺失、无法解析或为空对象时，若存在第一份备份，插件会尝试恢复它并显示通知。恢复过程使用 `.backup1`，不会逐个寻找后续可用备份。需要手动恢复时，先关闭图标模块，另存当前主文件及备份，再把确认有效的备份复制为 `iconic.json`，然后重新开启模块。

关闭图标模块会撤下图标界面修改、关闭所属弹窗并停用相关命令，已保存的数据会保留。重新开启后继续读取该文件。模块开启期间，外部修改会通过文件监听及窗口重新聚焦等检查触发重载。

## 常见问题

| 现象 | 检查方法 |
|---|---|
| NAND 顶部没有“图标”页签 | 在首页开启图标模块；关闭的领域不显示页签 |
| 找不到“更改当前文件的图标”命令 | 确认模块已开启，并先打开一篇文件 |
| 搜索不到中文描述的图标 | 尝试英文名称或关键词，并检查图标／Emoji 搜索模式 |
| 新图标被规则覆盖 | 检查规则书、命中条件和规则顺序 |
| 删除自定义图标后仍显示图标 | 检查匹配规则及“显示所有文件／文件夹图标”设置 |
| 同时装有独立 Iconic | 使用 NAND 图标模块时停用独立 Iconic，避免同时修改同一界面；NAND 不会自动导入它的数据 |
