# 编辑器与评论

在首页开启“编辑器”，在笔记中选中文字，通过评论入口添加讨论。编辑器侧边面板显示线程；支持回复、处理评论，以及从评论定位关联内容。

评论以文件、选区和原文锚点关联笔记，评论正文不会插入或改写原笔记。编辑、重命名和移动后，系统会尝试维护锚点；无法确认位置时显示失效状态，不能把旧位置视为可靠定位。

关闭评论面板只隐藏界面。关闭模块会清理所属浮层、停止交互并完成已接收的保存；已保存评论保留。未提交的输入需在关闭前完成保存。

## 保存与恢复

评论、线程索引和恢复事务位于 `.nand/editor/comments/`，属于必要的旁路 JSON。备份笔记时同时备份此目录；仅复制原笔记不会带走评论。

保存失败后检查原笔记和旁路目录的可读写状态。不要删除锚点或事务文件尝试强制修复；先复制需要保留的输入并备份，再检查错误和有效快照。评论位置恢复不能替代文件备份。

编辑器设置还提供复制引用等功能；写作统计与专注领域目前是预留模块。
