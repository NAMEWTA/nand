# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.0.1-alpha.1 | Yes |

## Reporting a vulnerability

Report it in the Issues of [NAMEWTA/nand](https://github.com/NAMEWTA/nand). There is no separate bounty program or security mailbox.

Keep the following out of public content:

- Access tokens, cookies, connection commands, `NAND_BROWSER_TOKEN` or CLI login credentials
- Archive text from your vault, terminal transcripts, web page screenshots or copies from `.nand/recovery/`
- Other people's email addresses, phone numbers or other personal data

Name the affected module, your Obsidian version and your operating system. To reproduce the problem, use a temporary vault with fake data.
