## 文档规则

当前源码、配置与可复现检查优先于旧说明。文档正文以简体中文为主，代码标识与许可证遵循来源。产品界面通过领域 I18N，默认中文，可选英文，入口为首页通用设置。

docs 只承载用户操作与必要第三方声明；实现日志和验收证据进入开发基线。context 定义术语，ADR 解释决定，不互相复制整段实现。

本轮经用户明确授权，用当前基线替换旧阶段档案；旧内容不在仓库内另存备份。以后更新以当前事实为准，阶段材料只有仍有验收价值时才保留。不能修改历史测试日期或把旧二进制结果当成当前构建结果。

变更条目仅保留真实未完成工作。status.json 与实际目录同步；清理后检查入口、链接和附件，删除范围限定为已授权的文档资产。第三方许可与固定来源声明持续保留。
