## 当前成果

- 保留五层架构、Obsidian 原生宿主、Preact 面板和 Rust PTY；终端执行状态独立于呈现界面。
- Markdown 保存业务资料，必要 JSON 进入 `.nand/`；文档保真、并发合并、保存状态和故障恢复由仓储负责。
- 手动／定时操作共用公共执行入口，看板保存动作引用；Agent 和浏览器通过会话与上下文材料接口协作。
- 首页先显示通用设置，再显示模块开关。中文默认、英文可选，关闭看板后仍可修改语言；声明式设置和回退渲染共用入口。
- 语言与普通设置共用保存队列。写入成功才发布语言，失败保留原选择；后续设置保存不会把旧语言写回。
- 看板更新已挂载面板，原生标签使用明确的翻译绑定；保留输入、草稿、焦点和选择范围。后台表单刷新不抢占确认弹窗焦点。用户内容不参与文本匹配翻译。
- 用户指南、13 份有效 ADR、领域上下文与状态索引已统一；旧阶段文档、重复归档和失效附件已清理，第三方许可证和来源声明保留。

## 验收边界

- 回退界面是在 1.13.7 中调用验证；真实 1.12.0 和移动端仍待验收。模块全部隐藏的用例检查语言入口，不等于逐一实机停用全部运行时。
- 终端实测使用隔离 PowerShell，浏览器使用本机夹具页面；没有登录或调用真实 Agent 账号。
- 5,000 份档案与 10,000 条记录属于内存夹具测试，不能替代实体磁盘与长期并发性能验证。
- 本轮没有重新运行 Rust 单元或跨平台原生矩阵，不将先前结果改日期后当作本轮结果。
- 截图和代表性界面用例不等于穷举所有操作系统、输入法、第三方主题与弹窗组合。
