# 看板

**看板工作区**：由一份被选择的看板 Markdown 笔记承载的看板内容。切换工作区改变当前看板来源。
_Avoid_: 终端工作台、Obsidian 工作区

**区块**：看板中组织卡片或特定功能面板的内容分区。
_Avoid_: 功能模块

**卡片**：看板内承载任务、项目、便笺或其他内容的可视单元。
_Avoid_: 档案卡片

**看板待办**：属于看板笔记的任务项，完成状态和提醒元数据随该来源维护。
_Avoid_: 独立自动化定义

**小组件**：看板中展示日历、倒计时、习惯、记账等特定能力的部件，其服务可具有独立于界面的生命周期。
_Avoid_: 每次打开才存在的任务

**文档库**：在看板中按文件、属性及查询结果组织已有库内笔记的展示功能。
_Avoid_: 档案资料目录

**DQL 结果**：由 NAND 看板查询求值产生、可用表格等方式呈现的数据结果。
_Avoid_: 第三方插件实例

**账本**：记账领域中可筛选、分页和编辑消费记录的明细视图。
_Avoid_: 通知历史

**番茄钟活动**：用于区分专注记录的活动分类，与专注或休息计时状态分开。
_Avoid_: 自动化运行
