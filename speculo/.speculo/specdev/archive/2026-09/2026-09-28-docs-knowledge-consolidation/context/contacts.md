# 档案

**档案记录**：人物或企业的结构化资料，拥有稳定身份并保存为一份可见 Markdown。
_Avoid_: 历史归档、文件名

**联系人**：档案中已收录的人物，可以有多段任职和直接人际关系。
_Avoid_: 企业实际全部员工

**企业**：档案中的组织记录，其人员列表从已收录联系人的任职派生。
_Avoid_: 自动生成的联系人分组

**档案身份**：跨显示名和文件路径变化仍标识同一记录的 nand-id。
_Avoid_: 姓名、文件名

**任职**：联系人与企业之间的一段工作经历，包括职位、时间及明确的现任或曾任状态。
_Avoid_: 直接人际关系

**关键角色**：某段现任经历中的负责人或关键联系人标记，用于企业视角展示。
_Avoid_: 领导关系

**直接关系**：录入方记载的“对方是此人的……”关系，可带企业语境和备注。
_Avoid_: 同企业成员自动生成的关系

**反向关系**：从对方保存的直接关系派生的展示，不是另写入本方的一份关系。
_Avoid_: 关系双写

**已收录在职人数**：当前任职于该企业且已录入档案的联系人去重数量。
_Avoid_: 企业总人数

**资料目录**：用户选择的库内可见档案数据来源目录；切换它只切换读取与保存位置。
_Avoid_: 开发文档归档目录

**冲突草稿**：与最新文件的同字段或同正文区域发生冲突后保留在表单中的未保存输入。
_Avoid_: 已合并记录
