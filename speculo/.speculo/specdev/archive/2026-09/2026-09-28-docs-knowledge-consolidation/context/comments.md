# 编辑器评论

**评论线程**：关联一段笔记原文、包含评论及回复并具有处理状态的讨论记录。
_Avoid_: 笔记正文、单条回复

**评论消息**：线程中的一条正文或回复。
_Avoid_: 整个评论线程

**原文锚点**：通过来源文件、选区位置和原文片段关联评论与笔记的定位信息。
_Avoid_: 只按行号定位

**已解决**：评论线程被标记为处理完毕的状态；线程仍保留，可以重新打开。
_Avoid_: 已删除

**失效锚点**：当前无法可靠匹配原文的评论定位状态，不能猜测新的来源文字。
_Avoid_: 已解决

**划选浮层**：由当前可操作来源编辑器的有效选区触发的评论入口和输入界面。
_Avoid_: 全局当前笔记输入框

**评论草稿**：尚未保存到线程的输入内容，有效来源暂时隐藏时可保留；不等同于已持久化评论。
_Avoid_: 自动保存的评论
