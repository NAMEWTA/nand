# 图标

**图标模块**：NAND 内集成 Iconic 行为的可启停功能，为原生界面项目设置图标、Emoji 与颜色。
_Avoid_: 独立 Iconic 插件、看板图标选择器

**图标偏好**：图标模块自己的显示、交互、搜索和备份配置。
_Avoid_: NAND 全部主设置

**规则书**：分别管理文件规则和文件夹规则的有序规则集合。
_Avoid_: 笔记属性

**命中规则**：按当前规则顺序和条件影响目标图标的规则；多条匹配时采用首条启用规则。
_Avoid_: 任意匹配规则都叠加

**自定义图标**：直接为特定目标配置的图标或 Emoji，可受命中规则影响。
_Avoid_: 关闭默认图标

**图标自动备份**：图标数据保存时按间隔与保留份数轮换的快照。
_Avoid_: 每次操作的撤销历史
