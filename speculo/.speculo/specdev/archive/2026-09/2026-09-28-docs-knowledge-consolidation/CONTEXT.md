# NAND 插件壳层

**功能模块**：由 NAND 首页独立启停、拥有对应资源生命周期的产品能力。模块启停不等同于打开或关闭其界面。
_Avoid_: 页面开关、插件实例

**业务面板**：呈现某项 NAND 功能并接收状态与操作的界面内容，可组合在叶子、看板区块或原生弹窗中。
_Avoid_: 独立插件

**宿主叶子**：Obsidian 工作区中承载视图的页面容器；关闭容器是否结束业务服务由所属领域决定。
_Avoid_: 会话、功能模块

**模块占位页**：功能模块停用后由已注册视图显示的说明界面，不启动该模块的业务服务。
_Avoid_: 已卸载插件

**NAND 语言**：用户在 NAND 设置中选择的界面语言，用于该插件文案；不等同于 Obsidian 的语言。
_Avoid_: 系统语言

**同步预留入口**：当前只说明未来同步能力的占位入口，不提供正在运行的同步服务。
_Avoid_: 同步模块已实现
