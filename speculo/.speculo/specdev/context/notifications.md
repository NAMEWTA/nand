# 通知

**通知请求**：带稳定通知身份、内容、来源或运行目标及渠道的投递请求。
_Avoid_: 自动化执行本身

**通知渠道**：通知的目标介质；当前应用内与系统渠道可投递，邮件和短信只是未接入入口。
_Avoid_: 全部已可用服务

**收件箱记录**：供用户查看、标记已读、清理或跳转来源的可见通知条目。
_Avoid_: 投递去重回执

**投递回执**：按通知身份及渠道保存的投递依据，独立于可见收件箱保留。
_Avoid_: 已读状态

**投递未知**：曾保留投递占位但无法确认结果的状态，既不证明送达也不触发自动重发。
_Avoid_: 投递成功

**已读**：用户处理收件箱条目的阅读状态，不表示任务成功或所有渠道已送达。
_Avoid_: 已执行

**来源跳转**：从通知打开所属档案、看板或自动化运行的导航操作。
_Avoid_: 重新执行动作
