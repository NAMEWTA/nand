# NAND 领域关系

本图描述数据所有权与协作端口，源码五层不等同于业务领域。

~~~mermaid
flowchart TB
  Shell[插件壳层与首页设置] --> Views[看板 / Agent / 浏览器 / 档案面板]
  Views --> Actions[公共动作与领域服务]
  Actions --> Automation[手动执行与设备调度]
  Automation --> Terminal[原生会话]
  Automation --> Notifications[通知与回执]
  Browser[浏览器页面与材料] --> Terminal
  Notes[笔记与档案材料] --> Terminal
  Actions --> Documents[文档仓储与宿主适配器]
~~~

| 领域 | 所有权 | 协作方式 |
|---|---|---|
| 壳层 | 模块开关、全局语言、装配与生命周期 | 注入端口，协调启停 |
| 看板 | 栏目、卡片、待办及动作引用 | 来源端口、动作 ID |
| 自动化 | 独立定义、调度游标和运行记录 | 公共动作执行；读取来源增量索引 |
| 终端与 Agent | 进程、会话、权威缓冲、历史索引 | AgentSessionApi 与上下文材料 |
| 浏览器 | 页面、分区、授权及恢复元数据 | 页面注册、版本快照、上下文附加 |
| 档案 | 人物、企业、履历、关系、目录附件 | 文件索引、导航、材料引用 |
| 业务记录 | 习惯、记账、阅读、番茄实体和记录 | 文档仓储、稳定行 ID、保存状态 |
| 评论 | 线程、锚点与旁路正文 | 原生笔记引用 |
| 图标 | 图标规则、偏好和备份 | 宿主装饰与 UI 注入 |
| 通知 | 收件箱与独立回执 | 按运行身份接收投递请求 |

界面共处一个工作台不会改变数据归属。更多定义见本目录领域文件，长期取舍见 ADR。
