# 终端与编程智能体

**智能体工作台**：组合运行会话、当前库原生历史与用量信息的终端界面。
_Avoid_: 看板工作区

**终端会话**：NAND 管理的存活终端进程及其输出状态，可以暂时没有可见叶子。
_Avoid_: 终端标签、原生历史会话

**原生历史会话**：CLI 自己保存、带原生身份与可信工作目录的历史记录，可经对应 CLI 恢复。
_Avoid_: NAND 终端进程、自动化运行

**当前库历史**：工作目录真实位置属于当前库或其子目录的原生历史集合。
_Avoid_: 本机全部历史

**恢复会话**：通过 CLI 原生恢复能力打开指定已有会话；目标缺失时报错，不静默替换为新会话。
_Avoid_: 重新提交上次提示词

**收起工作台**：隐藏或关闭呈现界面而保留存活终端会话的操作。
_Avoid_: 停止会话

**原生完成状态**：来自可信 CLI 生命周期或真实进程退出的执行状态；缺少依据时保持未知。
_Avoid_: 静默即成功

**Token 用量**：原生记录提供的输入与输出计数，缓存读写是输入明细，不能重复相加。
_Avoid_: 订阅剩余额度

**订阅额度**：提供方返回的账户窗口或模型额度状态；与本地日志的 token 统计分开。
_Avoid_: Token 用量、统一周额度

**原生费用**：CLI 日志明确记录的费用；缺失时未知，不按模型价格估算。
_Avoid_: 推算账单

**历史归档标记**：NAND 为原生历史保存的列表管理元数据，不删除或改写 CLI 的原始记录。
_Avoid_: 档案记录、删除会话
