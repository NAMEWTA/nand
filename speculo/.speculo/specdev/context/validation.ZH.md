# 验证

本文把已验证的内容与仅仅声明的内容分开。只有命令或有记录的运行给出结果，才算已验证。门禁本身列在[当前基线](current-baseline.ZH.md)中。

## 由自动化检查验证

下列检查在每次 push 和 pull request 时由 CI 运行（Linux 用 Node 22 与 24，另有 Windows 执行构建、lint 和测试），本地用同样的命令运行：

- 类型检查、零警告的 ESLint、带只减不增基线的 stylelint。
- 没有基线的架构检查。
- 启动、各模块和总体的体积预算。
- Vitest：单元和 DOM 测试、用户数据格式黄金样例、带故障注入的模块注册表、设置存储、对真实 git（一个裸远端加两个克隆）的 Git 同步，以及对真实辅助进程的终端会话模型。
- 全部 `test:*` 脚本，包括 i18n 键一致、文档链接和状态索引。
- 终端辅助进程的 `cargo test --locked`，以及在 linux-x64、linux-arm64、darwin-x64、darwin-arm64 和 win32-x64 上对构建出的辅助进程运行 `scripts/verify-pty-helper.mjs`。
- 第三方署名文件与打包内容和 crate 依赖图一致。

## 在真实宿主上验证

- **Linux，Obsidian 桌面版。** `scripts/obsidian-acceptance/workbench-fresh-runtime.mjs` 创建一次性的库和配置目录，以远程调试方式启动 Obsidian，安装构建出的插件并运行 `workbench-probe.mjs`。探针通过。它覆盖多种宽度下的工作台布局、图标轨上的每个页面、设置页、模块开关、档案编辑、浏览器 guest、记录页面、经由真实 `nand-pty` 的终端（连接、回显、重放、分屏）、恢复路由和面板宽度的重启，以及对本地远端的 Git 同步（配置、首次发布、真实冲突、中止、关闭模块）。证据写入探针的 `evidence/` 目录。

## 未验证

下列各项只是声明或已实现，没有真实宿主上的结果。其他任何地方都没有把它们写成已通过。

### 平台与宿主

- **Windows 与 macOS。** CI 在这两个系统上构建终端辅助进程并测试协议，Windows 任务还会构建并运行测试。但没有真实的 Obsidian 会话在这些系统上检验过 ConPTY、macOS 终端、中文输入法、Agent TUI 的键盘模式，或 git 的查找路径。
- **Obsidian 1.13.0。** `minAppVersion` 是 `1.13.0`，代码不使用标注为更晚版本的 API，但没有在恰好 1.13.0 上运行过。探针运行在已安装的任意 1.13.x 桌面版上。
- **移动端。** 没有在手机或平板上运行过插件。与移动端相关的工作是缩小启动集合、仅桌面模块不在移动端加载，以及窄宽度的抽屉布局（宽度分类由单元测试覆盖）。性能、输入法和触控行为没有测量。
- **第三方主题。** 主题预置有截图矩阵脚本（阅读、实时预览、源码模式），在 Obsidian 默认主题上运行；与社区主题和片段的相互作用没有验证。

### 账号与服务

- **真实托管服务上的 Git 同步认证。** 测试使用本地裸远端。HTTPS 凭据管理器、SSH agent、托管服务的拒绝信息，以及真实网络上的大仓库首次推送，都没有检验。
- **使用真实账号的 Agent CLI。** Claude Code、Codex、Gemini CLI、OpenCode、Pi 和 Grok 的登录、启动、恢复和额度显示没有用真实账号重新运行。历史解析和恢复边界有本地测试，那不是对已登录 CLI 的检验。
- **第三方小组件。** 微信读书、音乐和天气小组件由桩测试覆盖，没有用真实账号或线上服务检验。
- **从发布附件安装。** 没有真实宿主运行记录验证从 GitHub Release 附件安装插件并下载辅助程序。Obsidian 探针使用本地构建和本地辅助程序；CI 单独检查打包文件。

### 长时间行为

- **长期运行。** 长时间保持的终端会话、大量并发会话，以及跨越数天、睡眠与唤醒的自动化运行，都没有测量。

## 档案规模

`pnpm run accept:contacts-scale` 不在 `test:all` 中。它写入临时 Markdown，建好索引后删除文件，再对内存索引查询 20 次。每次查询必须恰好命中一条。目标是热查询 P95 不超过 100 毫秒；下表是一台机器上的测量，不是产品保证。

机器：Linux x64，Node v26.11.1，8 个逻辑 CPU（12th Gen Intel Core i7-12700），约 23 GB 内存。

| 条数 | 写入字节 | 建索引（毫秒） | 热查询 P95（毫秒） |
|---|---:|---:|---:|
| 100 | 669,279 | 57 | 0.03 |
| 1,000 | 6,695,679 | 330 | 0.01 |
| 5,000 | 33,491,679 | 1,309 | 0.01 |

这台机器上达到了查询目标。建索引的时间不是查询目标。
