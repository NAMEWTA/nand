**严重程度 / Severity**：S4（轻微）｜**建议优先级 / Priority**：P3｜**复现率 / Frequency**：1/1（实时切换后）；重新加载插件后 0/1｜**类型**：缺陷（i18n / 布局）

## 问题概述 / Summary
在工作台「设置 → 常规 → 语言」里把 English **实时切换**成简体中文后，再打开「图标 · 常规」：「更大的图标」下拉框里的「仅限移动设备」**被截断**，显示成「仅限移动设…」。

下拉框的宽度还是按英文选项（"Mobile only"）算的：Obsidian 用来量宽度的隐藏 select 里仍然是英文文本。停用再启用插件、在中文下重新渲染后，宽度是 121px，显示正常。

## 复现步骤 / Steps to reproduce
1. 插件语言 English，打开工作台 →「Icons」页（让它先在英文下渲染一次）
2. 设置 → 常规 → Language 改成「简体中文」
3. 回到「图标 · 常规」，看「更大的图标」的下拉框（值为「仅限移动设备」）

## 期望结果 / Expected behavior
切换语言后下拉框按新文字重新计算宽度，文字完整显示。

## 实际结果 / Actual behavior
「仅限移动设备」被截断（截图红框）。DOM 里该行的第二个 `select`（宽度测量用）选项仍是 `Mobile only`；「可点击的图标」行同样残留 `Desktop only`（中文短一些，没有被截断）。

![clipped](https://gist.githubusercontent.com/NAMEWTA/055537ff620ae786bd57e0033896754f/raw/nand-r24-14-icons-select-clipped.png)

## 原因（推断）
`src/modules/icons/ui/settings/sections.ts` 用 `bindLocalizedOptions` 在语言切换时更新选项文字，但没有让 Obsidian 下拉框的宽度测量节点跟着更新（或重新调用 `setValue` 触发重新测量）。
