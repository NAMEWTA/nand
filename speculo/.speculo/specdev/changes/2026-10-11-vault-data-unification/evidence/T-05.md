## 1. 实现摘要

默认及命名账号都进入 .nand/agents/<device>/accounts/<provider>/<stable-id>。显示名 NFC 规范化，中文/标点/大小写身份不碰撞，非空非法名字显式失败。HOME、Windows 数据目录、XDG、临时目录、六个 CLI 的专属目录均使用该身份；不继承父进程中的常见 API 凭据。恢复按身份重新计算并核对全部环境，拒绝元数据注入外部目录和外部 transcript。Codex 启动/恢复/自动化强制文件凭据与库内日志、SQLite 配置。

用量和历史仅从当前库身份读取；删除旧 TS 扫描器的全局隐式来源。Hook 配置、生成脚本和每个终端的事件目录同属账号，跨实例安装按账号排队，生成代码在写入时也拒绝目录链接。辅助程序存放于 .nand/helpers/<device>/<platform-arch>/<version>，校验下载、开发副本和缓存回执，升级保留旧版本；辅助进程和普通终端具有 .nand 内的 HOME 和临时目录。

旧插件 accounts/binaries 先记录冷启动门槛，完全重启后才复制校验并退休来源。旧有损账号目录只在用户明确选择后复制到新身份；可选择新建身份；原始恢复副本留在库内。拒绝迁移变化、缺失目标和链接。库外 CLI 全局用户配置不作为 NAND 自有来源自动搬迁或删除。旧浏览器产物的绝对引用经回执和哈希映射到库内恢复副本。

Windows 首次访问及迁移后以 .NET DACL 收紧已有目录和文件，仅当前 SID 与 SYSTEM；不无谓改变 owner。POSIX 分支保留 0700/0600，实现存在但本轮未在该平台运行。权限失败会中断，不能回退全局位置。
