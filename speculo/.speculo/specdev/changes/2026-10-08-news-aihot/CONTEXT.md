# 本地新闻工作台与 Agent 分析领域语义

**新闻模块**：负责信源采集、新闻分析、阅读和收藏的可启停模块，模块 id 为 news。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**信源**：一个用户配置的 RSS、Atom、JSON Feed 或静态网页列表入口，具有来源分级和参与方式。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**资料**：从一个信源采集到的原始内容；规范化身份标识同一内容，内容哈希区分修订。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**分析**：对一份资料修订、有效提示词版本及 Agent 的结构化结果，保留评分维度、分类、摘要和关系判断。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**发生**：同一主体在同一时间针对同一对象做出的具体动作；同一次发生的多篇报道共享一个发生身份。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**事件**：一个发生及与它直接关联的后续进展集合，可包含多个发生和多个信源报道。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**独立参与方**：参与同一事件的独立作者、运营组、机构或信源；同一参与方多篇报道只贡献一次当前热度。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**精选**：通过相关性、来源分级门槛、有效写作和归组/新增信息条件的资料展示集合。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**热度**：在时间窗口内按独立参与方最近原文时间衰减累加的事件讨论指标。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**今日要闻**：从已有分析按确定规则编排的一日正文与快讯，不调用模型作条目排序。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**我的视图**：具稳定身份和名称的持久化筛选条件，可供新闻页面和首页组件实例引用。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**运行收据**：记录一次实际 Agent 调用的输入身份、执行状态、原始返回、用量与错误的设备数据。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**深入了解简报**：根据当前条目或事件及用户关注点生成、带来源链接的 Markdown 背景和影响说明。
_Avoid_: 将该词用作其它模块的持久化或调度权威。

**可比观测组**：在当前与过去窗口持续覆盖、信源未落后且没有晚加入的独立参与方集合。
_Avoid_: 将该词用作其它模块的持久化或调度权威。
