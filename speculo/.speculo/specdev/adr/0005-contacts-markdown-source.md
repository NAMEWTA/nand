# ADR-0005：档案以实体目录与 Markdown 为资料来源

状态：已接受，当前规范。核对日期：2026-10-01。

## 问题

人物和企业需要独立身份、任职与关系，附件应随资料目录自然归属。

## 决策

默认在 档案/个人档案/<名称>/基本信息.md 和企业分类目录保存资料；稳定 ID 区分同名实体。基本字段使用 YAML，履历、关系和说明使用正文受管区域。附件按实际目录归属。任职和直接关系只记录在人物档案；企业成员与反向关系从索引推导。

## 取舍与约束

按字段或整个正文区域做三方合并，不对履历表行自动合并。原始编辑器未保存、解析损坏或同字段冲突阻止覆盖。整目录删除需要核实范围，目录变化和未保存文件会阻止删除。

## 验证依据

[当前源码](../../../../src/core/contacts/application.ts)。pnpm test:contacts；实机覆盖同名人物、目录改名、附件变化、部分导入失败、冲突草稿和窄屏。
