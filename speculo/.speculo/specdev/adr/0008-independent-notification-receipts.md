# ADR-0008：通知回执独立于可见收件箱

状态：已接受，当前规范。核对日期：2026-10-01。

## 问题

隐藏或清理通知不能导致已经投递的副作用再次发生。

## 决策

通知正文、可见状态与投递回执分别表达其职责，保存于 `.nand/notifications/<device-id>/`。按运行身份去重；无法确认投递结果时记录未知，不自动重复发送。停止服务先封闭接收，再完成已接受的持久化。

## 取舍与约束

系统通知权限由宿主管理；通知失败不改变 Agent 的原生执行结果。邮件与短信仍为不可用渠道占位。

[当前源码](../../../../src/core/notifications/service.ts)。pnpm test:automation、pnpm test:reliability；覆盖投递去重、清理、失败恢复与卸载写入。
