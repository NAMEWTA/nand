# ADR-0006：评论旁路保存且不改写笔记

状态：已接受，当前规范。核对日期：2026-10-01。

## 问题

评论需要独立线程和可恢复锚点，不能污染笔记正文。

## 决策

评论正文、线程、锚点和恢复事务位于 `.nand/editor/comments/`。原笔记仍拥有正文，评论操作不改写它。编辑器扩展由宿主注册，关闭面板只卸载 UI；停用模块清理浮层、完成已接收保存并释放存储。

## 取舍与约束

备份笔记时必须包含评论目录。锚点无法恢复时显示失效状态，不能静默关联到错误文本。

## 验证依据

[当前源码](../../../../src/core/comments/store.ts)。pnpm test:editor-comments 与 pnpm test:issue-regressions；覆盖锚点变更、保存失败和卸载。
