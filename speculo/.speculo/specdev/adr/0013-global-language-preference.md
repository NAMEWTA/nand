# ADR-0013：首页通用设置与双语界面

状态：已接受，当前规范。核对日期：2026-10-01。

## 问题

语言是插件级偏好，不能因为关闭看板而失去修改入口。

## 决策

首页先显示通用设置，再显示模块开关。NandSettings.language 仅为 zh/en，默认或非法值归一为 zh，持久化到 `.nand/config/settings.json`。插件组合层串行保存后发布语言变化；失败保留原语言。看板页不再提供语言控件。所有 NAND 文案归领域 I18N，中文和英文键及插值参数一致。

## 取舍与约束

沿用现有语言状态及订阅，不新增全局 store。设置的声明式与回退渲染共用入口；切换语言刷新已有窗口，保留草稿，不重启 PTY 或导航网页。用户内容、路径、ID 与原文材料不翻译。

[当前源码](../../../../src/plugin/settings/language.ts)。pnpm test:i18n、pnpm test:settings-nav 与隔离 Obsidian；验证默认值、失败、连续切换、重载、多窗口与草稿。
