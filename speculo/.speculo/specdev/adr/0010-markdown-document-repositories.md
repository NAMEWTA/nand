# ADR-0010：Markdown 优先与可恢复文档仓储

状态：已接受，当前规范。核对日期：2026-10-01。

## 问题

集中 JSON、集合并集和整文档序列化可能覆盖外部编辑、复活删除并丢失自由内容。

## 决策

实体和记录使用 Markdown；设置与必要运行 JSON 进入 `.nand/`。DocumentRepository 读取快照并基于基线局部更新；Vault.process 校验最新文档，保留未知 YAML、注释和自由正文。记录用稳定行 ID 三方比较增删改；同一记录冲突保留双方信息。集合索引通过事件增量更新，同一存储按路径串行写入。

## 取舍与约束

读取失败或解析损坏不能被当成空文档。DurableState 暴露保存中、已保存、未保存和冲突，失败草稿进入 `.nand/recovery/`。业务记录不受缓存限额影响；逻辑删除保留文件标记。无旧格式扫描、迁移、双写或自动删除旧数据。

## 验证依据

[当前源码](../../../../src/shared/storage/document-repository.ts)。pnpm test:reliability；覆盖故障、并发增删改、编辑器草稿、日记录、保真与 10,000 条合成记录。
