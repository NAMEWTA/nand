# ADR-0012：浏览器分区、权限与页面退役

状态：已接受，当前规范。核对日期：2026-10-01。

## 问题

标签页、弹窗和登录窗口需要共享正确会话；未响应导航不能让关闭操作悬挂。

## 决策

每个 Vault 使用独立分区；主页面与登录弹窗安装权限请求及检查处理器，按来源管理授权，敏感权限默认拒绝。页面具有稳定身份与快照版本，旧元素引用拒绝执行。导航默认 30 秒，关闭立即结束调用方等待；无法安全停止时退役 guest，迟到结果不得影响新页面。

## 取舍与约束

Cookie 由宿主管理；历史、授权与恢复元数据保存至 `.nand/browser/<device-id>/`。本地 CLI 连接令牌仅运行期有效。浏览器呈现不拥有 Agent 进程；材料通过统一上下文接口附加。
