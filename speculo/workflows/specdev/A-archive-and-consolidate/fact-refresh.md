# 现有知识的事实校正

此分支由 A 唯一拥有，用于用户已授权的现有 context 事实纠正：版本、文件路径、模块清单、命令及其权威来源指针。它不新增领域结论、不改变已接受架构决策、不重写验证历史，也不移动或删除归档。

## 输入与边界

- 具体目标、旧论断、当前可复现来源和用户授权；仅发现过时内容不自动授权写入。
- 来源使用 manifest、配置、脚本、CI 或已验证实现；产品声明与实测结论分开。
- 先核对 roots、目标真实路径和归属，检查相关 active change、未闭合事务、锁与待提升写集。无关任务不阻塞；重叠或无法确定归属时只暂停受影响写入。

## 执行

1. 列出旧值、事实源、拟改内容和必要验证；已有授权覆盖时直接继续。
2. 优先将易变值改为权威来源指针，保留稳定解释和独有信息。需要语义取舍、证据不足、新领域知识或 ADR 变化时，转 consolidate-from-code/正常提升合同。
3. 只修改授权的现有 context。核对 diff、链接与直接事实源，运行适用文档检查。源码或实际行为未变时不构建插件、不重跑历史验收。
4. 在本次提交说明或交付报告中记录 A owner、目标路径、来源路径与 revision/digest、核对时间、验证和未验证项；回读目标确认更正。已有 source/research/归档证据保持原样。

## 完成标准

授权事实已纠正且可由来源重建，适用检查通过，证据已报告，其他知识与状态未变。此分支不创建 Change、Ticket、Map 或新的状态 schema，不执行归档、发布或未授权 Git 动作。发生来源漂移时重新核对受影响事实，不能把未验证的推断写成事实。
